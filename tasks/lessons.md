# Lessons

- When generating `.xlsx` files from CSV-like rows, do not treat every cell as text. Headers and status labels can be strings, but numeric identifier columns such as `barmatrix_question_number` should be written as numeric cells and verified by inspecting the workbook cell type, not only by comparing displayed values.
- When OpenClaw has hundreds of sessions created within the last day, age-based pruning such as `session.maintenance.pruneAfter = "7d"` will not reduce pressure. Use `session.maintenance.maxEntries`, disk budget controls, lower concurrency, or earlier subagent archiving instead.
- When tuning OpenClaw model sampling for legal or MBE work, do not blanket-set every generation model to the provider maximum temperature. Use model-by-model temperatures in the useful range for the work: lower for legal accuracy/reasoning, moderate for explanatory drafting, and higher only for creative scenario generation.
- When migrating OpenClaw API keys to env SecretRefs, do not assume provider-default env names are required. Ask for or choose a clear project-specific naming convention, then point each SecretRef `id` at that custom env variable name.
- Never create avoidable extra work for the user when the agent can do it directly. For example, when creating a `.env` file for the user to fill in, make the requested variables active blank assignments rather than commented examples.
- When wiring a new customer-facing question launcher, prove the entire click path through question render and answer submission/reveal on live data. A link that reaches a route is not enough if the route expects a different question ID namespace.
- When an Atlas outline code displays an approved question count, the selected-code panel must expose a visible action that opens a runnable Atlas question, not only an anchor, copy action, or lesson navigation.
- When a live Atlas screenshot still shows removed controls, verify the hydrated production DOM before patching. The user's tab can be running an older client state even when `barmatrix.app` now serves the fixed anchors.
