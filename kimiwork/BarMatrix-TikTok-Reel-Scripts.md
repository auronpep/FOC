# BarMatrix TikTok & Reel Scripts

## Document Purpose

Full production-ready scripts for TikTok and Instagram Reels, with shot-by-shot direction, on-screen text, audio cues, and CTA guidance. Each script is designed for 9:16 vertical format (1080×1920) and is optimized for mobile viewing with captions-on consumption.

---

## Production Standards

| Spec | Requirement |
|------|-------------|
| **Aspect Ratio** | 9:16 vertical |
| **Resolution** | 1080 × 1920 px minimum |
| **Duration** | 15–30 sec (optimal), up to 45 sec for educational |
| **File Format** | .mp4 |
| **Captioning** | Burned-in captions (80%+ watch muted) |
| **Hook Speed** | First 1–3 sec must deliver the hook |
| **CTA** | End card with "Link in bio" + BarMatrix logo |
| **Music** | Trending sound OR low-key ambient (must work muted) |
| **Text Style** | Bold, high-contrast, readable at arm's length |

### Color & Text Guidelines for On-Screen Text

| Element | Color | Font Style |
|---------|-------|------------|
| **Hook text** | `#C41E3A` (Primary Red) | Bold, 72pt+ |
| **Body text** | `#FFFFFF` (White) | Semi-bold, 48pt+ |
| **Correct answer** | `#10B981` (Green) | Bold |
| **Wrong answer** | `#C41E3A` (Red) | Bold with strikethrough or X |
| **Forensic tag** | `#D4AF37` (Gold) | Monospace accent |
| **CTA** | `#C41E3A` or `#FFFFFF` on red background | Bold, 60pt+ |
| **Background** | `#0A192F` (Deep Navy) or clean white | — |

## SCRIPT 1: "POV — The Two-Answer Trap"

**Campaign Phase:** Awareness (Week 1–2)  
**Objective:** Video views, profile visits, diagnostic starts  
**Tone:** Relatable, slightly frustrated, eye-opening  
**Duration:** 22 sec

### Full Script

```
[0:00–0:02]  HOOK
─────────────────────────────────────
VISUAL:  Black screen. White text fades in word by word.
TEXT:    "POV: You narrowed the MBE question"
SFX:     Subtle "whoosh" as each word appears (or silent)

[0:02–0:04]  PAIN AMPLIFICATION
─────────────────────────────────────
VISUAL:  Split screen appears. Left = Answer A. Right = Answer B.
         A hand (POV) hovers between them, shaking slightly.
TEXT:    "to two answers..."
         (small text below) "And you ALWAYS pick the wrong one."
SFX:     Ticking clock sound (subtle, 2 ticks)

[0:04–0:06]  THE MOMENT OF FAILURE
─────────────────────────────────────
VISUAL:  Hand taps Answer A. Big red X slams over it.
         Correct answer (B) highlights in green.
         Screen shakes slightly on the X.
TEXT:    "A. ❌"  (strikethrough on A)
         "B. ✅ CORRECT"
SFX:     "Buzzer" sound (low, not harsh) or silent

[0:06–0:10]  THE REVELATION
─────────────────────────────────────
VISUAL:  Screen wipes to black. New text appears:
         "Here's what the MBE doesn't want you to know:"
         Then rapid-fire text overlays appear one by one,
         each with a 0.5 sec hold:
         - "Stale Rule."
         - "Wrong Timing."
         - "Wrong Party."
         - "Overbroad Waiver."
         Each in gold text with a subtle glow.
TEXT:    (as above)
SFX:     Subtle "tick" for each trap pattern

[0:10–0:16]  THE SOLUTION
─────────────────────────────────────
VISUAL:  Screen recording of BarMatrix diagnostic flow:
         1. Question screen → user selects wrong answer
         2. "TRAP DIAGNOSED" card slides in
         3. Forensic tag: "Purpose-of-Offer Trap"
         4. Red-Zone Map appears with 3 highlighted traps
         5. "REPAIR DRILL ASSIGNED" notification
TEXT:    "BarMatrix diagnoses YOUR trap patterns"
         "and builds a Red-Zone Map..."
         "then gives you the exact drill to fix each one."
SFX:     Gentle "pop" sounds for each UI element

[0:16–0:20]  THE OFFER
─────────────────────────────────────
VISUAL:  Clean screen. BarMatrix logo top center.
         Large text in center:
         "Free 15-minute diagnostic"
         "No credit card"
         "See your traps before you pay a dime"
         Small text at bottom: "Link in bio 👇"
TEXT:    (as above)
SFX:     None — let the text breathe

[0:20–0:22]  END CARD
─────────────────────────────────────
VISUAL:  BarMatrix logo animates in.
         Text: "barmatrix.app"
         "Link in bio 👇"
         Background: subtle animated gradient (navy → slightly lighter navy)
TEXT:    (as above)
SFX:     Subtle brand sound or silent
```

### Caption Text (for Post)

```
POV: You narrow to two and pick wrong every time. 😤

The MBE recycles the same traps — BarMatrix finds yours.

Free 15-minute diagnostic. No card. Link in bio. 👇

#MBE #BarPrep #BarExam #LawStudent #BarMatrix #MBEtips #Barexamtips #LawSchool #BarPrep2026 #JulyBar
```

### Producer Notes

- **POV hand:** Use a realistic hand (not a cartoon). Law students should feel like it's their own hand.
- **Answer A/B split:** Make the answers look like real MBE questions (Civil Procedure or Evidence work well for broad relatability).
- **The "X" moment:** This is the emotional low point. Make it feel familiar, not shameful. The student should think "that's me."
- **Screen recording:** Use actual BarMatrix UI. If not available, use a high-fidelity mockup that matches the site's design.
- **Music:** Use a trending sound from TikTok's "trending" tab (check 24 hours before filming). If no good trend, use no music — the visual pacing should carry it.
- **Caption burn:** Use a bold, readable font (Inter Bold or Montserrat Bold) at 60pt minimum. White text with a black outline for readability on any background.

## SCRIPT 2: "Day in the Life — Before & After Diagnostic"

**Campaign Phase:** Awareness / Consideration (Week 2–3)  
**Objective:** Traffic to diagnostic, emotional connection, trust  
**Tone:** Authentic, relatable, hopeful  
**Duration:** 38 sec

## SCRIPT 3: "The Forensic Tag — Educational Hook"

**Campaign Phase:** Awareness / Educational (Week 1–4, evergreen)  
**Objective:** Video views, shares, saves, authority building  
**Tone:** Educational, authoritative, slightly conspiratorial  
**Duration:** 28 sec

### Full Script

```
[0:00–0:03]  THE CHALLENGE
─────────────────────────────────────
VISUAL:  Close-up of an MBE question on screen. Text is clear and readable.
         The question: Evidence / Hearsay scenario.
         A red circle highlights the key fact: "a week before the fall"
TEXT:    "This MBE question has a trap."
         "Can you spot it?"
SFX:     Ticking clock (3 ticks)

[0:03–0:06]  THE COMMON MISTAKE
─────────────────────────────────────
VISUAL:  The "A" answer is highlighted: "Exclude as hearsay."
         A hand cursor clicks A.
         Big red X. Screen shakes.
TEXT:    "Most people see 'hearsay'"
         "and immediately exclude it. ❌"
SFX:     Buzzer (soft)

[0:06–0:12]  THE EXPLANATION
─────────────────────────────────────
VISUAL:  The key fact "a week before the fall" is highlighted in gold.
         An arrow draws from the fact to a new text box:
         "Purpose of the offer = NOTICE, not truth of the matter"
         The correct answer (B) highlights in green.
TEXT:    "But the trigger fact is: 'a week before the fall.'"
         "The purpose of the offer is NOTICE —"
         "not truth of the matter asserted."
         "✅ B is correct."
SFX:     Correct "ding"

[0:12–0:18]  THE FORENSIC TAG
─────────────────────────────────────
VISUAL:  A forensic tag card slides in from the right.
         "TRAP DIAGNOSED"
         "Forensic Tag: Overbroad Hearsay Myth"
         "Why you fell for it: You assumed 'out of court'
          = 'hearsay' without checking the purpose."
         Then a drill assignment appears:
         "REPAIR DRILL: Hearsay Purpose-of-Offer Drill"
TEXT:    "BarMatrix calls this the 'Overbroad Hearsay Myth.'"
         "And every miss like this gets tagged and repaired."
SFX:     Two soft "pop" sounds (tag + drill)

[0:18–0:23]  THE PATTERN CONNECTION
─────────────────────────────────────
VISUAL:  Red-Zone Map appears with "Overbroad Hearsay Myth"
         highlighted in the top 3.
         Other traps visible but faded.
TEXT:    "This trap shows up on your Red-Zone Map..."
         "along with every other pattern that's costing you points."
SFX:     None

[0:23–0:28]  THE CTA
─────────────────────────────────────
VISUAL:  Clean screen. BarMatrix logo.
         "Want to see which traps YOU fall for?"
         "Free diagnostic. 15 minutes. No card."
         "Link in bio. 👇"
TEXT:    (as above)
SFX:     Subtle brand sound
```

### Caption Text (for Post)

```
The MBE engineers this trap to catch you. 🎣

Can you spot why "hearsay" is the wrong analysis here?

BarMatrix diagnoses YOUR trap patterns and gives you the exact repair drill. Free diagnostic. Link in bio. 👇

#MBE #Evidence #BarExam #LawStudent #BarPrep #BarMatrix #Hearsay #MBEtips #LawSchool #LegalEagle
```

### Producer Notes

- **Question selection:** Use a real BarMatrix question (or a faithful recreation of the hearsay example from the website). Evidence and Civil Procedure have the broadest relatability.
- **The "challenge" format:** This is a classic educational hook. It works because it invites the viewer to test themselves before revealing the answer.
- **The gold highlight:** Use the accent gold (#D4AF37) for trigger facts. This trains viewers to look for gold = important.
- **The forensic tag card:** This is the product reveal. Make it look exactly like the BarMatrix UI. If you don't have the real UI, use a mockup that matches the site's dark navy + red + gold aesthetic.
- **Evergreen potential:** This script can be reused with different trap patterns (Stale Rule, Wrong Timing, Wrong Party). Create 5–10 versions with different questions.
- **Music:** No music needed. The ticking clock and sound effects create enough audio texture. If using music, choose something subtle and suspenseful.

**Objective:** Re-engage users who started but didn't finish the diagnostic  
**Tone:** Gentle, curious, low-pressure  
**Duration:** 12 sec

```

         The bar is BarMatrix red (#C41E3A).

─────────────────────────────────────

         "Complete it free. No card."
         "Link in bio. 👇"
         BarMatrix logo.
```

### Caption Text (for Post)

```
You started it. You didn't finish. 🤷‍♀️
```

- **Low-pressure tone:** No urgency. No FOMO. Just "it might change how you study." This works for retargeting because the user already showed interest.
- **Music:** Use a calm, slightly curious track. Nothing aggressive.

## SCRIPT 8: "The Stuck at 60% — Volume Myth Buster"

**Campaign Phase:** Awareness / Educational (Week 2–4, evergreen)  
**Objective:** Challenge the "more questions = better" belief  
**Tone:** Provocative, data-driven, contrarian  
**Duration:** 26 sec

### Full Script

```
[0:00–0:03]  THE PROVOCATION
─────────────────────────────────────
VISUAL:  Big text on screen: "2,000 MBE questions."
         Then a second line: "Score: 60%."
         Then a third line: "STILL."
TEXT:    "2,000 MBE questions."
         "Score: 60%. STILL. 📉"
SFX:     Record scratch or sudden silence

[0:03–0:07]  THE PROBLEM
─────────────────────────────────────
VISUAL:  A graph appears: X-axis = questions done, Y-axis = score.
         The line is flat at 60% despite the X-axis climbing to 2,000.
         An arrow points to the flat line with text: "The plateau."
TEXT:    "The problem isn't volume."
         "It's pattern."
SFX:     None

[0:07–0:12]  THE TRUTH
─────────────────────────────────────
VISUAL:  The graph transforms. Instead of questions, the X-axis shows
         trap patterns: "Stale Rule," "Wrong Timing," "Wrong Party," etc.
         The Y-axis shows "attractiveness" (how likely you are to fall for it).
         A red zone highlights the top 3 traps.
TEXT:    "The MBE recycles a finite set of trap patterns."
         "If you don't diagnose them, more questions = more mistakes."
SFX:     Pop sounds for each trap pattern

[0:12–0:18]  THE SOLUTION
─────────────────────────────────────
```
