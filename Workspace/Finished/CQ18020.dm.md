### 2. Student case study

## program_frame

This is a Real Property land-use restriction item. The stem gives two rules:

| Rule source            |              Requirement |
| ---------------------- | -----------------------: |
| HOA/private board rule |          30-foot setback |
| Zoning ordinance       | at least 20-foot setback |

The exam is not asking which rule is more important in the abstract. It asks whether the private rule is enforceable when it is stricter than zoning but still compatible with it.

## student_access_test

This item is **anchor-assisted**.

A student can see the answer-text traps: “all private rules” is too broad, and “private rule overrides zoning” points the relationship the wrong way. But the decisive rule requires a taught property anchor: private land-use restrictions may be stricter than zoning if both rules can be obeyed.

**Call:** If the board passes the 30-foot setback rule, will it be legally enforceable?

**Prediction:** Yes. A 30-foot setback is stricter than an at-least-20-foot zoning minimum. A builder can obey both by setting the house back 30 feet. The private rule does not violate zoning.

## governing_c3_lane

**Lane:** Real Property private land-use restriction plus zoning compatibility.

**Gold Key:** A private land-use restriction may be stricter than zoning and still be enforceable if both rules can be obeyed. It cannot authorize what zoning forbids.

**Silver Key:** Do the numbers first. A 30-foot setback satisfies an “at least 20 feet” zoning minimum. That points to coexistence, not override.

**Legal verification:** The Restatement (Third) of Property: Servitudes treats servitudes as generally valid unless illegal, unconstitutional, or contrary to public policy, and the ALI describes the Restatement as covering creation, validity, interpretation, benefits and burdens, and enforcement of servitudes. ([Open Casebook][1]) A representative zoning conflict provision states that zoning is not intended to annul private covenants, and that the more restrictive public provision controls when zoning imposes the greater restriction. ([American Legal Publishing][2])

## choice_by_choice_walkthrough

### A. No, because the zoning ordinance overrides all private rules.

1. **Student-accessible C3 signal:** “All private rules” is too broad.
2. **Student label:** Zoning-wipes-private-rules overclaim.
3. **What a true/responsive version would look like:** “No, if the private rule permitted what zoning forbids or made zoning compliance impossible.”
4. **Lawyer confirmation:** Zoning does not categorically erase private covenants or HOA rules. Private restrictions can coexist with zoning unless they are illegal, contrary to public policy, or incompatible with public law. ([Open Casebook][1])

### B. No, because zoning laws regulate all property use.

1. **Student-accessible C3 signal:** This choice talks about zoning’s scope. The call asks whether this stricter private setback conflicts with zoning.
2. **Student label:** Zoning-scope wrong element.
3. **What a true/responsive version would look like:** “No, if the private rule conflicted with the zoning ordinance.”
4. **Lawyer confirmation:** Zoning can regulate land development, including setbacks, but zoning’s existence does not by itself invalidate a compatible private setback rule.

### C. Yes, because the rule does not violate the zoning ordinance.

1. **Student-accessible C3 signal:** This choice uses the exact compatibility fact: 30 feet complies with an at-least-20-foot rule.
2. **Student label:** Compatibility survivor.
3. **What a true/responsive version would look like:** This is already true and responsive.
4. **Lawyer confirmation:** The private rule is stricter, not weaker. A residence set back 30 feet also satisfies the zoning ordinance’s 20-foot minimum, so both rules can be obeyed.

### D. Yes, because a private rule overrides a zoning ordinance.

1. **Student-accessible C3 signal:** This gets the result right for the wrong direction. The private rule does not override zoning. It survives because it does not violate zoning.
2. **Student label:** Dominant private-overrides-public reversal.
3. **What a true/responsive version would look like:** “Yes, because the private rule is more restrictive and compatible with zoning.”
4. **Lawyer confirmation:** Private rules do not supersede public zoning law. If zoning imposed the greater restriction, the public restriction would control; here the private restriction is greater and compatible. ([American Legal Publishing][2])

## residual_answer

**Residual answer: C.**

A overclaims. B answers the wrong element. D reverses the hierarchy. C is left: the private rule is enforceable because it does not violate the zoning ordinance.
