**Fills:** proximate cause, intervening cause, mens rea bait.
**Adjacent to master:** involuntary manslaughter, voluntary manslaughter mitigation, murder malice, suicide/intervening act.

## crossover_intersection_map

| Crossover                       | Similar C3 move                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| Torts proximate cause           | Intervening cause cuts liability chain.                                               |
| Evidence relevance              | Threshold before merits; if the first gate fails, downstream arguments do not matter. |
| Civil Procedure jurisdiction    | Threshold absence beats merits.                                                       |
| Constitutional Law state action | No threshold, no merits analysis.                                                     |

## review_truth

For homicide, the first gate is legal causation; if the defendant did not proximately cause the death, manslaughter fails before intent, malice, or emotional distress matters.
