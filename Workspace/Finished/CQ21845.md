# Student-facing C3 case study

## 1. program_frame

This is a Criminal Law attempt item. The surface story is an empty drawer. The real question is narrower: **does a conditional theft plan defeat attempt intent?**

The answer is not chosen by asking whether Mason completed larceny. He did not. The answer is chosen by asking whether he had enough intent and enough action for **attempt**.

## 2. student_access_test

This item is **anchor-assisted**.

A student can structurally cut D because it does not answer the call. A student can cut C if the factual-impossibility anchor is already taught. The dominant A/B fight requires a tiny anchor:

**Gold Key:** Conditional intent can satisfy attempt intent. “I will steal the envelopes if they are there” is still an intent to steal the envelopes.

So this is not a hard-structural C3 solve. It is an **ANCHOR_SOLVE**.

## 4. call_and_prediction

**Call:** Does Mason’s conditional plan defeat attempt intent?

**Prediction:** No. A conditional intent can still be intent. Mason intended to steal payroll envelopes if he found them and acted toward that goal.

**Adjacent traps to avoid:** The empty drawer is not the call. The bag is not the call. The call is about **conditional intent**.

## 6. governing_c3_lane

**Lane:** Attempt intent + factual impossibility + conditional intent.

**Workflow:** CUT → CLASH → CALL.

C and D can be cut first. A and B then clash on one axis: **does conditional intent count?** The axis does not resolve from grammar alone. Use the tiny anchor.

## 7. choice_by_choice_walkthrough

### A. “Yes, because he intended to steal only if payroll envelopes were present”

1. **Student-accessible C3 signal:** This is the dominant trap. It treats the condition as erasing intent.

2. **Student label:** Conditional-intent-erases-intent trap.

3. **What a true/responsive version would look like:** “No, because intending to steal the envelopes if they are present can still be attempt intent.”

4. **Lawyer confirmation:** Conditional intent can satisfy attempt intent when the defendant intends to commit the crime if the condition occurs. The presence of payroll envelopes is just the condition for carrying out the theft; it does not negate the criminal purpose.

**C3 tag:** NOT_TRUE / backwards / anchor_assisted.

---

### B. “No, because he intended to steal the envelopes if present and acted toward that objective”

1. **Student-accessible C3 signal:** This answer matches the tiny anchor and the facts.

2. **Student label:** Conditional-intent survivor.

3. **What a true/responsive version would look like:** This is already true and responsive.

4. **Lawyer confirmation:** Attempt liability is supported because Mason intended to steal payroll envelopes if present and took action toward that theft by entering the locked office with tools and a bag.

**C3 tag:** credited answer / anchor_assisted.

---

### C. “Yes, because no payroll envelopes existed in the drawer”

1. **Student-accessible C3 signal:** This answer treats factual failure as if it defeats attempt.

2. **Student label:** Empty-drawer impossibility trap.

3. **What a true/responsive version would look like:** “No, the empty drawer means Mason failed to complete the larceny, but factual impossibility does not defeat attempt.”

4. **Lawyer confirmation:** Factual impossibility is not a defense to attempt. The absence of envelopes explains why Mason failed, not why he lacked attempt liability.

**C3 tag:** NOT_TRUE / backwards / pure_anchor.

---

### D. “No, but only because Mason carried a bag”

1. **Student-accessible C3 signal:** The conclusion is right, but the reason answers the wrong part. The call is about conditional intent, not whether a bag alone proves attempt.

2. **Student label:** Bag-only wrong element.

3. **What a true/responsive version would look like:** “No, because Mason intended to steal the envelopes if present and acted toward that objective.”

4. **Lawyer confirmation:** The bag is evidence, but the attempt rule is not “bag equals attempt.” The legally relevant reason is conditional intent plus action toward the target offense.

**C3 tag:** NOT_RESPONSIVE / wrong_element / hard_structural.
