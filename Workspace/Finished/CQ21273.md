## 7. Full right-answer explanation

**D is correct.** Esther intentionally asked Daniel to commit burglary if the stated condition occurred and gave him the media-room code. **Gold Key:** solicitation is complete when the defendant, intending that a crime be committed, asks another person to commit it. The requested crime need not happen, the solicited person need not agree, and a conditional request still counts if it asks for criminal conduct when the condition occurs. **Silver Key:** cut answers that add a post-request requirement. The request itself is the inchoate offense.

## 8. Full wrong-answer explanations

**A.** Daniel's refusal is the wrong stopping point. Agreement is a conspiracy idea, not a solicitation requirement. **Gold Key:** solicitation does not require the solicited person to agree.

**B.** This is the dominant trap. The word "if" makes the request sound hypothetical, but the request still tells Daniel to commit burglary if the volunteer is away. **Gold Key:** a conditional criminal request can still be solicitation.

**C.** This choice waits for the condition to actually happen. That is too late. Solicitation is complete when the criminal request is made with the required intent; the target crime need not occur or even begin.

## 9. Full black-letter-law verification and legal reasoning

The source row is Q21273, a Criminal Law / Inchoate Crimes item. The row is keyed to guilt because Nia communicated a request that Chris commit burglary under specified circumstances, supplied the access code, and Chris's refusal did not matter. The verified outline code is **71040100**, "Inchoate Offenses > Solicitation."

The tested rule is stable. Model Penal Code § 5.02(1) defines solicitation as purposely commanding, encouraging, or requesting another person to engage in conduct that would constitute the crime or an attempt. Source: https://www.criminallawweb.net/MPC/PART1/snippets/5_02.htm. Justia's solicitation overview states the same core elements: the defendant must ask, order, encourage, hire, or otherwise seek to induce another person to commit a crime, must intend the crime, and the other person need not commit or attempt the crime. Source: https://www.justia.com/criminal/offenses/inchoate-crimes/solicitation/. Oregon v. Everett collects authorities stating that solicitation is complete when the request is made with the requisite intent and does not require agreement or action by the solicited person. Source: https://law.justia.com/cases/oregon/supreme-court/2014/s060300.html.

The variation preserves the legal issue and credited outcome. Esther's request was conditional, but the condition merely described when Daniel should break into the media room. Daniel refused, but refusal does not defeat solicitation.
