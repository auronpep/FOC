### 6. Full right-answer explanation

**B is correct.** The rental agreement was already effective, but it contained an “unless” event that would end Lydia’s duty if it occurred before parade day. That event occurred: the city engineer lowered the permitted load below the contract’s threshold before the parade.

**Gold Key:** A condition subsequent is a later event that cuts off an existing duty.

**Silver Key:** Do not replace the contract’s stated “unless” trigger with a different doctrine. If the trigger happened, the contract clause does the work.

### 7. Full wrong-answer explanations

The breaker is that the agreement did not use impossibility as the trigger; it used the city engineer’s below-threshold load order. **Gold Key:** the terminating condition itself cuts off the duty once it occurs.

**C.** This choice sells the idea that Ruth’s plan was close enough to proceed. **D.** This choice sells a true starting point: the rental was effective when signed. The breaker is timing. The call asks what happens after the stated later event occurred, not whether the rental existed at the beginning.

### 8. Black-letter-law verification and legal reasoning

A condition subsequent is a later event that terminates an existing obligation. Cornell’s Wex definition states the same functional idea: if the event occurs, the party’s obligation terminates. ([Legal Information Institute][1]) Restatement (Second) of Contracts §230 states that when the contract provides that an event will terminate an obligor’s duty, the duty is discharged if the event occurs. ([Open Casebook][2]) Courts applying §230 use the same rule: if the specified terminating event occurs, the duty is discharged. ([Justia][3])

The transformed item preserves the original rule, legal issue, trap structure, and credited outcome. The official row’s rule reference is “Condition subsequent / duty cut off,” and its credited answer is that the duty was discharged when the specified below-threshold official order occurred.
