## 7. Full Right-Answer Explanation
B is correct. The transaction is treated by substance, not by deed label. Martha borrowed money, gave Cedaracre as security, received far less than the property's full value, and stayed in possession. Gold Key: when an absolute deed is intended only as security for a debt, equity treats the deed as a mortgage and preserves the borrower's equity of redemption. Silver Key: classify the transaction before choosing the remedy. Once the arrangement is a mortgage, default points to foreclosure, not outright ownership or summary eviction.

## 9. Full Black-Letter-Law Verification AND Legal Reasoning for the Right Answer
The tested issue remains Real Property, Mortgages, Equitable mortgage, and the verified outline code is `83050105`. An instrument that is absolute in form may be treated as a mortgage when the parties intended it to serve as security for an obligation. The relevant indicators are all present here: Martha needed a loan, Barnabas advanced money, Cedaracre was security for repayment, the value of the land substantially exceeded the loan, Barnabas orally promised reconveyance on repayment, and Martha stayed in possession. Because the transaction is an equitable mortgage, Martha keeps an equity of redemption and Barnabas's remedy after default is foreclosure under the jurisdiction's foreclosure procedures.

The authority floor is satisfied by Restatement (Third) of Property: Mortgages section 3.2, which addresses the absolute deed intended as security and treats security intent as the mortgage trigger. The American Law Institute describes that Restatement as covering real property used as security for obligations and mortgage substitutes. State codifications point the same way. Oklahoma title 46, section 1 provides that an instrument purporting to be an absolute conveyance but intended as security for payment of money is deemed a mortgage and must be foreclosed as such. New York Real Property Law section 320 likewise treats certain absolute deeds intended only as mortgage-like security as mortgages and denies the deed holder an advantage from recording unless related defeasance writings are also recorded.
