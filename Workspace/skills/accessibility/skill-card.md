## Description: <br>
Build WCAG 2.1 AA compliant websites with semantic HTML, proper ARIA, focus management, screen reader support, color contrast checks, keyboard navigation, form labels, and live regions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to implement or audit web interfaces for WCAG 2.1 AA accessibility, including semantic structure, keyboard operation, focus management, forms, ARIA, screen reader behavior, and color contrast. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Accessibility audits may read or search project source files that include unrelated sensitive material. <br>
Mitigation: Point the auditor at the specific page, component, or source folder to review, and avoid broad audits in directories that contain unrelated sensitive content. <br>
Risk: Guidance-only accessibility recommendations can be incomplete for a specific product, user population, or compliance context. <br>
Mitigation: Review suggested fixes against WCAG criteria and verify changes with keyboard testing, screen reader testing, and automated tools before relying on them. <br>
