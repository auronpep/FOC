Question: Federal law regulates safety labels for batteries but says nothing about state residency preferences. A state then requires all batteries sold in the state to be packaged by resident-owned firms. The state argues Congress "must have allowed" the preference because it regulated batteries generally. What is the best response?
Answer A: General federal regulation of batteries is not clear authorization for a state residency preference
Answer B: Any federal regulation in a field authorizes every state burden in that field
Answer C: The state wins because packaging is never commerce
Answer D: The state wins unless Congress sues the state directly
Correct Answer: A
Correct Answer Explanation: Authorization to burden interstate commerce must be clear, not inferred from silence.
Wrong Answer Explanations: B: Speaking nearby is not unmistakable authorization for discrimination. C: Packaging requirements can burden interstate commerce. D: Private parties can raise DCC objections; congressional lawsuit is not required.
lb_rule_reference: Congressional authorization of a state burden on interstate commerce must be unmistakably clear; mere federal silence or regulation in a nearby field is not enough.
