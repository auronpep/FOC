Question: In a federal collision trial, an accident expert for Paul uses a short computer animation to illustrate his opinion about the vehicles' paths. The animation is based on measurements already in evidence, and Paul offers it only to help explain the expert's testimony, not as an exact recording of the crash. The opponent objects that the animation is not a real video. How should the court rule?
Answer A: Exclude the animation because only actual recordings may be shown to the jury.
Answer B: Allow the animation as a demonstrative aid if it fairly illustrates the expert's testimony and is not misleading.
Answer C: Admit the animation as a self-authenticating public record.
Answer D: Exclude the animation unless the expert personally saw the crash.
Correct Answer: B
Correct Answer Explanation: A demonstrative animation can be used to illustrate expert testimony if it is grounded in evidence and its illustrative role is clear. It need not be an actual video of the event.
Wrong Answer Explanations: A: A confuses demonstrative aids with recordings of real events. C misclassifies the animation. D demands personal observation not required for expert opinion.
