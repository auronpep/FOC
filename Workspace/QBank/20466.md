Question: Noah mails a catalog to 10,000 customers listing “cedar benches, $90 each, while supplies last.” Ruth mails Noah an order for one bench and a check for $90. Noah has no benches left and returns the check. Ruth sues, arguing that the catalog itself was an offer. Is Ruth correct?
Answer A: Yes, because any advertisement stating a price is an offer to every reader.
Answer B: Yes, because Ruth signed and mailed her order form.
Answer C: No, because the catalog was a general advertisement inviting orders, and Ruth's order was the offer.
Answer D: No, because a buyer's offer to buy goods can be accepted only by shipment.
Correct Answer: C
Correct Answer Explanation: A general catalog or advertisement normally invites customers to make offers. Noah's “while supplies last” catalog did not manifest commitment to sell to every reader. Ruth's order was the offer, which Noah did not accept.
