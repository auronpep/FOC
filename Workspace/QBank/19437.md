MBE Subjects (1 of 7): Civil Procedure
Subtopic: Jurisdiction and Venue
Outline: Minimum contacts test
Question: ArtisanCo, a small workshop in State A, accepts a custom order from a State B customer, sends design proofs into State B, ships the finished machine to State B, and provides remote setup instructions there. The machine allegedly malfunctions in State B. ArtisanCo argues that litigating in State B would be expensive and inconvenient for its two employees. What is the best due-process analysis?
Answer A: Jurisdiction fails automatically because litigating away from home is burdensome for a small defendant
Answer B: Jurisdiction likely exists because ArtisanCo purposefully dealt with State B for this machine, and ordinary burden alone does not defeat fairness
Answer C: Jurisdiction exists because fairness factors can create minimum contacts even when defendant conduct is absent
Answer D: Jurisdiction fails because the machine was made in State A
Correct Answer: B
Correct Answer Explanation: The claim arises from ArtisanCo's deliberate State B order, communications, shipment, and setup. Fairness is considered after contacts and is not defeated by ordinary inconvenience.
Wrong Answer Explanations: A: Burden is part of fairness after contacts. ArtisanCo deliberately created claim-related State B contacts. C: Fairness cannot create minimum contacts from nothing. Here contacts exist independently. D: Specific jurisdiction can exist in State B because the claim arises from deliberate State B transaction and shipment activity.
lb_rule_reference: Courts assess fairness after purposeful, claim-related minimum contacts are shown; ordinary travel burden alone rarely defeats jurisdiction when the defendant deliberately created forum contacts.
