Question: In a diversity negligence action, the jury finds the plaintiff 20 percent at fault. The governing state law uses comparative fault and reduces damages by the plaintiff's percentage of fault. The defendant argues the federal court should apply a federal all-or-nothing rule because the allocation is made at trial. Which fault-allocation rule applies?
Answer A: A federal all-or-nothing rule, because the allocation occurs during a federal trial
Answer B: The state comparative-fault rule, because it defines the state tort recovery
Answer C: The plaintiff's preferred rule, because plaintiffs choose substantive law by filing first
Answer D: No fault rule, because federal juries only decide damages totals
Correct Answer: B
Correct Answer Explanation: State substantive law governs liability allocation for the state-law negligence claim.
Wrong Answer Explanations: A: Comparative fault changes the substantive measure of liability and recovery under state tort law. C: Filing first does not let a party select an otherwise inapplicable liability standard. D: Federal juries can apply state substantive standards through proper instructions.
lb_rule_reference: A federal diversity court applies the governing state's comparative-fault or contributory-fault rule to state-law tort claims.
