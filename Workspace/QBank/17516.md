Question: In a federal assault trial, the actual knife was never recovered. The prosecutor wants to show the jury a store-bought knife of similar size only while a witness explains the length of the blade she saw. The prosecutor does not claim it is the actual weapon. The defendant objects that the knife is not real evidence. What is the best ruling?
Answer A: Exclude the replica because demonstrative aids must be the actual object.
Answer B: Allow the replica as a demonstrative aid if sufficiently similar for illustration and not misleading, with a limiting instruction if needed.
Answer C: Admit the replica as the real weapon.
Answer D: Exclude the replica only because no chain of custody exists.
Correct Answer: B
