Question: In a federal fraud trial, Rebecca calls Ruth as her first witness. Before Ruth's credibility has been attacked, Rebecca asks another witness, “Is Ruth known in the community as a truthful person?” The opposing party objects. What is the best ruling?
Answer A: Overrule the objection because a party may always prove its witness is truthful first.
Answer B: Sustain the objection because truthful-character evidence is admissible only after the witness's character for truthfulness has been attacked.
Answer C: Overrule the objection because fraud cases always allow truthful-character evidence.
Answer D: Sustain the objection because reputation evidence can never be used to support credibility.
Correct Answer: B
Correct Answer Explanation: Evidence supporting a witness's truthful character is admissible only after the witness's character for truthfulness has been attacked. Offering it before any attack is premature bolstering.
Wrong Answer Explanations: A: A is wrong because a party cannot bolster a witness's truthful character before attack. C: C is wrong because the type of case does not create automatic bolstering. D: D is wrong because reputation or opinion evidence for truthfulness can be used after the proper attack.
lb_rule_reference: FRE 608(a) / premature bolstering
