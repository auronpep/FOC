Question: Peter and Paul owned neighboring parcels. Their families informally used a path across Paul's parcel to reach a garden on Peter's parcel. The parcels were never owned by the same person. Years later, Peter sold his parcel to Mary. Mary claimed an implied easement by prior use over Paul's parcel because the path was visible. Should Mary's implied-easement-by-prior-use claim succeed?
Answer A: No, because an implied easement by prior use requires prior common ownership and severance of the parcels.
Answer B: Yes, because a visible path always creates an implied easement for later buyers.
Answer C: Yes, because neighboring owners who cooperate for many years are treated as one common owner.
Answer D: No, but only because implied easements can arise only for utilities, not for paths.
Correct Answer: A
Correct Answer Explanation: An implied easement by prior use arises from severance of commonly owned land. The visible path may matter if the parcels were once under common ownership, but the facts state they were never commonly owned.
Wrong Answer Explanations: B: B is wrong because visibility alone does not replace common ownership and severance. C: C is wrong because cooperation between neighbors is not common ownership. D: D is wrong because implied easements can involve access paths when the elements are met.
lb_rule_reference: Prior-use implication requires common ownership and severance
lb_student_diagnostic: The trap is letting a visible path do all the work and skipping the common-owner/severance lock.
