Question: In a federal securities case, a corporation intentionally files one privileged email from counsel stating that a disclosure draft complied with the law. The corporation uses that email to argue good faith but refuses to produce other privileged emails from the same counsel about the same disclosure draft that may qualify or contradict the filed email. The opposing party seeks the related emails. Which ruling is most accurate?
Answer A: Deny production because voluntary disclosure waives only the exact email disclosed and can never reach undisclosed communications.
Answer B: Order production of every privileged communication the corporation ever had with counsel.
Answer C: Order subject-matter production if the intentional disclosure waived privilege, the communications concern the same subject matter, and fairness requires them to be considered together.
Answer D: Deny production because subject-matter waiver applies only to work product, not attorney-client communications.
Correct Answer: C
Correct Answer Explanation: Under Rule 502(a), an intentional disclosure in a federal proceeding can create subject-matter waiver when the disclosed and undisclosed communications concern the same subject matter and fairness requires considering them together. The rule targets selective, misleading use. The decisive axis is intentional selective disclosure plus fairness.
Wrong Answer Explanations: A: A is wrong because This ignores subject-matter waiver when selective disclosure would be unfair. B: B is wrong because This overextends waiver. Subject-matter waiver is limited to the same subject matter and fairness need. D: A is wrong because This ignores subject-matter waiver when selective disclosure would be unfair. B is wrong because This overextends waiver. Subject-matter waiver is limited to the same subject matter and fairness need. C is wrong because Correct answer D is wrong because Rule 502(a) applies to attorney-client privilege and work-product protection.
lb_rule_reference: FRE 502(a) / subject-matter waiver
lb_student_diagnostic: Student either under-waives the disclosed email or over-waives all privileged communications.
