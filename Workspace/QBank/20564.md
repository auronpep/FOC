Subtopic: Jurisdiction and Venue
Outline: Personal Jurisdiction
Question: Plaintiff moved from North State to West State after a contract dispute arose. Defendant, a North State consultant, had negotiated and performed the consulting agreement entirely in North State. Defendant never advertised in West State, never sent work there, and did not know Plaintiff would move. West State's long-arm statute reaches as far as due process allows. Plaintiff sues Defendant in West State. How should the court analyze personal jurisdiction?
Answer A: Exercise jurisdiction because the long-arm statute reaches as far as due process allows
Answer B: Exercise jurisdiction because Plaintiff now feels the economic harm in West State
Answer C: Dismiss because the broad long-arm statute does not eliminate the need for defendant-created minimum contacts
Answer D: Dismiss only if West State also lacks subject-matter jurisdiction
Correct Answer: C
Correct Answer Explanation: Defendant did not create meaningful contacts with West State. A coextensive long-arm statute still requires due process.
Wrong Answer Explanations: A: The broad statute only removes a statutory obstacle. The court must still find defendant-created minimum contacts with West State. B: Plaintiff's unilateral move does not create the defendant's forum contacts. D: Personal jurisdiction and subject-matter jurisdiction are separate. The facts raise a PJ defect even if SMJ exists.
lb_rule_reference: When a state long-arm statute reaches to the limits of due process, the court still must ask whether the defendant has constitutionally sufficient forum contacts.
