Question: A coastal state requires all shrimp caught in its waters to be shelled and packaged by in-state processors before shipment to buyers in other states. The state says the rule helps local regulators track conservation data, but the same data could be gathered through landing reports. How should a court view the rule?
Answer A: As likely discriminatory because it forces in-state processing before interstate shipment
Answer B: As automatically valid because it applies to every shrimp caught in the state
Answer C: Under Pike balancing because every DCC case uses Pike
Answer D: As valid because states own all seafood once caught
Correct Answer: A
Correct Answer Explanation: The rule reserves processing work for local businesses and has a nondiscriminatory reporting alternative.
Wrong Answer Explanations: B: A local-processing mandate can discriminate by forcing business into the state. C: Discriminatory local-processing rules are not ordinary incidental burdens. D: A state cannot use ownership rhetoric to impose protectionist processing rules on articles of commerce.
lb_rule_reference: A state law requiring goods to be processed in-state before export is ordinarily discriminatory economic protectionism, even if framed as conservation.
