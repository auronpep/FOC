Outline: Reliance damages
Question: Jacob contracted with Deborah to host a training program. Deborah breached before the program began. Jacob reasonably spent $10,000 on reusable tablets for the program. After the breach, Jacob kept the tablets and used them in his regular business. Their fair value to Jacob in that use was $4,000. Jacob's expected profits from the training program are too uncertain. What reliance recovery best avoids overcompensation?
Answer A: $10,000, because Jacob spent that amount.
Answer B: $6,000, because the $10,000 expenditure is reduced by the $4,000 value Jacob retained.
Answer C: $4,000, because retained value is the only amount proven.
Answer D: Nothing, because Jacob kept the tablets.
Correct Answer: B
Correct Answer Explanation: Reliance damages should restore the injured party's reliance position without overcompensation. Jacob spent $10,000 but retained a $4,000 value from the tablets, so his net reliance loss is $6,000.
Wrong Answer Explanations: A: A is wrong because it ignores the value Jacob retained. C: C is wrong because retained value reduces damages; it is not the damage amount. D: D is wrong because keeping the tablets reduces recovery but does not eliminate it.
lb_rule_reference: Reliance damages / retained materials offset
