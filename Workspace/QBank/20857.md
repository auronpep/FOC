Question: A minor is injured in a state-law accident claim. The governing state limitations period is two years, but the same state tolls the period until the plaintiff turns 18. The plaintiff files in federal court under diversity three years after the accident, while still a minor. Is the claim time-barred?
Answer A: Yes, because only the two-year number matters in federal court
Answer B: Yes, because tolling is always a matter of federal procedure
Answer C: No, because the state tolling rule keeps the state claim alive
Answer D: No, but only because minors are immune from all civil limitations periods
Correct Answer: C
Correct Answer Explanation: In diversity, state limitations incidents such as tolling generally apply with the state claim.
Wrong Answer Explanations: A: State tolling rules are part of the state time-bar regime applied in diversity. B: The state tolling rule affects the life of the state claim and ordinarily travels with the state limitations rule. D: The answer depends on the governing state's tolling rule, not a universal immunity from time bars.
lb_rule_reference: A federal diversity court generally applies state limitations rules, including state tolling rules, unless a valid federal directive directly controls.
