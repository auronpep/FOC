Question: In a federal fraud trial, Esther testifies for the plaintiff. Before the defendant has cross-examined Esther or offered any evidence attacking her credibility, the plaintiff calls Ruth and asks, “What is Esther's reputation in the community for truthfulness?” The defendant objects. How should the court rule?
Answer A: Overrule the objection because every witness's credibility is automatically in issue once the witness testifies.
Answer B: Overrule the objection because reputation evidence is always the preferred method of proving character.
Answer C: Sustain the objection because evidence supporting a witness's truthful character is admissible only after that character has been attacked.
Answer D: Sustain the objection only if Ruth also planned to describe specific truthful acts by Esther.
Correct Answer: C
Correct Answer Explanation: Under FRE 608(a), a witness's character for truthfulness may be supported by reputation or opinion evidence only after the witness's character for truthfulness has been attacked. Esther has not yet been attacked for truthfulness, so Ruth's reputation testimony is premature.
Wrong Answer Explanations: A: A is wrong because credibility being generally relevant does not permit preemptive truthful-character bolstering. B: B is wrong because reputation is a permissible form only when support is otherwise allowed. D: D is wrong because the problem is timing, not merely the use of specific acts.
lb_rule_reference: FRE 608(a) / premature support for truthful character
lb_student_diagnostic: Tests premature bolstering and the sequence requirement for truthful-character support.
