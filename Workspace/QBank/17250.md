Outline: Issue and Claim Preclusion
Question: In a small civil action using a preponderance standard, a court found that Damon made a false statement. Later, a fraud action between the same parties requires proof by clear and convincing evidence. The plaintiff argues Damon is issue-precluded from disputing falsity because of the earlier finding. What is Damon's best response?
Answer A: The earlier finding necessarily controls because any prior finding is always preclusive
Answer B: The earlier finding may not preclude the issue because the later case requires a higher burden of proof
Answer C: The earlier finding controls only if the later case is filed in the same courthouse
Answer D: The earlier finding cannot matter because issue preclusion applies only after criminal convictions
Correct Answer: B
Correct Answer Explanation: A party should not be bound to a higher-burden issue solely by a lower-burden finding when fairness is impaired.
Wrong Answer Explanations: A: Issue preclusion is not automatic; fairness and burden differences matter. C: Courthouse location is not the controlling element. D: Issue preclusion is a civil doctrine too, but its elements must be satisfied.
lb_rule_reference: Issue preclusion requires fairness and a full and fair opportunity; a materially different burden of proof can defeat preclusion.
