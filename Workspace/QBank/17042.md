Question: A driver negligently injured a student's brother outside a school. The student was in class and did not see or hear the collision. Later that day, the student watched security video of the crash and suffered severe distress. The jurisdiction recognizes bystander NIED only for close relatives who contemporaneously perceive the injury-producing event. Can the student recover for bystander NIED?
Answer A: Yes, because the student saw video showing exactly what happened
Answer B: Yes, because the injured person was the student's brother
Answer C: No, because the student did not contemporaneously perceive the accident
Answer D: No, because emotional distress is recoverable only after physical impact
Correct Answer: C
Correct Answer Explanation: The student learned the details later by video, so the contemporaneous-observation requirement is missing.
Wrong Answer Explanations: A: The rule requires contemporaneous perception of the event, not later viewing. B: Relationship alone is not enough; contemporaneous perception is also required. D: The stated bystander rule can allow emotional-only recovery; this claim fails on timing, not impact.
lb_rule_reference: Bystander NIED usually requires contemporaneous perception of the injury-producing event, not learning about it later by video.
