Outline: Requirements for valid deed
Question: Hannah signed and delivered a deed stating, “I convey my lake lot to my children.” At delivery, Hannah had exactly two living children, Samuel and Miriam. No one else claimed to be Hannah's child. The deed otherwise satisfied deed formalities. Who owns the lake lot?
Answer A: Hannah, because a deed must name each grantee individually.
Answer B: Samuel and Miriam, because the class description identifies ascertainable grantees at delivery.
Answer C: Samuel alone, because the oldest child takes when a deed does not list shares.
Answer D: Hannah, until Samuel and Miriam sign the deed.
Correct Answer: B
Correct Answer Explanation: The title source is a deed, and the decisive validity gate is grantee ascertainability. A deed can identify grantees by an ascertainable class. Hannah's children at delivery were Samuel and Miriam, so the deed can convey the lake lot to them.
Wrong Answer Explanations: A: A is wrong because individual names are not always required if the class is ascertainable. C: C is wrong because the oldest child does not take the entire property merely because shares are unstated. D: D is wrong because grantees generally need not sign the deed to receive title.
