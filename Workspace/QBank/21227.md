Outline: Prior inconsistent statement
Question: In a federal accident trial, Martha testifies that the defendant's car stopped at the red light. The plaintiff properly impeaches Martha with her unsworn prior text message saying, “The defendant ran the red light.” The court admits the text only for impeachment. The defendant immediately requests a limiting instruction. What should the court do?
Answer A: Refuse the instruction because once the text is read, the jury may use it for any purpose.
Answer B: Give an instruction limiting the text to Martha's credibility and not the truth of whether the car ran the light.
Answer C: Strike the text entirely because limiting instructions are unavailable for prior inconsistent statements.
Answer D: Give the instruction only if Martha denies sending the text.
Correct Answer: B
Correct Answer Explanation: When evidence is admissible for one purpose but not another, the court must restrict the evidence to its proper scope and instruct the jury accordingly on timely request. Because the text is admitted only to impeach Martha, the requested limiting instruction should tell the jury not to use it as substantive proof.
Wrong Answer Explanations: A: A is wrong because limited-purpose evidence does not become usable for all purposes merely because the jury heard it. C: C is wrong because limiting instructions are the ordinary way to control impeachment-only evidence. D: D is wrong because the need for the instruction turns on limited use, not on whether Martha denies sending the text.
lb_rule_reference: FRE 105 / limiting instruction for impeachment-only PIS
lb_student_diagnostic: Tests limited-use control for impeachment-only prior inconsistent statements.
