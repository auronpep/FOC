Subtopic: Jurisdiction and Venue
Outline: Personal Jurisdiction
Question: Buyer, a State A museum, sends one email order to Seller, a State B art dealer, for a sculpture listed in a national catalog. Seller ships the sculpture from a warehouse in State C to Buyer's museum in State A. The invoice is payable to Seller's State B bank, but Buyer never visits State B and has no continuing obligations there. Seller sues Buyer in State B for nonpayment. Which statement best analyzes personal jurisdiction in State B?
Answer A: Jurisdiction exists automatically because Seller resides in State B
Answer B: Jurisdiction is doubtful because Buyer made only an isolated purchase with no forum performance or continuing State B obligations
Answer C: Jurisdiction exists because the invoice was payable to a State B bank
Answer D: Jurisdiction fails only if State B lacks subject-matter jurisdiction
Correct Answer: B
Correct Answer Explanation: A single purchase from a forum resident, without more defendant-created forum conduct, is weak for purposeful availment.
Wrong Answer Explanations: A: The defendant's contacts with the forum matter. Plaintiff residence alone does not create Buyer's minimum contacts. C: An invoice payable to the seller's bank is not enough by itself to show purposeful availment of the forum. D: The issue is defendant minimum contacts, not the court's subject-matter authority.
lb_rule_reference: A defendant does not necessarily purposefully avail itself of a forum by making a one-time purchase from a forum resident when performance, delivery, and ongoing obligations are outside the forum.
