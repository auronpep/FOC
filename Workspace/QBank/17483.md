Question: Congress creates a new optional health program and tells states they must join it or lose all funding for a long-running, separate health program that makes up a major portion of each state's budget. Several states argue the condition leaves them no real choice. What is the best analysis?
Answer A: The condition is valid because every federal funding condition is voluntary by definition
Answer B: The condition may be coercive because it threatens a large existing funding stream to force acceptance of a new program
Answer C: The condition is invalid only if it is unclear
Answer D: The condition is valid only if state voters approve it by referendum
Correct Answer: B
Correct Answer Explanation: The condition resembles compulsion rather than ordinary inducement.
Wrong Answer Explanations: A: Financial pressure can become coercive enough to cross the constitutional line. C: Clear conditions can still be coercive. D: Spending Clause doctrine does not require a state referendum.
lb_rule_reference: Spending conditions become unconstitutional when financial pressure is so coercive that states have no real choice, especially when Congress threatens large existing funding streams to force acceptance of a new program.
