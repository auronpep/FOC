Question: The court circulates proposed jury instructions and asks for objections before closing arguments. Defendant says nothing. After the jury returns an adverse verdict, defendant argues for a new trial based on an obvious but ordinary instruction error that defendant could have raised earlier. What is defendant's preservation problem?
Answer A: Defendant generally needed to object before the jury retired and state the grounds
Answer B: Defendant could wait until after verdict as a matter of right
Answer C: Jury instructions never need objections
Answer D: The issue is preserved only if defendant also moved for default judgment
Correct Answer: A
Correct Answer Explanation: Rule 51 requires timely objection to preserve ordinary instruction errors.
Wrong Answer Explanations: B: Waiting until after the verdict usually forfeits ordinary objection. C: Objections preserve instruction issues. D: Default judgment is unrelated to preserving instruction error.
lb_rule_reference: A party must object to a jury instruction on the record, stating the matter objected to and grounds, before the jury retires, unless plain-error review applies.
