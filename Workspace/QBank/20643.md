Subtopic: Defenses to Enforceability
Outline: Mistake / Lack of Mutual Assent
Question: Leah agrees to buy a set of 100 used carts from Isaac for her store. Both parties believe each cart has a capacity of 200 pounds. After signing, Leah discovers that the carts have a capacity of 195 pounds. The difference does not affect Leah's intended use or the carts' market value in any meaningful way. Can Leah avoid the contract for mutual mistake?
Answer A: No, because the mistake did not materially affect the agreed exchange.
Answer B: Yes, because any shared mistake about a number in the bargain permits rescission.
Answer C: Yes, because the seller is always responsible for exact technical accuracy.
Answer D: No, but only because Leah has already received the carts.
Correct Answer: A
Correct Answer Explanation: Mutual mistake requires a material effect on the agreed exchange. A minor capacity difference that does not meaningfully affect use or value is not enough for avoidance.
Wrong Answer Explanations: B: B is wrong because a shared factual error must be material. C: C is wrong because mistake doctrine does not make the seller automatically liable for immaterial technical inaccuracies. D: D is wrong because receipt alone is not the reason; the lack of material effect is decisive.
lb_rule_reference: Material effect requirement
