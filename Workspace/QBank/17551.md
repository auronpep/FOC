Question: In a federal nuisance trial, Esther has already called six witnesses who each testified that they heard the same machine noise at 10 p.m. each night. She calls a seventh witness and asks the same question about the same sound at the same time. The defendant objects. What is the best ruling?
Answer A: Sustain the objection if the additional testimony is needlessly cumulative.
Answer B: Sustain the objection because no more than three witnesses may testify to the same event.
Answer C: Overrule the objection because every witness with personal knowledge has an absolute right to testify.
Answer D: Overrule the objection because cumulative testimony is never a valid concern.
Correct Answer: A
Correct Answer Explanation: The court may control presentation to avoid wasting time. Even relevant firsthand testimony may be limited if it is needlessly cumulative.
Wrong Answer Explanations: B: B is wrong because there is no fixed numerical limit. C: C is wrong because personal knowledge does not create an absolute right to present unlimited cumulative proof. D: D is wrong because cumulative proof can be limited.
