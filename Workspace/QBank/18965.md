Question: Abraham is charged with mailing a threatening note to Isaac. The government offers an envelope found in a trash bin behind Abraham's house. The envelope bears Isaac's address and Abraham's fingerprint, but the threatening note itself was mailed in a different envelope that has been lost. Abraham objects that the envelope from the trash is inadmissible because it is not the original threatening note. How should the court rule?
Answer A: Exclude the envelope because the original threatening note is required for any evidence about mailing.
Answer B: Admit the envelope if its address, location, and fingerprint make it probative of preparation or connection to the mailing; the original-writing rule does not bar it.
Answer C: Exclude the envelope because fingerprints are character evidence.
Answer D: Admit the envelope only if the government proves it contained the lost threatening note.
Correct Answer: B
Correct Answer Explanation: The trash-bin envelope is not offered to prove the contents of the lost threatening note. It is circumstantial physical evidence connecting Abraham to preparations for a mailing to Isaac. The address, location, and fingerprint make it probative; weaknesses go to weight.
Wrong Answer Explanations: A: A is wrong because the original-writing rule does not bar physical evidence offered for circumstantial connection rather than contents. C: C is wrong because the fingerprint is identity/source evidence, not character evidence. D: D is wrong because the envelope can be relevant even if it did not contain the actual note.
lb_rule_reference: FRE 401; FRE 901(a); FRE 1002 decoy
lb_student_diagnostic: Student misroutes physical-source evidence into original-writing or character doctrine.
