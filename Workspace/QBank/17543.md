Outline: Motion for judgment on the pleadings
Question: Before limitations expired, Peter sued a delivery company for a January 10 crash. After limitations expired, Peter seeks to amend to add a claim against the same company for a separate February 20 crash at a different location. Does the amendment relate back merely because the defendant is the same?
Answer A: Yes, same defendant is always enough
Answer B: Yes, because all car crashes are the same type of event
Answer C: No, because the amendment concerns a different accident and factual occurrence
Answer D: No, because amendments after limitations are never possible
Correct Answer: C
Correct Answer Explanation: The original complaint did not give notice of the February crash claim.
Wrong Answer Explanations: A: Rule 15(c) requires the same conduct, transaction, or occurrence. B: Similarity is not the same transaction. D: Some amendments relate back when Rule 15(c) is satisfied.
lb_rule_reference: Same defendant is not enough; the amendment must arise from the same conduct, transaction, or occurrence.
