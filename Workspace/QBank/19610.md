Subtopic: Strict Liability and Products Liability
Outline: Strict Products Liability
Question: A component maker sells standard steel bolts that meet all specifications and are safe for ordinary uses. A machine manufacturer uses the bolts in a press design that places too few bolts near a high-stress joint. The joint fails because of the finished press design, injuring a worker. The worker sues the component maker in strict products liability. What is the component maker's strongest defense?
Answer A: The component maker supplied a nondefective component, and the defect came from the finished product's design
Answer B: The component maker is liable because every supplier of anything in the finished product is strictly liable
Answer C: The component maker is liable because the worker lacked a contract with the machine manufacturer
Answer D: The component maker wins only if steel bolts can never be dangerous
Correct Answer: A
Correct Answer Explanation: Strict liability does not automatically attach to a nondefective component when another party's integration creates the defect.
Wrong Answer Explanations: B: Component status does not erase the defect and causation requirements. C: Privity is not the issue, and it would not create a defect in the bolts. D: The point is that these bolts were nondefective and the finished design caused the harm.
lb_rule_reference: A supplier of a nondefective component is not automatically liable for a finished product's defective design created by another manufacturer.
