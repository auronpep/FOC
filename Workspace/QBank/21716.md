Outline: Parol Evidence Rule
Question: Jonah agreed in a signed writing to sell Esther 50 cedar tables for $500 each. A week before signing, Jonah had sent Esther a written proposal offering the tables for $450 each. Esther offers the earlier written proposal to reduce the price in the signed contract. How should the court rule? How should the court rule?
Answer A: Admit the earlier proposal because it is written rather than oral.
Answer B: Exclude the earlier proposal because it is prior extrinsic evidence that contradicts the final written price.
Answer C: Admit the earlier proposal because proposals are not negotiations.
Answer D: Exclude the signed contract because it differs from the prior proposal.
Correct Answer: B
Correct Answer Explanation: The parol evidence rule applies to prior writings as well as prior oral agreements. The earlier $450 proposal directly contradicts the final written $500 price and is not admissible to vary that term.
Wrong Answer Explanations: A: A is wrong because written status does not remove a prior proposal from PER analysis. C: C is wrong because a proposal is a negotiation document outside the final writing. D: D is wrong because inconsistency with a prior proposal does not invalidate the signed contract.
lb_rule_reference: Prior writing / contradiction
