Question: In a federal assault trial, Isaac offers a sword with a distinctive carved handle. Miriam testifies that she took the sword from the scene, recognized the carving, and gave it to the marshal. The marshal testifies that he brought that sword to court. The defendant objects that Isaac did not call the evidence-room clerk. How should the court rule?
Answer A: Exclude the sword because every link in every chain of custody must testify.
Answer B: Admit the sword if the testimony is sufficient to support a finding that it is the same distinctive object.
Answer C: Exclude the sword because distinctive objects cannot be authenticated by witness recognition.
Answer D: Admit the sword only if the defendant admits using it.
Correct Answer: B
Correct Answer Explanation: A distinctive physical object can be authenticated by witness recognition and testimony sufficient to support a finding that it is the item claimed. Missing links may affect weight if no serious tampering issue appears.
Wrong Answer Explanations: A: A demands an unnecessarily complete chain. C is false; distinctive characteristics can authenticate. D wrongly requires an opponent admission.
