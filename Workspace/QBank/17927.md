Subtopic: Relevancy and Excluding Relevant Evidence
Outline: Laying a Foundation
Question: In a federal theft trial, the prosecution offers a store surveillance video. Ruth, the store manager, testifies that the camera system records continuously, stamps the correct time, was working normally that day, and that the offered file was copied from the system's archive. The defendant objects that no eyewitness can say the video shows the event. How should the court rule?
Answer A: Exclude the video because only an eyewitness to the theft can authenticate it.
Answer B: Exclude the video unless a camera engineer testifies.
Answer C: Admit the video because Ruth's testimony sufficiently describes a process or system that produced an accurate recording.
Answer D: Admit the video only if the defendant admits he appears in it.
Correct Answer: C
Correct Answer Explanation: Evidence may be authenticated by describing a process or system and showing it produces an accurate result. Ruth's testimony about the surveillance system and archive supplies a sufficient foundation.
Wrong Answer Explanations: A: A is wrong because an eyewitness to the event is not the only authentication method. B: B is wrong because a camera engineer is not always required. D: D is wrong because the defendant's admission is not necessary.
lb_rule_reference: FRE 901(b)(9) / process or system authentication
lb_student_diagnostic: Tests process/system authentication for surveillance video.
