Question: A retailer orally ordered 700 plain wooden shelves from Solomon, a manufacturer. Solomon already sold the same plain shelves in his ordinary business. After the retailer repudiated, Solomon argued that he had set aside 700 shelves for the retailer and therefore the goods were “specially manufactured.” No writing was signed. Does the specially manufactured goods exception apply?
Answer A: Yes, because Solomon selected particular units for the retailer.
Answer B: Yes, because any large quantity of goods becomes specially manufactured once set aside.
Answer C: No, because plain shelves suitable for ordinary resale are not specially manufactured goods merely because Solomon earmarked them for the retailer.
Answer D: No, but only because Solomon had not yet delivered any shelves.
Correct Answer: C
Correct Answer Explanation: The specially manufactured goods exception requires goods made specially for the buyer that are not suitable for sale to others in the seller's ordinary course. Generic inventory or ordinary goods set aside for one buyer do not satisfy the exception merely because they are earmarked.
Wrong Answer Explanations: A: A is wrong because selecting units from ordinary inventory is not special manufacture. B: B is wrong because quantity alone does not make goods specially manufactured. D: D is wrong because delivery is not the test; suitability for ordinary resale and special manufacture are.
lb_rule_reference: UCC §2-201 / generic inventory failure
