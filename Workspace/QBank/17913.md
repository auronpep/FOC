Question: A diversity contract suit is filed in federal court in State A. The contract says State C law governs. State A's choice-of-law rules enforce some choice clauses but refuse others when State C has no substantial relationship to the dispute. How should the federal court decide whether State C law governs?
Answer A: Enforce State C law automatically because the contract names it
Answer B: Use State A's choice-of-law rules to determine the effect of the clause
Answer C: Use federal common law because contracts are interstate
Answer D: Use the plaintiff's preferred law because the plaintiff chose the forum
Correct Answer: B
Correct Answer Explanation: The federal diversity court applies the forum state's choice rules.
Wrong Answer Explanations: A: The choice clause matters, but Klaxon sends the court to State A's choice rules first. C: Diversity alone does not create federal choice rules. D: Party preference is not the rule of decision.
lb_rule_reference: Party preference does not replace Klaxon; the forum state's choice rules determine whether the clause controls.
