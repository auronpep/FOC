Question: A state requires all passenger vehicles to display a license plate bearing the state motto "Live for the State." A driver objects to displaying the ideological motto on his personal car and offers to cover only the motto while leaving the plate number visible. What is the driver's strongest argument?
Answer A: The requirement compels him to display an ideological message on his personal property
Answer B: The requirement is valid because government speech doctrine lets the state compel private display of any message
Answer C: The requirement is valid because license plates are a traditional public forum
Answer D: The requirement is invalid only if the driver proves the motto is false
Correct Answer: A
Correct Answer Explanation: The government cannot force private individuals to serve as carriers for an ideological message in this way.
Wrong Answer Explanations: B: Government may speak for itself, but compelled private display raises a separate First Amendment problem. C: The issue is compelled speech, not a forum-access claim. D: Compelled ideological speech does not require a showing that the message is false.
lb_rule_reference: The government generally may not compel a private person to use personal property as a vehicle for an ideological message with which the person disagrees.
