Question: In a federal fraud trial, Esther testifies for the plaintiff. Before cross-examination and before any evidence attacking Esther's truthfulness, the plaintiff calls Naomi to testify that Esther has a reputation for honesty. The defendant objects. How should the court rule?
Answer A: Overrule the objection because credibility is always in issue once a witness testifies.
Answer B: Sustain the objection because truthful-character support is allowed only after the witness's character for truthfulness has been attacked.
Answer C: Overrule the objection because reputation is always a permitted character form.
Answer D: Sustain the objection only if Naomi also planned to describe specific truthful acts.
Correct Answer: B
Correct Answer Explanation: FRE 608(a) allows support for a witness's truthful character by reputation or opinion only after the witness's character for truthfulness has been attacked. Esther has not yet been attacked for truthfulness.
Wrong Answer Explanations: A: A is wrong because general credibility relevance does not allow premature bolstering. C: C is wrong because reputation is permitted only when support is otherwise allowed. D: D is wrong because the defect is timing and sequence, not only specific-act form.
lb_rule_reference: FRE 608(a) / support after attack only
lb_student_diagnostic: Tests attack-before-support sequencing for truthfulness evidence.
