Subtopic: Law Applied by Federal Courts (Erie)
Outline: Erie Doctrine
Question: A state statute says, "This procedural rule governs all lawsuits for state consumer claims." The rule limits a claimant's right to recover statutory damages unless a pre-suit demand is sent. A diversity plaintiff argues that because the state called the rule procedural, federal court must ignore it automatically. Is the plaintiff's label-based argument correct?
Answer A: Yes, because state labels are conclusive under Erie
Answer B: Yes, because federal courts ignore all state rules about lawsuits
Answer C: No, because the federal court must independently analyze whether the rule is substantive under Erie and whether any federal directive controls
Answer D: No, because every state rule always applies
Correct Answer: C
Correct Answer Explanation: Erie analysis turns on function, federal directives, and twin aims, not labels alone.
Wrong Answer Explanations: A: The state label is relevant context but not controlling. B: Federal courts in diversity apply state substantive rules. D: A valid federal directive on point can displace state procedure.
lb_rule_reference: The federal court independently applies Erie/Hanna analysis rather than accepting the state label.
