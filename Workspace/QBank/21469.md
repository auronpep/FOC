Question: Hundreds of pension-plan participants sue the plan administrator, each seeking an order requiring a different method for calculating the same plan benefit. Separate suits could subject the administrator to incompatible court orders about how to run the plan. Which Rule 23(b) category best fits this concern?
Answer A: Rule 23(b)(1), because separate actions risk incompatible standards of conduct for the administrator
Answer B: Rule 23(b)(2), because every class action involving a plan is injunctive
Answer C: Rule 23(b)(3), because any class with many members must be a damages class
Answer D: No class category can apply when separate actions are possible
Correct Answer: A
Correct Answer Explanation: The risk is not merely many damages claims; it is incompatible commands governing the defendant's conduct.
Wrong Answer Explanations: B: The specific risk of incompatible standards points to Rule 23(b)(1). C: Numerosity does not dictate the Rule 23(b) category. D: Rule 23(b)(1) exists because separate actions can create specified risks.
lb_rule_reference: Rule 23(b)(1) certification may be proper when separate actions would create a risk of inconsistent or varying adjudications establishing incompatible standards of conduct for the opposing party.
