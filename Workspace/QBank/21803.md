MBE Subjects (1 of 7): Torts
Subtopic: Other Torts
Outline: Defamation
Question: A former manager was asked for a confidential reference about an assistant. The manager falsely told the prospective employer that the assistant had stolen cash, even though the manager knew an audit had cleared the assistant. The manager then forwarded the accusation to an unrelated trade association list "so everyone knows." Is the assistant likely to overcome the manager's qualified privilege defense in a defamation claim?
Answer A: No, because job references are always absolutely privileged
Answer B: Yes, because the manager knowingly made a false statement and excessively published it
Answer C: No, because privilege applies only if the statement is true
Answer D: Yes, but only because the statement was written rather than spoken
Correct Answer: B
Correct Answer Explanation: Any qualified privilege for a reference was lost by knowing falsity and by spreading the accusation beyond the common-interest audience.
Wrong Answer Explanations: A: Job references are generally protected, if at all, by qualified privilege, not absolute privilege. C: Privilege can protect some false statements if properly made, but this qualified privilege was abused. D: The dispositive issue is loss of qualified privilege, not the written medium.
lb_rule_reference: A qualified privilege for common-interest communications can be lost by knowing falsity, malice, excessive publication, or speaking outside the privilege's scope.
