Outline: Reliance damages
Question: Barnabas contracted to build display booths for Chloe for $50,000. Before Chloe repudiated, Barnabas bought $14,000 of lumber for the booths. After the repudiation, Barnabas used $5,000 worth of the lumber on another job and sold $2,000 worth. Barnabas cannot prove expected profit with reasonable certainty. What is Barnabas's reliance loss for the lumber?
Answer A: $14,000, because the lumber was bought for Chloe's contract.
Answer B: $12,000, because only the resale proceeds count as an offset.
Answer C: $7,000, the purchase price minus the value used elsewhere and resale proceeds.
Answer D: $0, because Barnabas did not complete the booths.
Correct Answer: C
Correct Answer Explanation: Reliance damages are reduced by salvage or value retained. Barnabas spent $14,000, but used $5,000 worth elsewhere and sold $2,000 worth, so the unrecovered reliance loss is $7,000.
Wrong Answer Explanations: A: A is wrong because it ignores both offsets. B: B is wrong because value used on another job is also a retained benefit. D: D is wrong because completion is not required for reliance damages after the other party's repudiation.
