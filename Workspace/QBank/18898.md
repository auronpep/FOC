Outline: Counterclaims
Question: A driver sues another driver in federal court for negligence arising from a two-car collision. The defendant believes the plaintiff was actually at fault and that the same collision caused the defendant's own injuries. The defendant answers but does not assert any claim for those injuries. After judgment, the defendant files a new federal suit against the plaintiff based on the same collision. What is the plaintiff's strongest response to the new suit?
Answer A: The new suit is allowed because counterclaims are always optional
Answer B: The new suit is allowed because the defendant denied liability in the first suit
Answer C: The new suit is barred only if the first case was in state court
Answer D: The claim should have been pleaded as a compulsory counterclaim in the first action
Correct Answer: D
Correct Answer Explanation: The defendant's injury claim arose from the same collision as the plaintiff's negligence claim. It was a compulsory counterclaim and should have been pleaded in the first action.
Wrong Answer Explanations: A: Claims arising from the same transaction or occurrence are generally compulsory under Rule 13(a). B: A denial is not the same as asserting an affirmative claim for the defendant's own injuries. C: The stated federal action invokes Rule 13(a). The compulsory-counterclaim issue exists in federal court.
lb_rule_reference: Rule 13(a) requires a pleading to state as a counterclaim any claim the pleader has against an opposing party if it arises out of the same transaction or occurrence and does not require adding a party outside the court's jurisdiction.
