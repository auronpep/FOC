Question: Before suit was filed, an investigator for defendant Solomon recorded a statement from eyewitness Jonah about a store accident. After suit begins, Jonah asks Solomon for a copy of Jonah's own recorded statement. Solomon refuses, asserting work product and demanding that Jonah show substantial need. How should the court rule?
Answer A: Deny the request because all recorded witness statements are opinion work product.
Answer B: Deny the request unless Jonah proves that he cannot remember the accident.
Answer C: Order production because a person may obtain that person's own previous statement about the action or its subject matter without the substantial-need showing.
Answer D: Order production only if Jonah was a party when he gave the statement.
Correct Answer: C
Correct Answer Explanation: Rule 26(b)(3)(C) allows a party or other person to obtain, on request and without the substantial-need showing, that person's own previous statement about the action or its subject matter. The decisive axis is own-statement entitlement.
Wrong Answer Explanations: A: A is wrong because This overclassifies a recorded statement as opinion work product. B: B is wrong because Memory loss is not the prerequisite for obtaining one's own previous statement. D: A is wrong because This overclassifies a recorded statement as opinion work product. B is wrong because Memory loss is not the prerequisite for obtaining one's own previous statement. C is wrong because Correct answer D is wrong because The rule applies to a party or other person, not only someone who was already a party.
