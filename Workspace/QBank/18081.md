Outline: Plea negotiations and withdrawn plea offers
Question: After arrest, but before any prosecutor was involved, a suspect told the arresting officer, “If you drop the gun charge, I will plead guilty to possession.” The officer had no authority to negotiate pleas and made no promise. At trial, the prosecution offers the statement. The suspect objects under Rule 410 only. How should the court rule on that objection?
Answer A: Sustain it because any mention of pleading guilty is protected.
Answer B: Overrule it because the statement was not made during plea discussions with an attorney for the prosecuting authority.
Answer C: Sustain it because statements to police are always plea discussions.
Answer D: Overrule it only because the suspect did not have counsel present.
Correct Answer: B
Correct Answer Explanation: Rule 410 protects plea discussions with an attorney for the prosecuting authority, along with specified plea proceedings and plea types. A unilateral bargaining statement to an arresting officer with no prosecutorial plea authority does not trigger Rule 410 on these facts. Other constitutional objections are not presented.
Wrong Answer Explanations: A: A is wrong because Rule 410 is not triggered by every reference to a guilty plea. C: A is wrong because Rule 410 is not triggered by every reference to a guilty plea. B is wrong because Correct answer C is wrong because Police questioning is not automatically a prosecutorial plea discussion. D is wrong because Counsel presence is not the decisive missing element; prosecuting-authority involvement is. D: D is wrong because Counsel presence is not the decisive missing element; prosecuting-authority involvement is.
