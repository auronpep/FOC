Outline: Diversity Jurisdiction
Question: Named Plaintiff, a citizen of State A, files a putative class action in federal court against Defendant, a citizen of State B, seeking more than the jurisdictional amount for Named Plaintiff's claim. The proposed class includes many absent members, including some State B citizens. No party invokes CAFA. Do the absent State B class members automatically destroy ordinary diversity jurisdiction?
Answer A: Yes, because every absent class member must be diverse from every defendant
Answer B: Yes, because class actions can never be heard under diversity jurisdiction
Answer C: No, absent class members do not automatically destroy ordinary diversity when the named representative is diverse
Answer D: No, but only because federal-question jurisdiction always exists in class actions
Correct Answer: C
Correct Answer Explanation: The named representative's citizenship is the relevant class-side citizenship for ordinary diversity.
Wrong Answer Explanations: A: For ordinary diversity class actions, the citizenship of named representatives controls the diversity analysis. B: Class actions can proceed in federal court when jurisdictional requirements are satisfied. D: Class status does not create federal-question jurisdiction.
lb_rule_reference: For ordinary diversity jurisdiction in a class action outside CAFA, the citizenship of named class representatives is used for complete diversity.
