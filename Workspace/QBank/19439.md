Question: Congress offers new transportation-safety grants to states that adopt a clearly stated bridge-inspection standard related to the funded bridge program. A state may decline the new funds and keep its existing federal funding. The state argues the offer commandeers its legislature. What is the best analysis?
Answer A: The offer is not commandeering if it is a valid spending condition that leaves the state a real choice
Answer B: Any federal funding condition is commandeering because it pressures the state
Answer C: The condition is valid because all state consent is automatic when Congress spends
Answer D: The offer is invalid unless Congress separately regulates private bridge users under the Commerce Clause
Correct Answer: A
Correct Answer Explanation: Conditional spending can induce state action without directly commanding state legislation when spending limits are satisfied.
Wrong Answer Explanations: B: Valid spending inducements are permitted; only coercive or otherwise invalid conditions fail. C: Spending conditions must still be clear, related, noncoercive, and otherwise constitutional. D: Spending power can be an independent route for federal programs.
lb_rule_reference: A valid condition on federal funds can encourage state action without commandeering, but it must satisfy spending-power limits such as clarity, relatedness, no independent constitutional bar, and no coercion.
