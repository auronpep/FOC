Question: In a federal assault trial, Caleb's lawyer asks an eyewitness, “How certain were you that the person you saw was Caleb?” The witness answers, “I was certain because I passed a police lie-detector test about it.” Caleb immediately moves to strike the reference to the lie-detector test. How should the court rule?
Answer A: Deny the motion because Caleb's lawyer opened the door by asking about certainty.
Answer B: Grant the motion to strike the reference to the lie-detector test because it was volunteered and improperly bolsters the witness through inadmissible matter.
Answer C: Deny the motion because all answers about certainty are automatically admissible in full.
Answer D: Grant the motion and bar the witness from giving any further identification testimony.
Correct Answer: B
Correct Answer Explanation: The lawyer asked about the witness's certainty. The witness's reference to passing a lie-detector test was volunteered and improperly bolstered credibility through inadmissible matter. The court should strike the reference while allowing otherwise proper identification testimony.
Wrong Answer Explanations: A: A is wrong because asking about certainty does not open the door to an inadmissible lie-detector reference. C: C is wrong because certainty testimony can contain improper volunteered matter. D is overbroad because the improper reference does not necessarily bar all identification testimony. D: A is wrong because asking about certainty does not open the door to an inadmissible lie-detector reference. C is wrong because certainty testimony can contain improper volunteered matter. D is overbroad because the improper reference does not necessarily bar all identification testimony.
