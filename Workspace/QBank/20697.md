Outline: Preemption and Consent
Question: Congress validly regulates private manufacturers of medical devices and provides that any conflicting state labeling requirement is without effect. A state argues that the federal statute commandeers the state because it prevents the state from enforcing its own labels. What is the best response?
Answer A: The statute is ordinary preemption of conflicting state law, not commandeering, because it regulates private manufacturers rather than ordering the state to administer a federal program
Answer B: The statute commandeers the state because every preemptive law tells the state what to do
Answer C: The statute is invalid because Congress can never preempt state health laws
Answer D: The statute is valid only if states voluntarily consent to preemption
Correct Answer: A
Correct Answer Explanation: Valid federal regulation can displace conflicting state law under the Supremacy Clause.
Wrong Answer Explanations: B: Preemption and commandeering are distinct; preemption displaces state regulation, while commandeering commands state governance. C: Valid federal law can preempt state law even in traditional state fields. D: Valid federal law is supreme without state consent.
lb_rule_reference: A valid federal law regulating private actors may preempt conflicting state law; preemption is not the same as commandeering state governments.
