Question: Nia tells Chris, "If the night guard is alone when you pass the office, break in and take the payroll laptop." Nia gives Chris the office code. Chris refuses and leaves. Nia is charged with solicitation to commit burglary. Which statement is most accurate?
Answer A: Nia is not guilty because the request was conditional
Answer B: Nia is guilty because she intentionally asked Chris to commit burglary if the stated condition occurred
Answer C: Nia is not guilty because Chris did not agree
Answer D: Nia is guilty only if the guard was actually alone that night
Correct Answer: B
Correct Answer Explanation: Nia communicated a request for Chris to commit a burglary under specified circumstances and supplied the access code. Chris's refusal does not matter.
Wrong Answer Explanations: A: A conditional request can still intentionally seek criminal conduct if the condition occurs. C: Solicitation does not require agreement by the solicited person. D: The solicitation is complete when the request is communicated with the required intent; the condition need not occur.
lb_rule_reference: A conditional request can still be solicitation if the defendant intentionally asks another person to commit a crime if the stated condition occurs.
