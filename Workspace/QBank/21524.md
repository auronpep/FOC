Question: A tenant falls on a broken exterior stairway. The landlord denies that it controlled the stairway, claiming it belonged to a neighboring building. The tenant offers evidence that, the day after the fall, the landlord sent its own maintenance crew to repair that stairway. The tenant offers the evidence only to prove control, not negligence. How should the court rule?
Answer A: Exclude the evidence because subsequent repairs are never admissible.
Answer B: Exclude the evidence because the repair is relevant only if it proves negligence.
Answer C: Admit the evidence for the limited purpose of proving control if control is disputed and other rules are satisfied.
Answer D: Admit the evidence for all purposes because the landlord denied control.
Correct Answer: C
Correct Answer Explanation: Rule 407 permits evidence of subsequent remedial measures for another purpose, such as proving ownership or control, if disputed. The tenant offers the repair for control only, so limited admission is proper. The decisive axis is permitted purpose plus limiting scope.
Wrong Answer Explanations: A: A is wrong because This is remedial-measure absolutism. Rule 407 has permitted purposes. B: B is wrong because The repair can be relevant to control independent of negligence. D: A is wrong because This is remedial-measure absolutism. Rule 407 has permitted purposes. B is wrong because The repair can be relevant to control independent of negligence.
