Outline: Diversity Jurisdiction
Question: A citizen of Ohio sues a citizen of Texas in federal court under diversity jurisdiction. The state in which the federal court sits requires service within 45 days and says dismissal is mandatory if service is late. Federal Rule 4(m) gives the plaintiff 90 days for service. The plaintiff serves the defendant on day 70. The defendant moves to dismiss under the state rule. Should the federal court dismiss for untimely service?
Answer A: Yes, because Erie requires state procedural deadlines in every diversity case
Answer B: Yes, because the state rule is outcome determinative
Answer C: No, because Federal Rule 4(m) directly controls service timing and is valid
Answer D: No, but only because diversity cases never use state law
Correct Answer: C
Correct Answer Explanation: A valid Federal Rule on point governs in federal court under Hanna even when a state procedural rule would produce a different result.
Wrong Answer Explanations: A: Erie does not start with outcome or state labels when a valid Federal Rule directly answers the issue. B: Outcome effect is not the first step when Rule 4(m) is directly on point. D: Diversity cases use state substantive law; the error is ignoring the federal-rule fork.
lb_rule_reference: Under Hanna, first ask whether a federal statute or Federal Rule directly controls the issue and is valid under the Rules Enabling Act and Constitution.
