Subtopic: Relevancy and Excluding Relevant Evidence
Outline: Laying a Foundation
Question: In a federal wage case, the employer offers electronic badge-swipe records to show when Moses entered the building. The security supervisor, Joel, testifies that the badge system records each employee's unique badge number and timestamp, that the system was functioning normally, and that the report was generated from the system's regular database. Moses objects that no one personally watched him swipe his badge. How should the court rule on authentication?
Answer A: Admit the report because testimony describing the electronic process and showing that it produces accurate results can authenticate the data.
Answer B: Exclude the report because an eyewitness must personally see each badge swipe.
Answer C: Exclude the report unless the programmer who wrote the software testifies.
Answer D: Admit the report as conclusive proof that Moses was inside the building.
Correct Answer: A
Correct Answer Explanation: Evidence about a process or system may authenticate an item if it describes the system and shows that it produces an accurate result. Joel's testimony about the badge system supplies that foundation. The report's weight remains for the factfinder.
Wrong Answer Explanations: B: B is wrong because machine-generated data can be authenticated by process evidence. C: C is wrong because the programmer is not always required. D: D is wrong because authentication does not make the report conclusive.
lb_rule_reference: FRE 901(b)(9) / process or system / data report
lb_student_diagnostic: Tests electronic-process authentication and separates admissibility from weight.
