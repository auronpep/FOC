Subtopic: Jurisdiction and Venue
Outline: Venue
Question: A defendant first files a timely Rule 12 motion challenging venue. The court denies the motion. The defendant then answers and asserts that the complaint fails to state a claim. The plaintiff argues that the Rule 12(b)(6) defense was waived because it was not included in the first Rule 12 motion. Is the plaintiff's waiver argument correct?
Answer A: Yes, because every Rule 12 defense is waived if omitted from the first motion
Answer B: Yes, because venue and failure to state a claim must always be joined
Answer C: No, because Rule 12(b)(6) can be raised later in an answer, Rule 12(c) motion, or at trial
Answer D: No, because failure to state a claim can be raised only for the first time on appeal
Correct Answer: C
Correct Answer Explanation: Rule 12(h)(2) preserves failure to state a claim beyond the first pre-answer motion. The defendant did not waive it merely by omitting it from the venue motion.
Wrong Answer Explanations: A: The waiver rule is not identical for all Rule 12 defenses. Failure to state a claim is preserved under Rule 12(h)(2). B: Venue is in the waivable group, but Rule 12(b)(6) is preserved for later listed stages. The plaintiff's all-or-nothing consolidation theory is too broad. D: Rule 12(h)(2) allows specific later trial-court stages. This answer overstates and misstates the timing.
lb_rule_reference: Failure to state a claim under Rule 12(b)(6) may be raised in a pleading, by Rule 12(c) motion, or at trial; it is not waived merely because it was omitted from the first Rule 12 motion.
