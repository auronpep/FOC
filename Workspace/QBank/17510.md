Subtopic: Jurisdiction and Venue
Outline: Personal Jurisdiction
Question: Vendor, a State A software company, signs a five-year implementation contract with Customer, a State B corporation. Vendor sends engineers to State B for installation, trains Customer's State B employees, agrees to provide monthly remote support to State B, and chooses State B law in the contract. Customer sues Vendor in State B over failures in that implementation. What is the best personal-jurisdiction analysis?
Answer A: Jurisdiction is impossible because a contract with a forum resident can never create minimum contacts
Answer B: Jurisdiction likely exists because Vendor deliberately created continuing State B contacts related to the implementation claim
Answer C: Jurisdiction exists solely because the contract chooses State B law
Answer D: Jurisdiction fails unless Vendor is incorporated or headquartered in State B
Correct Answer: B
Correct Answer Explanation: Vendor's installation, training, support, and related claim create a purposeful forum link beyond a bare contract.
Wrong Answer Explanations: A: The facts show continuing State B obligations, forum performance, and a claim tied to those contacts. C: Choice of law may support purposeful availment, but it is not the same as a forum-selection clause or automatic consent. D: This is a specific-jurisdiction case based on claim-linked forum performance.
lb_rule_reference: A contract alone does not automatically create personal jurisdiction, but forum choice-of-law, forum negotiations, continuing obligations, and forum performance can support purposeful availment when tied to the claim.
