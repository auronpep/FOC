Subtopic: Relevancy and Excluding Relevant Evidence
Outline: Definition
Question: A burglar left a muddy footprint near a broken window. The print was from a size-nine hiking boot. Police later found size-nine hiking boots in Joshua's closet. Joshua objects that size nine is common and the boots cannot be tied to the exact footprint. How should the court rule?
Answer A: Exclude the boots, because common shoe size evidence is never relevant.
Answer B: Exclude the boots unless the prosecution proves the boots made the exact print.
Answer C: Admit the boots, because they have some tendency to connect Joshua to the burglary; the commonness of the size affects weight.
Answer D: Admit the boots only if Joshua admits wearing them that night.
Correct Answer: C
Correct Answer Explanation: The boots have some tendency to connect Joshua to the footprint and burglary. The link is weak because the size is common, but weak proof may still be relevant.
Wrong Answer Explanations: A: A is wrong because common evidence can still have some probative value. B: B is wrong because exact-source proof is not required for threshold relevance. D: D is wrong because the defendant's admission is not required for relevance.
lb_rule_reference: FRE 401 / FRE 402
lb_student_diagnostic: The trap is excluding weak physical-link evidence because it is not distinctive enough.
