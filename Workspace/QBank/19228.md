Outline: Marital Communications Privilege
Question: Paul sent his wife Lydia a private text message during their marriage: “I moved the cash to the storage unit.” No one else received the text. In a later federal proceeding, the government subpoenas Lydia to authenticate and read the text. Paul asserts marital communications privilege. Which ruling is most proper?
Answer A: Overrule the objection, because the privilege protects only spoken words.
Answer B: Sustain the objection, because a confidential written message between spouses during marriage can be a protected marital communication.
Answer C: Overrule the objection, because a text message is a document rather than a communication.
Answer D: Sustain the objection only if Lydia refuses to testify.
Correct Answer: B
Correct Answer Explanation: The communication privilege turns on confidential marital communication, not whether the words were spoken or written. A private text from Paul to Lydia during the marriage qualifies if the other elements are met. The decisive axis is communication substance and confidentiality.
Wrong Answer Explanations: A: A is wrong because This creates a false oral-only limitation. Written private marital communications may be protected. C: C is wrong because A document can embody a privileged communication; document format does not defeat the privilege. D: D is wrong because Lydia's willingness does not eliminate Paul's communication privilege on these facts.
lb_rule_reference: FRE 501 / written confidential marital communication
lb_student_diagnostic: Student is confusing evidence format with the protected communication object.
