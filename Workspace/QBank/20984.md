Question: Police have probable cause to believe a stolen flat-screen television is in a van. They search the van without a warrant. In the glove box, they open a pill bottle too small to contain the television and find narcotics. Does the automobile exception justify opening the pill bottle?
Answer A: Yes, because probable cause to search a vehicle allows police to open every container inside
Answer B: No, because the pill bottle could not contain the object for which police had probable cause
Answer C: Yes, but only because the van was mobile
Answer D: No, because the automobile exception never permits container searches
Correct Answer: B
Correct Answer Explanation: The exception allowed a search where the stolen television could be hidden, not a general search of tiny containers.
Wrong Answer Explanations: A: Container scope follows the object of probable cause. A pill bottle cannot hold a television. C: Mobility does not erase the object-container scope limit. D: Containers can be searched when they could conceal the object of probable cause.
lb_rule_reference: The automobile exception permits search of containers in the vehicle only where the object of probable cause could be found.
