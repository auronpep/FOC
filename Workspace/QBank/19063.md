Question: Sarah owned Lot 1, which benefited from an express easement over Lot 2. Moses then bought both Lot 1 and Lot 2 in fee simple absolute. While Moses owned both lots, he used the old route across Lot 2. Moses later sold Lot 1 to Ruth. Ruth's deed did not mention any easement over Lot 2. Does the old express easement automatically revive when Moses sells Lot 1?
Answer A: No, because the easement was extinguished by merger when Moses owned both the dominant and servient estates in fee simple, and it does not automatically revive on later severance.
Answer B: Yes, because using the old route during unity of ownership preserves the express easement.
Answer C: Yes, because merger applies only to mortgages, not easements.
Answer D: No, but only because all appurtenant easements terminate whenever the dominant estate is sold.
Correct Answer: A
Correct Answer Explanation: An easement may terminate by merger when the same person acquires the dominant and servient estates in the same ownership and estate. Once extinguished, the old easement does not automatically revive when the parcels are later separated, though a new easement might be created by grant or implication if facts support it.
Wrong Answer Explanations: B: B is wrong because using one's own land during unity of ownership does not preserve a separate easement. C: C is wrong because merger can terminate easements. D: D is wrong because appurtenant easements normally pass with the dominant estate; the issue is prior merger.
lb_rule_reference: Termination by merger
lb_student_diagnostic: The recurring trap is assuming a familiar access route survives even after complete unity of ownership extinguishes it.
