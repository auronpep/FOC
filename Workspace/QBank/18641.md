Subtopic: Presentation of Evidence
Outline: Materiality and probative value
Question: Isaac sues a store after slipping on water near the store's entrance in Denver. To prove that the floor was wet, Isaac offers a weather report showing that it rained in Miami that same afternoon. Isaac offers no evidence connecting the Miami weather to the Denver store. How should the court rule?
Answer A: Admit the report because any weather report has some relevance to whether a floor was wet.
Answer B: Admit the report because weather evidence is always background evidence.
Answer C: Exclude the report because it lacks a logical connection to a consequential fact in this case.
Answer D: Exclude the report only if the store proves it was sunny in Denver.
Correct Answer: C
Correct Answer Explanation: Evidence must have some logical tendency to affect a consequential fact. Rain in an unrelated city, with no link to the store or local conditions, does not make the wet-floor fact more or less probable.
Wrong Answer Explanations: A: A is wrong because relevance requires a link to this case, not just a general topic connection. B: B is wrong because background evidence must still help explain a consequential matter. D: D is wrong because the opponent need not prove contrary local weather to defeat irrelevant remote weather evidence.
lb_rule_reference: FRE 401
lb_student_diagnostic: Student mistakes topic similarity for a probative link.
