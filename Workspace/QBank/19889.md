Question: For 14 summers, Hannah openly crossed Samuel's lakeside strip to reach a boat dock. The lake froze each winter, and no one used the dock during winter. Hannah never asked Samuel for permission. The jurisdiction's prescriptive period is 10 years. Samuel argues that Hannah's use was not continuous because it occurred only in summer. Which is the best result?
Answer A: Hannah may satisfy continuity because seasonal use can be continuous when it matches the normal use of the claimed easement.
Answer B: Hannah cannot satisfy continuity because prescriptive use must occur every day of the year.
Answer C: Hannah owns the lakeside strip because seasonal use automatically ripens into title.
Answer D: Hannah has only a license because all recreational access is presumed permissive.
Correct Answer: A
Correct Answer Explanation: Continuity is measured by the kind of use claimed. Seasonal use may be continuous when it is the normal and expected pattern for the property use, such as summer access to a dock on a lake that freezes in winter.
Wrong Answer Explanations: B: B is wrong because daily year-round use is not required. C: C is wrong because the claim is a use right, not title. D: D is wrong because recreational purpose alone does not prove permission on these facts.
lb_rule_reference: Seasonal use may be continuous
lb_student_diagnostic: The repair signal is overreading continuity as constant physical use rather than use consistent with the easement type.
