Question: A state requires all trucks using its highways to carry a safety reflector visible at night. The rule applies equally to in-state and out-of-state carriers. Out-of-state carriers must spend modest amounts to add the reflector, and accident data supports the safety benefit. Which test should govern?
Answer A: Strict scrutiny because interstate carriers must spend money
Answer B: Pike balancing, with the law upheld unless the interstate burden is clearly excessive
Answer C: Automatic invalidity because all truck regulations burden interstate commerce
Answer D: No DCC analysis because safety rules are immune from review
Correct Answer: B
Correct Answer Explanation: The rule is evenhanded, safety-based, and imposes only incidental costs.
Wrong Answer Explanations: A: A nondiscriminatory incidental burden uses Pike balancing, not near-per-se invalidity. C: DCC does not invalidate every state highway safety rule. D: Safety matters in the balance; it does not eliminate DCC analysis.
lb_rule_reference: A nondiscriminatory law that incidentally burdens interstate commerce is upheld unless the burden on interstate commerce is clearly excessive in relation to the putative local benefits.
