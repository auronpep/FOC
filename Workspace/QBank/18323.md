Question: Police obtain a valid warrant to search Nina's apartment for stolen diamond rings. In the bedroom, officers open a jewelry box on the dresser and find the rings. Nina argues the warrant did not separately list the jewelry box. Was opening the jewelry box within the warrant's scope?
Answer A: Yes, because diamond rings could reasonably be found inside a jewelry box
Answer B: No, because every closed container requires a separate warrant by name
Answer C: No, because jewelry boxes are never searchable for stolen property
Answer D: Yes, because a warrant for rings also authorizes searching every digital file in the apartment
Correct Answer: A
Correct Answer Explanation: The warrant described the items to be seized. Officers may search containers where those small items could reasonably be hidden.
Wrong Answer Explanations: B: A valid warrant for small items permits searching containers where those items may be located. C: Personal privacy does not defeat a valid warrant whose listed items could fit there. D: The scope is limited to places where rings could reasonably be found. Digital files would not fit that object.
lb_rule_reference: A valid warrant authorizes police to search places and containers where the objects described in the warrant could reasonably be located.
