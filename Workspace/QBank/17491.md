Subtopic: Jurisdiction and Venue
Outline: Domicile
Question: Plaintiff lived in State A for ten years. Two weeks before filing suit, Plaintiff rented an apartment in State B for a six-month temporary assignment and told friends he planned to return to State A when the assignment ended. Plaintiff sues Defendant, a State A citizen, invoking diversity jurisdiction and listing his current State B address. Is Plaintiff a State B citizen for diversity purposes?
Answer A: Yes, because current residence always equals domicile
Answer B: Yes, because domicile changes whenever a person rents an apartment in another state
Answer C: No, not on these facts; the temporary assignment does not show intent to remain in State B indefinitely
Answer D: No, but only because Defendant objects before answering
Correct Answer: C
Correct Answer Explanation: Plaintiff is physically present in State B, but the stated plan to return to State A undercuts intent to make State B his domicile.
Wrong Answer Explanations: A: Residence is evidence but not the rule. Domicile requires presence plus intent to remain indefinitely. B: A temporary stay with intent to return does not necessarily change domicile. D: Subject-matter jurisdiction does not depend on a timely personal-jurisdiction-style objection.
lb_rule_reference: An individual's state citizenship is domicile, requiring physical presence in a state and intent to remain indefinitely.
