Outline: Invasion of privacy
Question: A landlord falsely told one prospective tenant that a prior tenant had "left because the apartment was haunted." The prior tenant was not named publicly, no advertisement repeated the statement, and no one else heard it. Is the prior tenant likely to prevail on a false light claim against the landlord?
Answer A: Yes, because the statement created a false impression about the tenant
Answer B: No, because the false statement was not publicized broadly
Answer C: Yes, because false light requires only publication to one third party
Answer D: No, because false light only applies to commercial advertisements
Correct Answer: B
Correct Answer Explanation: The landlord made a private statement to one person, which lacks the publicity required for false light.
Wrong Answer Explanations: A: False light requires widespread publicity; a one-to-one statement is not enough. C: False light requires publicity to the public or many people, not merely one third party. D: False light can apply outside advertisements; this claim fails because publicity is missing.
lb_rule_reference: False light requires publicity to the public or many people; a private one-to-one falsehood is not enough.
