Question: In a civil deposition, Nathan is asked, “Did you personally destroy the audit report after receiving the subpoena?” A truthful answer could expose Nathan to criminal obstruction charges. Nathan invokes the Fifth Amendment. How should the court rule on the invocation?
Answer A: Reject it, because the case is civil rather than criminal.
Answer B: Allow it, because the question calls for testimonial information that could incriminate Nathan.
Answer C: Reject it, because the audit report is relevant and probative.
Answer D: Allow it only if Nathan has already been indicted.
Correct Answer: B
Correct Answer Explanation: The Fifth Amendment privilege may be invoked in civil proceedings when the answer would be compelled, testimonial, and incriminating. Nathan is being asked for an admission of potentially criminal obstruction. The decisive axis is testimonial incrimination, not case type.
Wrong Answer Explanations: A: A is wrong because This denies the privilege merely because the proceeding is civil. The privilege can apply outside criminal trials. C: C is wrong because Relevance does not override a valid self-incrimination privilege. D: D is wrong because A witness need not wait for an indictment if there is a real risk of incrimination.
lb_rule_reference: Fifth Amendment / compelled testimonial incrimination
lb_student_diagnostic: Student is treating the Fifth Amendment as criminal-trial-only or letting relevance defeat privilege.
