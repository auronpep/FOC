Question: A Nevada citizen sues an Oregon citizen in federal court. The complaint asserts a $50,000 contract claim and a separate $30,000 defamation claim against the same defendant. The claims are unrelated but both are asserted by the same plaintiff against the same defendant. Is the amount-in-controversy requirement satisfied?
Answer A: No, because unrelated claims can never be aggregated
Answer B: No, because each claim must independently exceed $75,000
Answer C: Yes, because one plaintiff may aggregate the $50,000 and $30,000 claims against one defendant
Answer D: Yes, but only if the claims arise from the same transaction
Correct Answer: C
Correct Answer Explanation: The aggregated amount is $80,000, which exceeds the threshold.
Wrong Answer Explanations: A: One plaintiff may aggregate unrelated claims against one defendant. B: The single plaintiff's claims against the same defendant can be combined. D: Same transaction is not required for one plaintiff's aggregation against one defendant.
lb_rule_reference: A single plaintiff can aggregate all claims against a single defendant, related or unrelated, for amount in controversy.
