Question: A recorded subdivision declaration gives the owners of Lots 1, 2, 3, and 4 “the right to use the private lane located on Lot 5 for access to the public road.” Miriam buys Lot 3. John buys Lot 5 and argues that the lane right is personal to the original lot buyers. What is the best classification of the lane right?
Answer A: An appurtenant easement benefiting Lots 1 through 4 and burdening Lot 5.
Answer B: An easement in gross because several people may use the lane.
Answer C: A revocable license because each later buyer did not receive a new signed permission letter.
Answer D: A profit because road access increases the value of Lots 1 through 4.
Correct Answer: A
Correct Answer Explanation: A right to use a lane for access can be appurtenant to multiple benefited parcels. Lots 1 through 4 are the dominant estates, and Lot 5 is the servient estate. The right is not personal merely because multiple owners may use it.
Wrong Answer Explanations: B: B is wrong because multiple users do not make a right in gross when each right benefits a parcel. C: C is wrong because appurtenant easements can pass to later lot owners. D: D is wrong because increased value is not resource removal.
lb_rule_reference: Multiple appurtenant easements / shared lane
