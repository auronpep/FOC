Outline: Creation
Question: Joshua owned Lot A. Caleb owned neighboring Lot B. The lots were never commonly owned. For fifteen years, Caleb allowed Joshua to cross Lot B to reach a fishing pond, saying, “You may use the path as long as you close the gate.” Joshua always closed the gate. Joshua later sold Lot A to Hannah, who claimed both an implied easement by prior use and a prescriptive easement over Lot B. What is the best result?
Answer A: Hannah has an implied easement by prior use because the path existed before she bought Lot A.
Answer B: Hannah has a prescriptive easement because the use lasted more than ten years.
Answer C: Hannah has title to the path because Joshua used it continuously.
Answer D: Hannah likely has neither claimed easement because the parcels were never severed from common ownership and the use was permissive.
Correct Answer: D
Correct Answer Explanation: The implied-prior-use route requires common ownership and severance, which never existed. The prescriptive route requires adverse use, and Caleb's permission defeated adversity. Hannah therefore fails on both creation theories.
Wrong Answer Explanations: A: A is wrong because the path's existence does not replace common ownership and severance. B: B is wrong because long use with permission is not adverse. C: C is wrong because the claim is a use right, not title, and the facts do not show adverse possession. D is correct for the reasons above.
lb_rule_reference: No implication without severance; no prescription with permission
lb_student_diagnostic: The trap is stacking multiple easement labels without checking each creation source separately.
