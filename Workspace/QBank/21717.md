Question: Two neighbors settled a boundary dispute by consent judgment. The judgment stated: "The parties stipulate and intend this judgment to conclusively establish that the oak tree stands on Parcel A for all future disputes between them." A later suit between the same neighbors turns on ownership of that oak tree. How should the later court treat the ownership issue?
Answer A: It should ignore the consent judgment because settlements can never affect later litigation
Answer B: It should treat the ownership issue as potentially precluded because the consent judgment expressly made that issue binding
Answer C: It should apply issue preclusion to every factual statement discussed during settlement talks
Answer D: It should apply claim preclusion only if the second suit asks for the same remedy
Correct Answer: B
Correct Answer Explanation: The stated intent to conclusively resolve the specific issue supports preclusion between the same parties.
Wrong Answer Explanations: A: Consent judgments can have the preclusive effect the parties clearly intended. C: Preclusion turns on the judgment and intended determinations, not every negotiation statement. D: The question targets a specific issue, not a remedy-matching rule for claim preclusion.
lb_rule_reference: Issue preclusion after a consent judgment depends on whether the parties clearly intended a specific issue to be conclusively resolved.
