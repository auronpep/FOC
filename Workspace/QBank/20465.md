Outline: Refreshing recollection
Question: In a federal civil trial, Samuel testifies about a store inspection. On cross-examination, he says he met with counsel the night before trial and saw a folder of photographs, emails, and notes, but he also says he did not review the folder to refresh his memory and did not rely on it for his testimony. Opposing counsel asks for the entire folder under Rule 612. How should the court rule?
Answer A: Grant the request because any materials shown to a witness before trial must be produced.
Answer B: Grant the request because Rule 612 gives automatic access to all litigation-preparation files.
Answer C: Deny the request under Rule 612 absent a showing that Samuel used the folder to refresh memory for the purpose of testifying.
Answer D: Admit the entire folder as substantive evidence because Samuel saw it before trial.
Correct Answer: C
Correct Answer Explanation: Rule 612 is triggered when a witness uses a writing to refresh memory while testifying, or before testifying if justice requires access. The rule is not a wholesale discovery device for every material shown to a witness. Samuel says he did not use the folder to refresh memory for testimony, so Rule 612 does not itself require production on these facts.
Wrong Answer Explanations: A: A is wrong because pretrial exposure is not the same as refresh use. B: B is wrong because Rule 612 does not authorize fishing through all preparation files. D: D is wrong because seeing a folder before trial does not make it substantive evidence.
lb_rule_reference: FRE 612 / writing must be used to refresh memory for testimony
lb_student_diagnostic: Tests whether the writing was actually used to refresh memory for testimony.
