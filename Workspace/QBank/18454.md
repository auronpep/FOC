Question: In a federal civil negligence trial, Moses testifies for the defendant. The plaintiff seeks to impeach Moses with a three-year-old felony conviction for aggravated assault. Moses is not a party. Moses objects that the conviction does not involve dishonesty. How should the court rule?
Answer A: Exclude the conviction because only crimes involving dishonesty or false statement may be used to impeach a witness.
Answer B: Admit the conviction subject to Rule 403 because the crime was punishable by imprisonment for more than one year and Moses is not a criminal defendant.
Answer C: Admit the conviction only if the conviction's probative value outweighs its prejudicial effect to Moses.
Answer D: Exclude the conviction because violent crimes are never relevant to credibility.
Correct Answer: B
Correct Answer Explanation: For a nondefendant witness, a felony conviction may be used to attack character for truthfulness under FRE 609(a)(1)(A), subject to Rule 403. The conviction need not involve dishonesty if it was punishable by more than one year.
Wrong Answer Explanations: A: A is wrong because felony convictions not involving dishonesty may still be used under Rule 609(a)(1). C: C is wrong because the special probative-value-outweighs-prejudice test applies to a criminal defendant witness, not a nondefendant witness. D: D is wrong because Rule 609 permits some felony convictions even when the crime is not a false-statement crime.
lb_rule_reference: FRE 609(a)(1)(A) / felony conviction of nondefendant witness
lb_student_diagnostic: Tests nondefendant felony impeachment and the wrong balancing-standard trap.
