Outline: Refreshing recollection
Question: In a federal negligence trial, Joseph cannot remember the color of the traffic light when an accident occurred. His lawyer shows him a note Joseph wrote an hour after the accident. Joseph reads it and says, “I still do not remember the light, but I wrote this note when the event was fresh, and I knew it was accurate then.” The lawyer asks to have the note read to the jury. Opposing counsel objects. How should the court rule?
Answer A: Sustain the objection because the note was first shown to Joseph during testimony.
Answer B: Sustain the objection because a witness may use a writing only to refresh present memory, never as a recorded recollection.
Answer C: Overrule the objection and allow the note to be read if the court finds the recorded-recollection foundation satisfied; the note itself is received as an exhibit only if offered by the adverse party.
Answer D: Overrule the objection and admit the note as an exhibit because any writing used during testimony is automatically substantive evidence.
Correct Answer: C
Correct Answer Explanation: If a writing refreshes present memory, the witness testifies from memory under Rule 612. If the witness still cannot recall well enough, the proponent may use the recorded-recollection exception if its foundation is satisfied: the witness once knew the matter, made or adopted the record when fresh, and the record accurately reflected the witness's knowledge. The record may be read but received as an exhibit only if offered by the adverse party.
Wrong Answer Explanations: A: A is wrong because showing the note during testimony does not bar recorded-recollection use. B: B is wrong because recorded recollection is a separate hearsay exception. D: D is wrong because using a writing during testimony does not automatically admit it as a substantive exhibit.
