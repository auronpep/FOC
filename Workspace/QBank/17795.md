Outline: Erie Doctrine
Question: State law creates a presumption that a product seller is not liable if the product complied with a specific state safety certification. The presumption is part of the state product-liability framework. A diversity plaintiff asks the federal court to ignore the presumption because presumptions are courtroom procedure. What is the best Erie response?
Answer A: Ignore the presumption automatically because all presumptions are federal
Answer B: Apply the state presumption if it is part of the substantive state-liability framework and no valid federal directive displaces it
Answer C: Apply the presumption only if the defendant asks for removal
Answer D: Apply federal criminal presumptions by analogy
Correct Answer: B
Correct Answer Explanation: Erie prevents federal court from altering the substance of the state-created claim.
Wrong Answer Explanations: A: Some presumptions are bound up with state substantive rights. C: Removal posture is not the Erie test. D: This is a civil state-law diversity claim.
lb_rule_reference: Rules that affect substantive state rights, including some presumptions, are strong candidates for Erie application absent a federal directive.
