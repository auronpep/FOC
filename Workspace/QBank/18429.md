Question: A contractor sues an owner for unpaid amounts under a renovation contract. When the owner serves its answer, it already has a claim that the contractor damaged the same building during the same renovation. How should the owner's damage claim be classified?
Answer A: It is a compulsory counterclaim because it arises from the same transaction or occurrence as the contractor's claim
Answer B: It is permissive because all counterclaims are optional
Answer C: It is barred because defendants may never assert claims in an answer
Answer D: It is compulsory only if it independently satisfies diversity jurisdiction
Correct Answer: A
Correct Answer Explanation: Both claims arise from the same renovation contract and work. The owner's existing damage claim must be pleaded as a compulsory counterclaim if no exception applies.
Wrong Answer Explanations: B: Rule 13 distinguishes compulsory and permissive counterclaims. C: Counterclaims are asserted in responsive pleadings. D: Classification as compulsory depends on Rule 13(a); jurisdiction is a separate question.
lb_rule_reference: Rule 13(a) requires a pleading to state a counterclaim that arises out of the same transaction or occurrence as the opposing party's claim and is mature at the time of service.
