Outline: Cause in fact (actual cause)
Question: Two campers at separate sites negligently left campfires burning. A windstorm pushed both fires toward a cabin. Each fire alone would have destroyed the cabin at the same time; together they merged and destroyed it. How should actual cause be analyzed?
Answer A: Neither camper is an actual cause because the cabin would have burned from the other fire
Answer B: Each camper may be treated as an actual cause because each negligent fire was a substantial factor sufficient to cause the loss
Answer C: Only the camper whose fire reached the cabin first can be an actual cause
Answer D: Actual cause is irrelevant whenever there are two negligent defendants
Correct Answer: B
Correct Answer Explanation: The substantial-factor approach handles concurrent sufficient causes.
Wrong Answer Explanations: A: This rigid but-for view would wrongly exclude duplicative sufficient causes. C: The facts say each fire was sufficient and they merged in causing the same destruction. D: Causation remains an element for each defendant.
lb_rule_reference: When two independent negligent forces each would have been sufficient to cause the same harm, each may be treated as an actual cause under the substantial-factor approach.
