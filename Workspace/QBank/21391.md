Question: In a federal criminal trial, Solomon does not testify. The prosecutor offers Solomon's prior felony theft conviction solely to impeach Solomon's credibility. Solomon objects. How should the court rule?
Answer A: Admit the conviction because theft is relevant to credibility.
Answer B: Admit the conviction because Solomon is a criminal defendant.
Answer C: Exclude the conviction because conviction impeachment under Rule 609 attacks the credibility of a witness, and Solomon has not testified.
Answer D: Exclude the conviction only if it is more than ten years old.
Correct Answer: C
Correct Answer Explanation: Rule 609 is a witness-impeachment rule. If Solomon does not testify, he is not a witness whose credibility can be attacked through conviction impeachment. The conviction cannot be offered solely for impeachment of a non-testifying defendant.
Wrong Answer Explanations: A: A is wrong because relevance to credibility matters only if there is witness credibility to attack. B: B is wrong because defendant status does not make a non-testifying person impeachable. D: D is wrong because the basic witness-status problem arises before the ten-year limit.
lb_rule_reference: FRE 609 / conviction impeachment only of a witness
lb_student_diagnostic: Tests the witness-status gate and blocks using impeachment language as a backdoor propensity route.
