Outline: Invasion of privacy
Question: Office Manager falsely told Employee, in a closed one-on-one meeting, "Your coworker Alex is secretly sabotaging your work." Employee did not repeat the statement. Alex learned about it from Manager's later apology and sued for false light. Is Alex likely to prevail on false light?
Answer A: Yes, because the statement created a false impression about Alex
Answer B: Yes, because false light is identical to defamation
Answer C: No, because the false statement was not publicized broadly enough
Answer D: No, because false light requires commercial use of Alex's identity
Correct Answer: C
Correct Answer Explanation: Manager communicated to one employee in a private meeting, and the statement went no further. That lacks false-light publicity.
Wrong Answer Explanations: A: False light requires publicity to the public or a broad audience. A private one-to-one statement is not enough. B: False light has its own publicity and offensiveness requirements. D: Commercial identity use belongs to appropriation. False light fails here because publicity is absent.
lb_rule_reference: False light requires widespread publicity placing the plaintiff in a false or misleading light; a private one-to-one false statement is insufficient.
