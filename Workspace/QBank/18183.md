Question: Esther signed a note stating, “Daniel has my permission to use the path across my land until I revoke this permission.” Daniel recorded the note. Daniel did not pay for the permission and did not build or improve anything in reliance on it. Esther later revoked the permission. What is the best classification of Daniel's right?
Answer A: A revocable license, because the writing expressly gives permission only until Esther revokes it.
Answer B: An express easement, because any written permission to cross land is automatically an easement.
Answer C: A prescriptive easement, because recording a permission note makes the use adverse.
Answer D: Fee title to the path, because the note was recorded.
Correct Answer: A
Correct Answer Explanation: The language of the instrument controls the interest created. A writing that gives permission only until revocation shows a license, not an intent to create a permanent property interest. Recording the note does not transform revocable permission into an easement.
Wrong Answer Explanations: B: B is wrong because not every written permission creates an easement; intent and operative language matter. C: C is wrong because permission defeats adversity. D: D is wrong because recording a license does not create fee title.
lb_rule_reference: Revocable permission language / license
