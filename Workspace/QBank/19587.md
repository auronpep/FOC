Question: In a federal hit-and-run trial, the prosecutor offers evidence that tire marks at the scene were the same width as the tires on Joseph's car. Joseph objects that thousands of cars use tires with that same width. How should the court rule?
Answer A: Admit the evidence because the matching tire width has some tendency to identify Joseph's car; the commonness of the width affects weight.
Answer B: Exclude the evidence because the tire width does not uniquely identify Joseph's car.
Answer C: Exclude the evidence unless the prosecutor proves Joseph's tires made the marks by a preponderance.
Answer D: Admit the evidence only if the tire marks contain a distinctive tread pattern.
Correct Answer: A
Correct Answer Explanation: A nonunique match may still have probative value. The shared tire width makes it slightly more probable that Joseph's car was involved. The fact that many cars share that width is a weakness for the jury, not a relevance bar.
Wrong Answer Explanations: B: B is wrong because evidence need not uniquely identify the source to be relevant. C: C is wrong because Rule 401 does not demand preponderance proof of the ultimate source. D: D is wrong because a distinctive tread would strengthen the proof, but it is not required for threshold relevance.
lb_rule_reference: FRE 401; FRE 402
lb_student_diagnostic: Student equates nonunique evidence with no relevance.
