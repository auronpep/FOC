Subtopic: Law Applied by Federal Courts (Erie)
Outline: Erie Doctrine
Question: In a diversity action, a student argues that the Erie answer is always simple: if applying the state rule would change the outcome, the state rule applies; if it would not, federal practice applies. The actual dispute may involve a Federal Rule directly on point. What is wrong with the student's statement?
Answer A: Nothing; outcome effect is the complete Erie test in every case
Answer B: It ignores the threshold question whether a valid federal directive directly controls the issue
Answer C: It is wrong because federal law always applies in diversity
Answer D: It is wrong because state law always applies in diversity
Correct Answer: B
Correct Answer Explanation: Hanna requires the court to check first for a federal rule or statute on point.
Wrong Answer Explanations: A: Outcome effect is not complete and does not precede the federal-rule inquiry. C: Diversity courts apply state substantive law. D: Valid federal procedural directives can govern.
lb_rule_reference: Erie sequence: check for valid federal directive, then classify and analyze twin aims and federal interests if no directive controls.
