Subtopic: Law Applied by Federal Courts (Erie)
Outline: Erie Doctrine
Question: A diversity plaintiff sues for negligent infliction of emotional distress under state law. The forum state's highest court requires proof of physical impact as an element of that claim. The plaintiff asks the federal court to ignore that element because federal pleading rules do not mention it. May the federal court ignore the physical-impact element?
Answer A: Yes, because federal pleading rules define all elements in federal court
Answer B: Yes, because Erie never applies to tort elements
Answer C: No, because the state-law element travels with the state cause of action
Answer D: No, but only because the parties consented
Correct Answer: C
Correct Answer Explanation: The federal court cannot alter the elements of a state-created claim merely because the case is in federal court.
Wrong Answer Explanations: A: Pleading rules govern how claims are presented; state substantive law defines the elements of the state claim. B: Tort elements are classic state substantive law. D: Party consent is not needed for Erie to require state substantive law.
lb_rule_reference: Erie requires application of state substantive law, including claim elements and defenses.
