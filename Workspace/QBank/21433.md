Outline: Expectation damages
Question: Naomi contracted with Aaron to install a particular brand of pipe inside a finished wall for $60,000. Aaron installed an equivalent brand that functions identically and has the same useful life. Replacing the pipe would require tearing out finished walls at a cost of $45,000. The difference in market value between the house as promised and as built is $4,000. What is Naomi's proper expectation recovery?
Answer A: $45,000, because Aaron did not install the exact brand promised.
Answer B: $60,000, because the breach defeats the entire contract.
Answer C: $4,000, because replacement would cause economic waste and diminution in value is the proper measure.
Answer D: Nothing, because the substituted pipe functions identically.
Correct Answer: C
Correct Answer Explanation: When the cost to remedy a construction defect is grossly disproportionate to the benefit and would cause economic waste, damages are limited to diminution in value. Naomi receives the $4,000 difference in value, not the $45,000 tear-out cost.
Wrong Answer Explanations: A: A is wrong because literal replacement would cause disproportionate economic waste. B: B is wrong because the breach does not justify refunding the entire contract price. D: D is wrong because Naomi still did not receive the exact promised performance and proved a value difference.
lb_rule_reference: Common law construction damages; economic waste
