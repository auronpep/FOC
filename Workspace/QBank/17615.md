Question: Noah signed a written contract with a contractor to remodel Noah's kitchen for a fixed price. The contract stated that changes had to be made by a signed written change order. After demolition began, Noah orally asked the contractor to move plumbing lines and build a larger island, work not shown in the plans. The contractor ordered custom materials, completed the extra work while Noah watched, and then billed for the added cost. Noah refused to pay, arguing that the written contract barred any oral change. What is the contractor's strongest Content/Meaning argument?
Answer A: The parol evidence rule bars the oral request because the written contract was final.
Answer B: The contractor cannot recover because performing construction work is always a preexisting duty.
Answer C: The later request and performance can support a modification, waiver, or reliance route; the parol evidence rule does not bar later changes.
Answer D: The contractor can recover only if the original writing was ambiguous about the island.
Correct Answer: C
Correct Answer Explanation: The narrow rule is that the parol evidence rule applies to prior or contemporaneous terms, not later changes or waivers. The trigger facts are Noah's post-signing request, the extra work outside the original plans, and the contractor's performance in reliance on that request. The decisive lock is timing: this is a later modification/waiver problem, not a parol-evidence problem. The no-oral-modification clause is relevant, but it does not turn later relied-on conduct into prior parol evidence.
Wrong Answer Explanations: A: A is wrong because it commits a PER timing error; the request occurred after the writing. B: B is wrong because the larger island and plumbing relocation were additional scope, not merely the same preexisting duty. D: D is wrong because the contractor need not show ambiguity in the original plans to prove a later change or waiver.
lb_rule_reference: Common law subsequent modification / waiver; PER timing lock
