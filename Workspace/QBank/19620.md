Question: In a diversity fraud case, state law requires clear and convincing proof of reliance. The defendant moves for summary judgment in federal court. The plaintiff argues the court must use a state summary-judgment procedure rather than Federal Rule 56. Which statement is most accurate?
Answer A: The federal court uses Rule 56 procedure while considering the state substantive burden
Answer B: The federal court ignores the state burden because Rule 56 exists
Answer C: The federal court must use only state motion practice
Answer D: Summary judgment is unavailable in diversity cases
Correct Answer: A
Correct Answer Explanation: Federal procedure governs the motion mechanism, but state law supplies the substantive burden for the claim.
Wrong Answer Explanations: B: Rule 56 does not redefine state-law claim elements or burdens. C: A valid Federal Rule governs summary judgment procedure. D: Diversity cases use federal civil procedure.
lb_rule_reference: Federal Rule 56 supplies the summary judgment procedure; state law can still define the claim elements and burden.
