Question: A state requires sworn police officers with arrest authority and discretionary law-enforcement powers to be United States citizens. A lawful permanent resident who otherwise qualifies challenges the requirement under Equal Protection. What is the state's best defense?
Answer A: State alienage classifications always receive rational basis
Answer B: The public-function exception may allow citizenship requirements for police officers exercising sovereign authority
Answer C: The requirement is invalid per se because no alienage exception exists
Answer D: The federal immigration power makes every state citizenship requirement valid
Correct Answer: B
Correct Answer Explanation: Police officers perform core governmental functions involving discretionary public authority, making the exception relevant.
Wrong Answer Explanations: A: State alienage classifications generally receive strict scrutiny. C: The public-function exception is real for roles tied to self-governance. D: A state rule needs its own Equal Protection justification; federal plenary power does not automatically save it.
lb_rule_reference: State alienage classifications generally receive strict scrutiny, but states may reserve certain public-function positions tied to democratic self-governance for citizens.
