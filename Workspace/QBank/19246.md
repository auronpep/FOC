Outline: Scope
Question: A deed granted Paul, as owner of Field Lot, “a right to use the farm road over Lydia's land for agricultural access to Field Lot.” Field Lot was used for a small orchard. Paul later converted Field Lot into a public event venue with nightly concerts. Hundreds of cars now use the farm road each week, creating dust, noise, and congestion far beyond the prior agricultural use. Which is the best result?
Answer A: Lydia may object because the new public-event use likely exceeds the agricultural-access scope and unreasonably increases the burden on the servient estate.
Answer B: Paul may use the road for any purpose because the grant used the word access.
Answer C: The easement terminated automatically when Paul changed the use of Field Lot.
Answer D: Lydia has no claim unless the concerts violate zoning law.
Correct Answer: A
Correct Answer Explanation: Easement scope is controlled by the grant's language and purpose, along with reasonable expectations. A farm-road easement for agricultural access is likely overburdened by a public event venue generating heavy nightly traffic, noise, and congestion beyond the contemplated agricultural use.
Wrong Answer Explanations: B: B is wrong because access language is limited by context and purpose. C: C is wrong because excessive use is usually enjoined or limited, not automatic termination. D: D is wrong because private easement scope can be violated even if zoning is satisfied.
lb_rule_reference: Scope evolution / unreasonable burden
lb_student_diagnostic: The trap is either freezing every change or allowing any change once the word access appears.
