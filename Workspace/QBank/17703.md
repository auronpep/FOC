Outline: Requirements for valid deed
Question: Hannah owned two parcels in Judah County and no other land there. She signed and delivered to Samuel a deed stating, “I convey all my land in Judah County to Samuel.” The deed did not list the parcels separately, but the county records and Hannah's ownership facts identified the two parcels. Samuel accepted. What is the best result?
Answer A: Hannah keeps both parcels because a deed must separately list every parcel conveyed.
Answer B: Samuel receives both parcels because the description identifies all of Hannah's land in the county with reasonable certainty.
Answer C: Samuel receives only the parcel with the lower tax number.
Answer D: Hannah keeps both parcels unless Samuel paid consideration.
Correct Answer: B
Correct Answer Explanation: The title source is a deed, and the decisive validity gate is property-description sufficiency. A deed can describe property generally if the land can be identified with reasonable certainty from the instrument and existing ownership facts. “All my land in Judah County” identifies both parcels Hannah owned there, so title passes to Samuel.
Wrong Answer Explanations: A: A is wrong because each parcel need not be separately listed if the general description is sufficiently certain. C: C is wrong because the deed conveys all land fitting the description, not a single parcel selected by tax number. D: D is wrong because consideration is not required for deed validity.
