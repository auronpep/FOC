Outline: Requirements for valid deed
Question: Abigail owned one house at 12 Olive Road in Canaan County. She signed and delivered to Ezra a deed stating, “I convey the house at 12 Olive Road in Canaan County to Ezra.” The deed did not attach a survey or use metes and bounds. Abigail later argues that the description was inadequate. Who owns the house?
Answer A: Abigail, because a street address can never satisfy the property-description requirement.
Answer B: Ezra, because the description reasonably identifies the house conveyed.
Answer C: Abigail, because a deed must include metes and bounds.
Answer D: Ezra only if a survey was attached before delivery.
Correct Answer: B
Correct Answer Explanation: The title source is a deed, and the decisive validity gate is property description. A deed description is sufficient if it reasonably identifies the land conveyed. A street address can be enough when it identifies the property, so title passes to Ezra.
Wrong Answer Explanations: A: A is wrong because a street address is not categorically insufficient. C: C is wrong because metes and bounds are not always required. D: D is wrong because a survey is not required when the description otherwise identifies the property.
lb_rule_reference: Property description / street address
