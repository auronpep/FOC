Question: Solomon granted Deborah “a driveway easement for access to the existing single-family residence on Deborah's parcel, and for no other residential units.” Deborah later built four rental cottages on the parcel and directed the tenants to use the driveway. The added traffic significantly increased wear on the driveway. Solomon sues to limit the use. Which is the best result?
Answer A: Deborah may use the driveway for all four cottages because the cottages are on the same parcel.
Answer B: Deborah may use the driveway for all residential units because any residential use is automatically within scope.
Answer C: Solomon should prevail because the express grant limited access to the existing single-family residence and excluded other residential units.
Answer D: Solomon should prevail only by proving that Deborah abandoned the original residence.
Correct Answer: C
Correct Answer Explanation: Although some easements allow reasonable development of the dominant estate, the express grant here specifically limits access to the existing single-family residence and excludes other residential units. That stated limit controls scope.
Wrong Answer Explanations: A: A is wrong because same-parcel status does not override an express use limitation. B: B is wrong because the grant excludes other residential units. C is correct because the grant's explicit limit controls. D: D is wrong because abandonment is not required to enforce the scope limit.
lb_rule_reference: Express residential-use limit / multifamily expansion
