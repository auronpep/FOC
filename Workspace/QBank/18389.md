Question: Jacob owned two adjoining lots. During one summer, he occasionally drove construction trucks across Lot B while repairing a house on Lot A. After the repairs ended, no one used Lot B to reach Lot A. The next year, Jacob sold Lot A to Rebecca by a deed that did not mention access across Lot B. Rebecca claims an implied easement by prior use for regular truck access across Lot B. What is the best result?
Answer A: Rebecca has the easement because any prior use by a common owner is enough.
Answer B: Rebecca likely has no implied easement because the temporary construction use was not a continuous quasi-easement at severance.
Answer C: Rebecca has an easement by necessity because construction trucks once used Lot B.
Answer D: Rebecca has title to the route because truck use is more substantial than footpath use.
Correct Answer: B
Correct Answer Explanation: Implied easements by prior use generally require an apparent and continuous pre-severance use, not a temporary or occasional use that ended before the conveyance. Jacob's sporadic construction access does not support a permanent implied access easement.
Wrong Answer Explanations: A: A is wrong because not every prior use qualifies. B is correct for the reasons above. C: C is wrong because past truck use does not show strict necessity. D: D is wrong because the claim is a use right and the facts do not support title.
lb_rule_reference: Continuous prior use requirement
lb_student_diagnostic: The miss is overlooking the continuous-use lock and treating one-time construction convenience as a permanent servitude.
