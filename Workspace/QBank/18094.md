Outline: Uniform Commercial Code (UCC)
Question: A seller and a buyer signed a contract for 100 tools at $4 each. Later, they orally agreed in good faith to reduce the quantity to 60 tools at $4 each. The buyer later insists the oral modification is unenforceable because it was not in writing and no new consideration was given. Assuming no signed no-oral-modification clause applies, what is the best answer under Article 2?
Answer A: The modification is unenforceable because every goods modification must be signed.
Answer B: The modification can be enforceable because Article 2 modifications need no consideration and, as modified, the sale price is below $500.
Answer C: The modification is unenforceable because reducing quantity is never permitted under the UCC.
Answer D: The modification is enforceable only if the buyer paid for all 60 tools before the oral agreement.
Correct Answer: B
Correct Answer Explanation: Under Article 2, a good-faith modification needs no consideration. Section 2-209 requires compliance with the Statute of Frauds only if the contract as modified is within §2-201. Sixty tools at $4 each is below $500, so the UCC goods SOF does not bar the oral modification on that ground.
Wrong Answer Explanations: A: A is wrong because not every goods modification must be signed. C: C is wrong because quantity reductions can be valid modifications. D: D is wrong because advance payment is not required when the modified contract is outside the goods SOF.
lb_rule_reference: UCC §2-209 / modification below SOF threshold
