Question: A proposed consumer class action has more than one hundred members, aggregated alleged losses above the CAFA threshold, and at least one class member who is diverse from one defendant. Some class members share citizenship with some defendants. Which jurisdictional statement is most accurate?
Answer A: CAFA jurisdiction is impossible because every class member must be diverse from every defendant
Answer B: CAFA may supply jurisdiction if its class size, amount, and minimal-diversity requirements are met and no exception applies
Answer C: CAFA jurisdiction is automatic for every class action filed in federal court
Answer D: CAFA applies only when every class member's individual claim exceeds the ordinary amount threshold
Correct Answer: B
Correct Answer Explanation: The facts point to CAFA's special jurisdictional structure rather than ordinary complete diversity.
Wrong Answer Explanations: A: CAFA uses minimal diversity for qualifying class actions. C: The statute has requirements and exceptions. D: CAFA uses aggregated amount in controversy.
lb_rule_reference: CAFA can provide federal jurisdiction for qualifying class actions with minimal diversity, sufficient aggregate amount in controversy, and the required class size, subject to statutory exceptions.
