Outline: Expectation damages
Question: A retailer contracted to sell a new boat to Caleb for $60,000. Caleb wrongfully repudiated. The retailer had an unlimited supply from the manufacturer and would have made both Caleb's sale and any later sale. The retailer later sold the same model boat to Joshua for $60,000. The retailer's profit on each boat sale was $6,000, and it incurred $400 in reasonable incidental damages from Caleb's breach. What may the retailer recover from Caleb?
Answer A: $6,400, the lost profit plus incidental damages.
Answer B: Nothing, because the retailer resold the same model for the same price.
Answer C: $400 only, because the resale eliminated the lost profit.
Answer D: $60,000, the full contract price.
Correct Answer: A
Correct Answer Explanation: A lost-volume seller would have made both the breached sale and the later sale. Same-price resale does not put the seller in the position performance would have done because the seller lost one sale volume. The proper measure is the lost profit, including reasonable overhead where appropriate, plus incidental damages: $6,000 + $400.
Wrong Answer Explanations: B: B is wrong because resale does not erase damages for a true lost-volume seller. C: C is wrong because it undercounts the lost sale profit. D: D is wrong because action for the price is limited and not the proper measure for a lost-volume seller with a resale.
lb_rule_reference: UCC §2-708(2)
