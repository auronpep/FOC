Outline: Materiality and probative value
Question: In a federal fraud trial, the prosecutor offers a receipt from a copy shop near the fraud scene. The receipt is signed “David,” and the prosecutor shows that David was in the area that afternoon. David objects that many people are named David and that the receipt does not include a last name. How should the court rule?
Answer A: Exclude the receipt because a first name can never be probative identity evidence.
Answer B: Admit the receipt only if a handwriting expert identifies the signature as David's.
Answer C: Exclude the receipt unless the prosecutor proves no other David used the shop.
Answer D: Admit the receipt if the common first name and surrounding location/timing evidence have some tendency to connect David to the transaction; weaknesses affect weight.
Correct Answer: D
Correct Answer Explanation: The first name alone would be weak, but the timing and location give it some probative value. The commonness of the name and lack of surname are weight arguments.
Wrong Answer Explanations: A: A is wrong because a common name may still have some probative value when combined with surrounding facts. B: B is wrong because a handwriting expert is not categorically required for relevance. C: C is wrong because the proponent need not eliminate every other possible David.
lb_rule_reference: FRE 401
lb_student_diagnostic: Student treats partial identity evidence as worthless unless conclusive.
