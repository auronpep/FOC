


BARMATRIX Q#: 22745
Outline_code: 94010000
MBE Subjects (1 of 7): Civil Procedure
Subtopic: Jurisdiction and Venue
Outline: Federal Subject-Matter Jurisdiction
Question: A State A brewery wanted to sue a State B brewery for copyright infringement because it believed that the State B brewery's name and logo were too close to the ones used by the State A brewery. The State A brewery wanted to sue the State B brewery in federal court in State A, where the State B brewery had several billboards and sometimes sent coupons to residents. All of the State B brewery's warehouses, employees, and manufacturing was in State B. Is venue appropriate in State A?
Answer A: A: Yes, because the State B brewery advertised in State A.
Answer B: B: Yes, because the State A brewery's copyright is the subject of the State A brewery's claim.
Answer C: C: No, because the State B brewery has insufficient minimum contacts with State A.
Answer D: D: No, because the State B brewery has all of its operations in State B.
Correct Answer: A
Correct Answer Explanation: When a defendant being sued for copyright infringement targets a particular place with advertising and active marketing, these actions constitute a substantial part of the events giving rise to the claim. Consequently, venue would be proper in that location. Here, the State B brewery has billboards in State A and sends coupons to its residents, so venue would be appropriate in State A. B is incorrect because the fact that the State A brewery's copyright claim is the subject of the lawsuit does not immediately make venue in State A proper. C and D are incorrect because the State B brewery is conducting ongoing advertising in State A.
