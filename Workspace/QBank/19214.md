Question: Adam owned Lot A and Lot B. Before severance, Adam occasionally crossed a marked path on Lot B only to inspect a well located near the boundary. The path was not used to reach a public road or any residence. Adam sold Lot A to Eve by a deed that did not mention the path. Eve now wants to use the path across Lot B as her regular route to a public road. What is the best result?
Answer A: Eve has an implied easement for regular road access because any path between severed parcels becomes an access easement.
Answer B: Eve has an easement by necessity because the path would be convenient.
Answer C: Eve likely cannot convert a limited prior well-inspection use into a general access easement to the public road.
Answer D: Eve owns the path by adverse possession because Adam marked it before severance.
Correct Answer: C
Correct Answer Explanation: An implied easement by prior use is measured by the use that existed at severance. A path used only for well inspection does not imply a broader general ingress-and-egress easement to a public road absent facts supporting that broader use.
Wrong Answer Explanations: A: A is wrong because a path does not automatically become a general access easement. B: B is wrong because convenience is not strict necessity. C is correct for the reasons above. D: D is wrong because Adam's marking of his own land before severance was not adverse possession.
lb_rule_reference: Prior-use easement limited by existing use
lb_student_diagnostic: The trap is finding a prior use and then expanding it beyond the use actually made before severance.
