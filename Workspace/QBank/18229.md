Question: A consumer sues a company in federal court under diversity jurisdiction and seeks to certify a class under Rule 23. The forum state's statute says claims for a certain statutory penalty may not be brought as class actions. The proposed class otherwise satisfies Rule 23. Which rule should the federal court apply to the certification question?
Answer A: The state class-action ban, because state policy always defeats a federal rule in diversity
Answer B: Rule 23, because it directly governs class certification in federal court
Answer C: Federal common law, because diversity cases use federal law for all remedies
Answer D: The law of the state where most class members live
Correct Answer: B
Correct Answer Explanation: A valid Federal Rule on point governs the federal procedure even if applying it changes whether the claim can proceed as a class action.
Wrong Answer Explanations: A: The certification mechanism is directly governed by Rule 23 when the rule covers the issue and is valid. State policy does not skip the Hanna fork. C: The source is not general federal common law. The answer depends on Rule 23 as a valid rule directly on point. D: The issue is the procedural availability of class certification in the federal forum, not which state's substantive law governs every class member's claim.
lb_rule_reference: In a diversity class action, Rule 23 governs whether the case may proceed as a class action when the rule is directly on point and valid.
