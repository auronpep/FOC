Subtopic: Relevancy and Excluding Relevant Evidence
Outline: Authentication and Identification
Question: Elijah is charged with assaulting Jacob with a small folding knife. Three months later, police find a common folding knife in a public park two miles from the scene. No witness connects the knife to Elijah, Jacob, or the assault; it has no blood, fingerprints, or distinctive markings. The prosecutor offers the knife because it is the same general kind of weapon described by Jacob. How should the court rule?
Answer A: Exclude the knife because the government has not connected this generic object to the defendant, victim, or event.
Answer B: Admit the knife because any object of the same general type as the weapon described is relevant.
Answer C: Admit the knife because the jury can speculate whether it might be the weapon.
Answer D: Exclude the knife only if Elijah proves he never owned a folding knife.
Correct Answer: A
Correct Answer Explanation: A generic object found months later in a public place, with no connection to the defendant, victim, or event, lacks a sufficient probative link. Mere similarity in general type is not enough.
Wrong Answer Explanations: B: B is wrong because same general type alone is too weak without connection to the case. C: C is wrong because admissibility requires a reasonable inferential link, not speculation. D: D is wrong because the prosecutor must connect the object; Elijah need not disprove ownership.
lb_rule_reference: FRE 401; FRE 104(b)
lb_student_diagnostic: Student confuses generic similarity with sufficient source identity.
