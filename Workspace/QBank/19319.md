Question: In a federal battery trial, Miriam offers a still image printed from a surveillance video to show where Moses stood. A technician authenticates the video system and testifies that the still is an accurate frame from the video. The opponent objects that only the entire video can be used. What is the best ruling?
Answer A: Exclude the still because a still image from a video is never admissible.
Answer B: Admit the still if it is properly authenticated and no fairness concern requires showing more of the video.
Answer C: Admit the still only as impeachment evidence.
Answer D: Exclude the still because all photographs must be self-authenticating.
Correct Answer: B
Correct Answer Explanation: A still frame can be admitted if authenticated and fair in context. The court may require additional portions if needed to avoid misleading the jury, but the entire video is not automatically required.
