Question: Delivery drivers allege that a company used one written policy that wrongly classified all drivers as independent contractors. The amount of back pay would differ by driver because routes and hours varied. The company argues that the case cannot satisfy commonality because damages are not identical. How should the court address the commonality objection?
Answer A: Reject certification automatically because different damages always defeat commonality
Answer B: Treat commonality as satisfied only if each driver worked the same route and hours
Answer C: Ask whether the legality of the common classification policy can generate a common answer for the class
Answer D: Skip Rule 23(a) and analyze only Rule 23(b)(3) because damages are requested
Correct Answer: C
lb_rule_reference: Commonality requires a common contention capable of classwide resolution; individualized damages do not automatically defeat commonality.
