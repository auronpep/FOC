Outline: Requirements for valid deed
Question: Hannah owned exactly one farm in Judah County. She signed and delivered to Samuel a deed stating, “I convey my farm in Judah County to Samuel.” The deed did not include metes and bounds, a parcel number, or a survey. Hannah later argues that the deed failed for insufficient description. Who owns the farm?
Answer A: Hannah, because a deed must use metes and bounds or a parcel number.
Answer B: Samuel, because the description reasonably identifies the only farm Hannah owned in Judah County.
Answer C: Hannah, because extrinsic facts may never be used to apply a deed description.
Answer D: Samuel only if he recorded the deed before Hannah objected.
Correct Answer: B
Correct Answer Explanation: The title source is a deed, and the decisive validity gate is property description. A description is sufficient if it allows the property to be identified with reasonable certainty, including by applying the deed language to existing facts. Hannah owned only one farm in Judah County, so the description is sufficient and title passes to Samuel.
Wrong Answer Explanations: A: A is wrong because metes and bounds or parcel numbers are not always required. C: C is wrong because extrinsic facts may be used to apply, not rewrite, a sufficient description. D: D is wrong because recording is not needed for validity between Hannah and Samuel.
