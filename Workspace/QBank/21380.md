Outline: Subsequent remedial measures
Question: In a machinery case, the manufacturer's engineer testifies, “It was not feasible to install a guard over that gear before the accident.” The plaintiff offers evidence that, two days after the accident, the manufacturer installed exactly such a guard on the same model. The plaintiff offers the evidence only to rebut the feasibility testimony. How should the court rule?
Answer A: Exclude the evidence because subsequent remedial measures can never be used after an accident.
Answer B: Exclude the evidence because feasibility is never a permitted purpose under Rule 407.
Answer C: Admit the evidence to prove both feasibility and that the original design was defective.
Answer D: Admit the evidence for the limited purpose of proving feasibility after the manufacturer disputed feasibility.
Correct Answer: D
Correct Answer Explanation: Rule 407 permits subsequent remedial measures for purposes such as feasibility if feasibility is disputed. The engineer directly disputed feasibility. The evidence should be limited to feasibility, not used as proof of defect.
Wrong Answer Explanations: A: A is wrong because Rule 407 is not an absolute bar. B: B is wrong because Feasibility is an expressly recognized permitted purpose when disputed. C: C is wrong because This converts a permitted purpose into a prohibited product-defect purpose.
lb_rule_reference: FRE 407 / feasibility purpose
lb_student_diagnostic: Student misses the disputed-feasibility trigger or overuses it to admit the evidence for defect.
