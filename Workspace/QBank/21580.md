Outline: Requirements for valid deed
Question: Noah owned a cabin. The cabin bordered a river on three sides and one adjoining parcel on the fourth side. Eve owned the adjoining parcel and was Noah's only neighbor. Noah signed and delivered a deed stating, “I convey my cabin to my neighbor.” Eve accepted the deed. Who owns the cabin?
Answer A: Noah, because a deed must state the grantee's full legal name.
Answer B: Noah, because the word “neighbor” is always too vague.
Answer C: Eve, because the deed description identifies the only person who fit the stated grantee description.
Answer D: Eve only if Noah later signs a corrective deed naming her.
Correct Answer: C
Correct Answer Explanation: The title source is a deed, and the decisive validity gate is grantee ascertainability. A deed need not state a full legal name if the grantee can be identified with reasonable certainty from the instrument and existing identifying facts. Because Eve was Noah's only neighbor, the description identifies her and title passes to Eve.
Wrong Answer Explanations: A: A is wrong because exact full legal names are not required when identity is reasonably certain. B: B is wrong because a generic description can be sufficient when only one person fits it. D: D is wrong because a corrective deed is unnecessary when the original deed identifies the grantee.
lb_rule_reference: Grantee ascertainability / external identifying facts
