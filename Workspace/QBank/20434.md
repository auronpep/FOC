Question: Naomi bought a commercial oven from Samuel for use in her bakery. The oven was warranted to be worth $40,000 if conforming. Naomi accepted it and timely notified Samuel that it did not reach the warranted temperature. At the time and place of acceptance, the oven as delivered was worth $28,000. Naomi did not revoke acceptance. What is the ordinary measure of Naomi's breach-of-warranty damages for the accepted oven, apart from any incidental or consequential damages?
Answer A: Nothing, because Naomi accepted the oven.
Answer B: The $40,000 value the oven would have had if it had conformed.
Answer C: The $28,000 value of the oven as accepted.
Answer D: $12,000, the difference between the value as warranted and the value as accepted.
Correct Answer: D
Correct Answer Explanation: For accepted goods, the ordinary breach-of-warranty measure is the difference, at the time and place of acceptance, between the value the goods would have had if as warranted and the value of the goods as accepted. That difference is $12,000.
Wrong Answer Explanations: A: A is wrong because acceptance does not eliminate damages for nonconformity after proper notice. B: B is wrong because awarding the full warranted value would overcompensate Naomi. C: C is wrong because the value of the defective oven is not the loss measure by itself.
lb_rule_reference: UCC §2-714
