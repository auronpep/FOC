Outline: Erie Doctrine
Question: In a diversity negligence case, no Federal Rule or statute addresses whether a pre-suit notice condition must be satisfied. The state statute creating the claim requires notice to the defendant before suit. Ignoring the notice condition would make federal court materially more attractive than state court for the same state claim. What should the federal court do?
Answer A: Ignore the state notice condition because all pre-suit steps are procedural
Answer B: Apply the state notice condition if ignoring it would encourage forum shopping or inequitable administration
Answer C: Apply state law only if the defendant is a citizen of the forum state
Answer D: Use outcome effect alone and never consider federal interests
Correct Answer: B
Correct Answer Explanation: The twin aims support applying a state condition tied to the state claim when no valid federal directive displaces it.
Wrong Answer Explanations: A: Without a federal rule on point, the court must consider Erie twin aims and the state right. C: Erie does not turn on forum-defendant citizenship. D: Outcome effect matters, but it is not the whole analysis.
lb_rule_reference: Erie analysis after the federal-rule fork uses the twin aims and any countervailing federal interest.
