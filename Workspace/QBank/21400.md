Question: A diversity action in federal court is governed entirely by State X contract law. The defendant seeks testimony from the plaintiff's physician about a confidential consultation unrelated to any physical condition the plaintiff has placed in issue. State X recognizes a physician-patient privilege for the consultation. The defendant argues that federal common law supplies the privilege rule because the case is in federal court. How should the court rule on the privilege objection?
Answer A: Sustain it only if the physician was retained for litigation rather than treatment.
Answer B: Sustain it, because state privilege law governs a claim or defense for which state law supplies the rule of decision.
Answer C: Overrule it, because federal common law never applies state-law privileges in federal court.
Answer D: Overrule it, because physician-patient communications are always discoverable if relevant.
Correct Answer: B
Correct Answer Explanation: In a civil case, state privilege law governs privilege regarding a claim or defense for which state law supplies the rule of decision. This is a diversity/state-law contract case, and no federal claim supplies the relevant rule of decision. Because State X recognizes the privilege and no waiver facts appear, the objection should be sustained.
Wrong Answer Explanations: A: A is wrong because The treatment/litigation distinction is not the source-law trigger. The stem supplies a confidential physician consultation protected by State X law. B is wrong because Correct answer C is wrong because This is a forum-law shortcut. Federal court does not automatically mean federal privilege law for state-law claims.
