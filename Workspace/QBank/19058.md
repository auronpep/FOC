Subtopic: Presentation of Evidence
Outline: Refreshing recollection
Question: In a federal civil trial, Lazarus cannot remember the exact number of boxes delivered. While on the stand, he looks at his own note and then testifies from refreshed memory. The opposing party asks to inspect the note. Lazarus's lawyer objects that the note was not admitted into evidence. How should the court rule?
Answer A: Deny inspection because a writing used only to refresh memory is never disclosed.
Answer B: Deny inspection unless Lazarus offers the note as an exhibit.
Answer C: Admit the note automatically as substantive evidence.
Answer D: Permit inspection and cross-examination about the note; the testimony, not the note itself, is the evidence unless a separate rule permits admission.
Correct Answer: D
Correct Answer Explanation: When a witness uses a writing to refresh memory while testifying, the adverse party is entitled to inspect it, cross-examine the witness about it, and introduce related portions when appropriate. The writing does not automatically become substantive evidence merely because it refreshed memory.
Wrong Answer Explanations: A: A is wrong because Rule 612 gives inspection rights. B: B is wrong because inspection does not depend on the proponent offering the writing as an exhibit. C: C is wrong because refreshing memory does not automatically admit the writing.
lb_rule_reference: FRE 612 / writing used while testifying
lb_student_diagnostic: Tests refresh-versus-record/admission confusion and timing of inspection rights.
