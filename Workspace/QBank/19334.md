Question: Congress creates a federal licensing system for drone operators and orders county sheriffs to perform federal background checks before any license is issued. The sheriffs receive no choice and must use state staff to carry out the federal program. What is the likely result?
Answer A: The command is unconstitutional because Congress may not require state executive officers to administer a federal regulatory program
Answer B: The command is valid because federal law is supreme and state officers must enforce it
Answer C: The command is valid because drones travel in interstate commerce
Answer D: The command is invalid only if the sheriffs object in state court first
Correct Answer: A
Correct Answer Explanation: The statute commandeers state executive officials.
Wrong Answer Explanations: B: Anti-commandeering prevents Congress from conscripting state executive officers to administer federal programs. C: Even with commerce authority, Congress cannot commandeer state officers. D: The constitutional defect is the command itself, not a prerequisite state-court objection.
lb_rule_reference: Congress may not require state executive officers to administer or enforce a federal regulatory program.
