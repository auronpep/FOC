Outline: Motion for judgment on the pleadings
Question: Defendant was properly served and failed to answer. Plaintiff asks the clerk to enter default and also asks for default judgment on an unliquidated emotional-distress claim requiring proof of damages. No default has yet been entered. What is the best description of the required sequence?
Answer A: Default judgment is automatic the moment an answer deadline passes
Answer B: The clerk may enter default, but default judgment on unliquidated damages generally requires court involvement
Answer C: Plaintiff must file a Rule 50 motion before default
Answer D: A defendant who fails to answer can never be defaulted
Correct Answer: B
Correct Answer Explanation: Entry of default comes first; clerk default judgment is limited, and unliquidated damages generally need judicial action.
Wrong Answer Explanations: A: The rules distinguish entry of default from default judgment. C: Rule 50 is for trial sufficiency, not default. D: Failure to plead or defend is the classic default posture.
lb_rule_reference: When a party fails to plead or otherwise defend, the clerk may enter default; default judgment requires a separate step, with clerk authority limited to qualifying sum-certain cases.
