Question: Peter sold a used delivery cart to Mary. The written warranty stated, “Seller will repair any wheel defect for one year, but this warranty ends if Buyer resells the cart without giving Seller written notice.” Six months later, Mary resold the cart without notice. The new owner later demanded a free wheel repair from Peter under the warranty. What is Peter's best argument?
Answer A: The warranty never existed because Mary might resell the cart.
Answer B: The resale without notice was a condition subsequent that ended Peter's warranty duty.
Answer C: The new owner can enforce the warranty because conditions subsequent are invalid.
Answer D: Peter breached the warranty because Mary's resale was only a minor breach.
Correct Answer: B
Correct Answer Explanation: The warranty duty existed initially, but the contract made resale without notice an event that would terminate the duty. That is a condition subsequent. Once the event occurred, Peter's repair duty ended.
Wrong Answer Explanations: A: A is wrong because the warranty existed until the terminating event occurred. C: C is wrong because conditions subsequent can cut off an existing duty when properly triggered. D: D is wrong because the issue is termination of the warranty duty, not whether Mary committed a minor covenant breach.
lb_rule_reference: Condition subsequent
