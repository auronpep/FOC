Question: An independent candidate challenges a ballot-access signature deadline that falls 45 days before each special election. The election ends before appellate review, but the candidate has publicly announced that she will run in the next special election governed by the same deadline. Election officials argue the case is moot. Which statement best applies the exception?
Answer A: The case is not moot because the deadline is too short to be fully litigated and the same candidate reasonably expects to face it again
Answer B: The case is not moot solely because election rules are important
Answer C: The case is moot because the challenged election has ended
Answer D: The case is not moot whenever any person might face the rule again
Correct Answer: A
Correct Answer Explanation: The short election timeline evades full review, and the same plaintiff is likely to encounter the same rule in the next election.
Wrong Answer Explanations: B: Importance alone does not create a mootness exception. The same-party recurrence and evading-review elements matter. C: The capable-of-repetition exception can preserve jurisdiction for recurring short-duration disputes. D: The exception generally requires a reasonable expectation that the same complaining party will face the challenged action again.
lb_rule_reference: A dispute can avoid mootness when the challenged action is too short in duration to be fully litigated and there is a reasonable expectation the same complaining party will face it again.
