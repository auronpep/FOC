Subtopic: Other Torts
Outline: Invasion of privacy
Question: An apartment manager guessed a tenant's email password and read the tenant's private messages to learn whether the tenant planned to complain about building conditions. The manager did not share the messages with anyone. The tenant sues for intrusion upon seclusion. Is the tenant likely to prevail?
Answer A: No, because the manager did not publish the emails
Answer B: No, because the manager owns the building
Answer C: Yes, because unauthorized reading of private email is a highly offensive intrusion
Answer D: Yes, but only if the emails contained false statements
Correct Answer: C
Correct Answer Explanation: The manager intentionally accessed private communications without permission for a self-interested reason. Publication is unnecessary.
Wrong Answer Explanations: A: Intrusion does not require publication. The unauthorized access itself can be the invasion. B: Building ownership does not authorize breaking into a tenant's private email account. D: Intrusion protects privacy from offensive access, not from false statements.
lb_rule_reference: Unauthorized access to private communications can be a highly offensive intrusion even if the information is never published.
