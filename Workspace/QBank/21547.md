MBE Subjects (1 of 7): Torts
Subtopic: Negligence
Outline: Cause in fact (actual cause)
Question: A warehouse owner failed to repair a sprinkler valve at noon. Unknown to anyone, a chemical fire had started at 11:45 a.m. in a sealed storage room and had already destroyed the inventory before noon. The unrepaired valve would have mattered only to a later fire. Is the noon failure to repair an actual cause of the destroyed inventory?
Answer A: Yes, because the owner breached a fire-safety duty on the same day
Answer B: Yes, because causation is presumed whenever fire safety is involved
Answer C: No, because the loss had already occurred before the breach could affect it
Answer D: No, because sprinkler failures are governed only by strict liability
Correct Answer: C
Correct Answer Explanation: The failure to repair cannot be a but-for cause of damage that was already complete.
Wrong Answer Explanations: A: The breach must cause the specific loss. B: There is no automatic presumption that replaces actual cause. D: This is a negligence causation problem, not strict liability.
lb_rule_reference: A breach cannot be an actual cause of a loss that had already become unavoidable before the breach occurred.
