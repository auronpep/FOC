Question: In a federal criminal trial, the defendant Elijah does not testify. The prosecutor offers evidence that Elijah was convicted of felony burglary four years ago, solely to impeach Elijah's credibility. Elijah objects. The prosecutor identifies no non-impeachment purpose for the conviction. How should the court rule?
Answer A: Admit the conviction because felony convictions are generally admissible to impeach.
Answer B: Admit the conviction because Elijah's credibility is always relevant in a criminal trial.
Answer C: Exclude the conviction because a conviction offered solely to impeach credibility has no impeachment target unless Elijah testifies.
Answer D: Exclude the conviction only if burglary is not a crime involving false statement.
Correct Answer: C
Correct Answer Explanation: Rule 609 governs attacking a witness's character for truthfulness by evidence of a criminal conviction. If Elijah does not testify, there is no witness credibility to impeach. The prosecutor has offered no other permissible purpose.
Wrong Answer Explanations: A: A is wrong because impeachment requires a witness to impeach. B: B is wrong because a non-testifying defendant's credibility is not before the jury as a witness. D: D is wrong because the problem is not burglary's classification; it is that the conviction is offered solely for impeachment when Elijah has not testified.
lb_rule_reference: FRE 609 / witness has not testified
lb_student_diagnostic: Tests conviction impeachment as a proof channel tied to witness status.
