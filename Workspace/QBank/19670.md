Question: Several diversity products cases filed in different states are transferred to one federal district for coordinated pretrial proceedings in multidistrict litigation. A defendant argues that the transferee court should apply the transferee state's choice-of-law rules to every case because all cases are now before that court. Which approach is correct?
Answer A: Apply the transferee state's choice rules to every transferred case
Answer B: Apply no state law because MDL creates a federal mass-tort law
Answer C: Apply the law and choice rules each transferor court would have applied
Answer D: Apply only the law of the state with the largest number of plaintiffs
Correct Answer: C
Correct Answer Explanation: The MDL transferee court generally respects the transferor law package for each transferred diversity case.
Wrong Answer Explanations: A: Coordinated pretrial transfer does not ordinarily erase the law that would have applied in each transferor court. B: MDL coordinates procedure; it does not create general federal substantive law for diversity claims. D: Plaintiff concentration is not the choice-of-law rule for transferred diversity cases.
lb_rule_reference: In multidistrict litigation, the transferee court generally applies the same state substantive law and choice-of-law rules that the transferor court would have applied to each transferred diversity case.
