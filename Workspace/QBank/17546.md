Question: In a federal negligence trial, Ruth does not request witness exclusion before opening statements. After the first witness finishes testifying, Ruth asks that all remaining nonexempt witnesses be excluded from the courtroom. The opponent argues that the request is too late because it was not made before the first witness testified. How should the court rule?
Answer A: Deny the request because witness exclusion must be requested before the first witness testifies or it is waived.
Answer B: Grant the request prospectively as to remaining nonexempt witnesses, although the order cannot undo testimony already heard.
Answer C: Deny the request unless Ruth proves the first witness lied.
Answer D: Grant the request only if the remaining witnesses are parties.
Correct Answer: B
Correct Answer Explanation: Rule 615 does not require the request to be made before the first witness testifies. The court should order remaining nonexempt witnesses excluded on request, but the order operates prospectively and does not erase testimony already given.
Wrong Answer Explanations: A: A imposes a strict timing waiver not in the rule. C adds a misconduct requirement. D reverses the party exception; parties are generally exempt from exclusion. D: A imposes a strict timing waiver not in the rule. C adds a misconduct requirement. D reverses the party exception; parties are generally exempt from exclusion.
