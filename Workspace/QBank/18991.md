Question: In a federal negligence trial, Daniel refreshes his memory on the stand with one page from a notebook. The page also contains notes about Daniel's unrelated dispute with his neighbor. Opposing counsel Esther asks to inspect the page. Daniel's lawyer objects that the unrelated notes should not be disclosed. What should the court do?
Answer A: Deny inspection entirely because the page contains unrelated material.
Answer B: Order Daniel to produce the entire page without review because any writing used to refresh memory must be disclosed in full.
Answer C: Examine the page in camera, delete unrelated matter, and order production of the related portion.
Answer D: Admit the page as an exhibit but instruct the jury to disregard the unrelated notes.
Correct Answer: C
Correct Answer Explanation: Rule 612 allows inspection of a writing used to refresh memory, but if the producing party claims that the writing contains unrelated matter, the court must examine the writing in camera, delete unrelated portions, and order delivery of the rest. Any deleted portion over objection must be preserved for the record.
Wrong Answer Explanations: A: A is wrong because unrelated matter does not defeat access to related portions. B: B is wrong because Rule 612 provides an in camera deletion process. D: D is wrong because the page is not automatically admitted as an exhibit merely because it refreshed memory.
lb_rule_reference: FRE 612(b) / unrelated matter and in camera deletion
lb_student_diagnostic: Tests redaction and in camera review under the refresh channel.
