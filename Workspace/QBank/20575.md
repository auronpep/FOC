Outline: Fourth Amendment
Question: Officers have probable cause to believe a car contains a stolen desktop computer tower. They search the trunk and back seat. They also open a tiny eyeglass case in the glove compartment and find pills. Was opening the eyeglass case justified by the automobile exception?
Answer A: No, because a desktop computer tower could not reasonably fit in the eyeglass case
Answer B: Yes, because probable cause for a vehicle permits every container search no matter the object
Answer C: Yes, because glove compartments are always searchable during car stops
Answer D: No, because the automobile exception never permits trunk searches
Correct Answer: A
Correct Answer Explanation: Probable cause defined the scope. Officers could search places where a desktop tower might be found, but not a container too small to hold it.
Wrong Answer Explanations: B: Scope is limited by where the object of the search could reasonably be located. C: A location is searchable only if the justification and object support searching there. D: The trunk and back seat could be searched for a computer tower. Only the tiny case exceeds scope.
lb_rule_reference: Probable cause to search a vehicle defines the permissible scope by the nature and size of the suspected item.
