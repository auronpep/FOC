Outline: Liquidated damages
Question: Rachel contracted with Samuel to cater a business dinner for $18,000. The contract contained a valid $3,500 liquidated-damages clause for customer cancellation, covering Samuel's expected lost profit, scheduling disruption, and administrative costs. Rachel canceled in breach. Samuel proved that the same covered cancellation losses actually totaled $2,200 and argued that he should receive both the $3,500 clause amount and the $2,200 actual loss. What is Samuel's maximum recovery for those cancellation losses?
Answer A: $2,200, because actual damages are known after breach.
Answer B: $5,700, because the liquidated amount and actual damages both resulted from Rachel's breach.
Answer C: $3,500, because the valid liquidated-damages amount substitutes for actual damages covering the same cancellation loss.
Answer D: Nothing, because Samuel cannot prove that Rachel's cancellation caused every administrative cost listed in the clause.
Correct Answer: C
Correct Answer Explanation: The remedy interest is expectation under common law, measured by a valid liquidated-damages clause. The breach posture is customer cancellation, and the loss category is the set of cancellation losses that the clause covers. Because the clause is valid, the formula is the stipulated amount, $3,500. The offset and anti-stacking gate prevents adding $2,200 in actual damages for the same covered loss. The result scope is limited to the liquidated amount and does not decide any separate loss outside the clause.
Wrong Answer Explanations: A: A is wrong because it substitutes later actual damages for a valid stipulated measure. B: B is wrong because it stacks two measures for the same loss, triggering WAL-REM-008. D: D is wrong because a valid liquidated-damages clause avoids the need to prove every covered component after breach, so nominal or no recovery is not the right fallback.
lb_rule_reference: Common law liquidated damages — valid stipulated amount substitutes for actual damages covering the same loss
