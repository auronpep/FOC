Question: A candidate challenges a ballot-access rule that applies only during a six-week election filing window. The election ends while the case is on appeal. The candidate credibly plans to run for the same office in the next election, when the same rule will apply again. Which mootness principle is most relevant?
Answer A: The case is automatically moot because the election ended
Answer B: The exception may apply because the dispute is short-lived and likely to recur for the same candidate
Answer C: The exception applies whenever an issue is important to the public
Answer D: The case is not moot because every voter could sue instead
Correct Answer: B
Correct Answer Explanation: The filing window is too short for full review, and the same candidate is reasonably likely to face the same rule again.
Wrong Answer Explanations: A: Short election disputes can fall within the capable-of-repetition-yet-evading-review exception when recurrence to the same plaintiff is likely. C: Public importance is not the exception; the action must evade review and be likely to recur for the same complaining party. D: The exception focuses on recurrence for the same complaining party in this case.
lb_rule_reference: A case may avoid mootness when the challenged action is too short to be fully litigated before ending and there is a reasonable expectation that the same complaining party will face it again.
