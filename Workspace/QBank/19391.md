Question: Deborah owned Gardenacre, which had an appurtenant easement over Gideon's adjoining lot. Deborah signed and delivered a valid written release of the easement to Gideon. Deborah later conveyed Gardenacre to Samuel. The deed to Samuel stated that Gardenacre was conveyed “with all appurtenances.” May Samuel use the former easement over Gideon's lot?
Answer A: Yes, because the deed to Samuel used the phrase “with all appurtenances.”
Answer B: No, because Deborah had already released the easement before conveying Gardenacre to Samuel.
Answer C: Yes, because an appurtenant easement cannot be released by the dominant owner.
Answer D: No, but only because Samuel personally did not sign the earlier release.
Correct Answer: B
Correct Answer Explanation: Samuel may not use the easement. Deborah, as the easement holder, validly released it before conveying Gardenacre. A later deed conveying “all appurtenances” passes only existing appurtenant rights; it does not recreate an easement that has already been terminated.
Wrong Answer Explanations: A: A is wrong because there was no existing easement left to pass. C: C is wrong because the easement holder can release the easement. D: D is wrong because Samuel takes Gardenacre subject to the legal effect of Deborah's earlier valid release.
lb_rule_reference: Release / termination of easement by holder
