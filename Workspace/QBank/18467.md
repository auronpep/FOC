Outline: Erie Doctrine
Question: In a diversity product-liability case, the plaintiff files a complaint satisfying Federal Rules 8 and 11. The forum state requires every complaint in that type of case to attach a state-law pleading certificate, and says a complaint without the certificate must be dismissed at filing. No federal statute incorporates the certificate requirement. What is the best Erie analysis?
Answer A: Apply the state certificate rule because the state calls it mandatory
Answer B: Apply Federal Rules 8 and 11 if they directly control the pleading question and are valid
Answer C: Dismiss automatically because diversity jurisdiction always imports state filing procedures
Answer D: Ignore both state and federal rules and ask only whether dismissal changes the outcome
Correct Answer: B
Correct Answer Explanation: Hanna asks first whether a valid federal directive is on point.
Wrong Answer Explanations: A: State labels do not control when valid Federal Rules directly govern pleading. C: Diversity does not mean every state procedural step applies. D: Outcome testing is not first when a Federal Rule controls.
lb_rule_reference: When a Federal Rule directly answers a procedural question and is valid, it governs under Hanna.
