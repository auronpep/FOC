Subtopic: Relevancy and Excluding Relevant Evidence
Outline: Discretionary exclusion (undue prejudice, confusion, waste of time)
Question: In a California civil trial, Boaz offers 25 witnesses to testify that a store aisle was bright enough to see a spill. The first five witnesses already gave the same description from the same viewpoint. The store objects under Evidence Code section 352 that the remaining testimony would consume undue time and be cumulative. How should the court rule under California law?
Answer A: Overrule the objection because California section 352 applies only to criminal cases.
Answer B: Overrule the objection because relevant evidence cannot be excluded for undue consumption of time.
Answer C: Sustain the objection if the court determines the probative value of the additional repetitive testimony is substantially outweighed by undue consumption of time or cumulative presentation concerns.
Answer D: Sustain the objection only if the store proves the witnesses are lying.
Correct Answer: C
Correct Answer Explanation: California Evidence Code section 352 permits discretionary exclusion when probative value is substantially outweighed by undue consumption of time or dangers such as undue prejudice, confusing issues, or misleading the jury. Repetitive testimony from the same viewpoint may be excluded or limited.
Wrong Answer Explanations: A: A is wrong because section 352 applies in civil trials as well as criminal trials. B: B is wrong because section 352 expressly permits exclusion of relevant evidence in proper circumstances. D: D is wrong because the issue is time/cumulative value, not witness dishonesty.
lb_rule_reference: CEC §352
lb_student_diagnostic: Student misses the California §352 counterweight and treats relevance as mandatory admission.
