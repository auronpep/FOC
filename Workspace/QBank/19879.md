Question: Daniel agreed to design and install a security system for Hannah's store for $20,000, payable in two installments: $10,000 at signing and $10,000 when the system was operational. Daniel installed only half the cameras, left the control panel nonfunctional, and then walked off the job. Hannah refused to pay the final $10,000. If Daniel sues for the final installment, what is the likely result?
Answer A: Daniel wins because Hannah received some benefit from the partially installed cameras.
Answer B: Hannah wins because Daniel's material failure to make the system operational prevents the final payment duty from maturing.
Answer C: Daniel wins because any breach after partial performance is only a minor breach.
Answer D: Hannah wins only if she proves Daniel acted in bad faith.
Correct Answer: B
Correct Answer Explanation: The final payment was tied to the system being operational. Daniel's incomplete and nonfunctional installation is a material failure of the constructive condition to final payment. Hannah's final payment duty has not matured.
Wrong Answer Explanations: A: A is wrong because some benefit does not automatically create a right to the final contract installment. C: C is wrong because a serious incomplete performance can be material. D: D is wrong because material breach does not require proof of bad faith.
lb_rule_reference: Common-law material breach
