Subtopic: Intentional Torts
Outline: Trespass to land
Question: During an argument over a shared driveway, Neighbor intentionally threw a heavy bucket over Owner's fence so it would land in Owner's vegetable garden. The bucket crushed several plants. Neighbor never crossed the fence. Owner sues Neighbor for trespass to land. Is Neighbor likely liable?
Answer A: No, because Neighbor's body never entered Owner's land
Answer B: No, because trespass requires permanent damage to the land itself
Answer C: Yes, because Neighbor intentionally caused a tangible object to enter Owner's land
Answer D: Yes, but only because the bucket damaged plants
Correct Answer: C
Correct Answer Explanation: Neighbor deliberately threw the bucket over the fence and onto Owner's property. That intentional object entry supports trespass to land.
Wrong Answer Explanations: A: Causing a physical object to enter another's land can be trespass. B: Trespass protects possessory interests and does not require permanent land damage. D: The intentional entry itself is the trespass. Damage is not required, though it affects recovery.
lb_rule_reference: A person commits trespass to land by intentionally causing a physical object to enter another's land, even if the person does not enter personally.
