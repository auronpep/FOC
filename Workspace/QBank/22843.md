


BARMATRIX Q#: 22843
Outline_code: 91090400
MBE Subjects (1 of 7): Civil Procedure
Subtopic: Jury Trials
Outline: Jury Instructions
Question: A man sued a corporation in federal district court based on diversity. After the evidence was presented, the corporation filed a written request for the jury instructions it wanted the court to give. The man felt that several of the instructions were incorrect statements of law and were unfairly prejudicial. How should the man proceed?
Answer A: A: The man should file a general objection based on misstatement of law under Rule 51(c).
Answer B: B: The man should file objections to each instruction stating the specific grounds for each objection.
Answer C: C: The man should file a general objection based on unfair prejudice under Rule 403.
Answer D: D: The man should file a general objection based on plain error under Rule 51(d).
Correct Answer: B
Correct Answer Explanation: Under Fed. R. Civ. P. 51(c)(1), “(a) party who objects to an instruction or the failure to give an instruction must do so on the record, stating distinctly the matter objected to and the grounds for the objection.” Consequently, the man should file objections to each instruction, stating the grounds for each. A, C, and D are incorrect because there is no rule allowing a general objection. Additionally, C is incorrect because Rule 403 is a rule of evidence, not civil procedure.
