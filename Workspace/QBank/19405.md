Question: Cal lost a contract case at trial, and the trial judgment was later used against him in a second action. While the second action was pending, the appellate court reversed the first judgment and remanded for a new trial. What happens to the preclusion argument based on the first judgment?
Answer A: It remains binding because a trial judgment can never lose preclusive effect
Answer B: It remains binding only for issue preclusion, never claim preclusion
Answer C: It generally falls away because the judgment supporting preclusion has been reversed
Answer D: It automatically proves Cal should win the second action
Correct Answer: C
Correct Answer Explanation: A reversed judgment is no longer a valid final foundation for preclusion.
Wrong Answer Explanations: A: Reversal undermines the judgment that supplied preclusion. B: Reversal can defeat both claim-preclusive and issue-preclusive reliance on the judgment. D: Reversal removes the preclusion foundation; it does not decide the second action's merits.
lb_rule_reference: When the judgment supporting preclusion is reversed, its claim-preclusive and issue-preclusive force generally falls away.
