Question: Caleb owned Lot A and Lot B. While he owned both lots, a paved lane across Lot B was used daily to reach a cottage on Lot A. The lane was visible and permanent. Caleb sold Lot A to Abigail. Lot A also had a narrow legal path to a public road, but the path was too narrow for ordinary residential deliveries and emergency vehicles. Abigail claims an implied easement by prior use over the paved lane. Which statement is most accurate?
Answer A: The claim fails because prior-use easements require complete landlock.
Answer B: The claim may succeed because prior use requires reasonable necessity, not strict necessity.
Answer C: The claim fails because the lane was used daily and daily use proves only a license.
Answer D: The claim succeeds only if Abigail proves that Caleb expressly promised the lane in a separate contract.
Correct Answer: B
Correct Answer Explanation: Unlike an easement by necessity, an implied easement by prior use generally requires reasonable necessity. The visible, daily, pre-severance lane use and the practical need for ordinary access support the prior-use route even though Lot A is not completely landlocked.
Wrong Answer Explanations: A: A is wrong because complete landlock is a necessity concept, not a prior-use requirement. B is correct for the reasons above. C: C is wrong because daily use can support a continuous quasi-easement. D: D is wrong because the issue is implication from severance, not an express contract promise.
lb_rule_reference: Reasonable necessity for prior-use easement
lb_student_diagnostic: The trap is importing strict necessity into every implied-easement question.
