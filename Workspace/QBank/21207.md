Subtopic: Relevancy and Excluding Relevant Evidence
Outline: Laying a Foundation
Question: In a federal robbery trial, the victim testifies that the robber wore a red scarf. Ten minutes after the robbery, police found a red scarf in a trash can on the only alley route from the store. A security video shows a person matching Isaac's build running down that alley immediately after the robbery. Isaac objects that no witness saw him wearing the scarf. How should the court rule?
Answer A: Exclude the scarf because no witness saw Isaac wearing it.
Answer B: Exclude the scarf because only direct evidence can connect an exhibit to a defendant.
Answer C: Admit the scarf only if Isaac's fingerprints are found on it.
Answer D: Admit the scarf if the circumstantial evidence is sufficient for a reasonable jury to find it connected to the robbery.
Correct Answer: D
Correct Answer Explanation: A physical object can be connected to a case through circumstantial evidence. The red scarf, the victim's description, the timing, the route, and the video provide enough foundation for the jury to decide its significance.
Wrong Answer Explanations: A: A is wrong because direct sighting is not required. B: B is wrong because circumstantial foundation can be sufficient. C: C is wrong because fingerprint evidence is not a required foundation method.
lb_rule_reference: FRE 104(b) / conditional relevance / circumstantial object link
lb_student_diagnostic: Tests circumstantial object identification and the direct-proof false positive.
