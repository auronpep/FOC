Outline: Removal to Federal Court
Question: A plaintiff files a state-law products case in State A court. The defendant removes the case to the federal district court sitting in State A based on diversity. The injury occurred in State B and the product was made in State C. Which choice-of-law rules should the federal court use?
Answer A: State A's choice-of-law rules, because the case was filed in and removed from State A
Answer B: State B's choice-of-law rules, because the injury occurred there
Answer C: State C's choice-of-law rules, because the product was made there
Answer D: Federal common-law choice rules, because removal federalized the case
Correct Answer: A
Correct Answer Explanation: Under Klaxon, the federal diversity court uses the choice rules of the forum state; removal to the federal court in the same state does not change that anchor.
Wrong Answer Explanations: B: It does not select the choice-of-law rules in the first instance. C: Product origin may be a contact, but it does not choose the forum's conflict rules. D: Removal does not create an independent federal choice-of-law system for an ordinary diversity state-law claim.
lb_rule_reference: A federal court hearing a removed diversity case applies the choice-of-law rules of the state in which the action was originally filed and from which it was removed.
