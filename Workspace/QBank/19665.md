Subtopic: Hearsay and Circumstances of Its Admissibility
Outline: Statement by opposing party
Question: In a federal negligence trial, John testifies that he inspected a ladder on Monday. On cross-examination, the opposing party shows John a signed note he wrote two days after the accident stating, “I did not inspect the ladder until Wednesday.” John admits writing the note. The note does not qualify under any hearsay exception and is not an opposing-party statement. John's party requests a limiting instruction. How should the court handle the note?
Answer A: Exclude the note for all purposes because prior inconsistent statements can never be used unless sworn.
Answer B: Admit the note as substantive proof that John inspected the ladder on Wednesday.
Answer C: Allow the note to impeach John's credibility and, on timely request, instruct the jury not to use it for the truth of the Wednesday inspection fact.
Answer D: Allow the note only if John first denies writing it.
Correct Answer: C
Correct Answer Explanation: A prior inconsistent statement that does not qualify for substantive use may still be used to impeach. If admitted for impeachment but not for truth, the court must give a limiting instruction on timely request.
Wrong Answer Explanations: A: A is wrong because impeachment use can be allowed even when substantive use is unavailable. B: B is wrong because the facts do not supply an independent substantive route. D: D is wrong because John's admission does not bar impeachment use; denial is not required.
lb_rule_reference: FRE 105 and 613 / impeachment-only document use
lb_student_diagnostic: Tests impeachment-only versus substantive-use collapse and limiting-instruction mechanics.
