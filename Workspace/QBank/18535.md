Subtopic: Motions
Outline: Motion for more definite statement
Question: A complaint alleges that "Defendant's acts harmed plaintiff" without identifying which of three defendants acted, what conduct occurred, or when. The defendants cannot reasonably admit, deny, or assert defenses. They move for a more definite statement. Is Rule 12(e) a plausible route?
Answer A: Yes, because the pleading is too vague to permit a reasonable response
Answer B: Yes, because defendants may use Rule 12(e) to demand all evidence
Answer C: No, because vague complaints can never be challenged
Answer D: No, because Rule 12(e) applies only after trial
Correct Answer: A
Correct Answer Explanation: Rule 12(e) fits when ambiguity prevents a responsive pleading.
Wrong Answer Explanations: B: Evidence comes through discovery, not a more definite statement. C: Rule 12(e) exists for this situation. D: It is a pleading-stage motion.
lb_rule_reference: A more definite statement is proper only for unintelligible pleadings, not ordinary discovery needs.
