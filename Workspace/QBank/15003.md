Question: The owner of land located in State A transferred the title of the land to a buyer. The buyer, a resident of State B, subsequently filed a suit against the owner in the federal district court of State A, alleging that the owner's transfer, effectuated in State B, was fraudulent. Federal jurisdiction was based on diversity. The buyer is seeking money damages based on the buyer's reliance on the owner's fraudulent transfer. Will State B's substantive laws apply to the buyer's fraud claim?
Answer A: A: No, because the suit was filed in State A, so State A's substantive laws will apply.
Answer B: B: No,becausethe property is located in State A, so State A's substantive laws will apply.
Answer C: C: Yes, becauseState B has the greatest interest in the dispute.
Answer D: D: Yes,because State B is where the buyer lives.
Correct Answer: C
Correct Answer Explanation: C is correct. As the site where the fraud took place and where the buyer resides, State B's substantive laws will apply because it has the greatest interest in the outcome of the lawsuit.
Wrong Answer Explanations: A is incorrect. The federal court is required to apply the choice of law rules based upon the competing interests of the states involved. Because this involves fraudulent damages for a conveyance, State B's interests prevail. B is incorrect. This is the rule for cases involving only property issues (such as whether a covenant should be upheld as valid). However, the central dispute here is whether to award the buyer damages based on a fraudulent conveyance, and the alleged fraudulent activity occurred in State B, so that is the most interested location. D is incorrect. Domicile is not outcome-determinative for the purpose of determining which rules a court should apply when multiple states have an interest in a case. Here, it is the combination of the fact that the fraud allegedly occurred in State B, in addition to the fact that the buyer lives in State B, that will cause State B to have the greatest interest in resolving this dispute.
