Question: A named plaintiff challenges a prison mail policy and the court certifies a class of affected prisoners. The named plaintiff is later transferred to a facility that does not use the policy, but other certified class members remain subject to it. Does the transfer necessarily moot the certified class action?
Answer A: Yes, because the named plaintiff personally no longer faces the policy
Answer B: Yes, because prisoners cannot maintain class actions
Answer C: No, not if the certified class still has members subject to the challenged policy
Answer D: No, but only because transfer is voluntary cessation by the defendant
Correct Answer: C
Correct Answer Explanation: The class controversy remains live through members still affected by the policy.
Wrong Answer Explanations: A: Once a class is properly certified, the class's live controversy can continue even if the named plaintiff's individual claim becomes moot. B: There is no categorical bar stated here that makes all prisoner class actions impossible. D: The stronger fact is certified class posture with remaining affected members.
lb_rule_reference: In a properly certified class action, mootness of the named plaintiff's individual claim does not necessarily moot the class's live controversy.
