Subtopic: Relations Between Federal and State Governments
Outline: Tenth Amendment
Question: Congress enacts a statute ordering each state legislature to pass a state law requiring private recycling companies to use federally specified labels. If a state legislature refuses, the statute says the state is in violation of federal law. What is the best Tenth Amendment objection?
Answer A: Congress may not require state legislatures to enact federal regulatory commands
Answer B: The statute is valid because federal supremacy allows Congress to command states whenever commerce is affected
Answer C: The statute is invalid because Congress can never regulate private recycling companies
Answer D: The statute is valid because states can avoid the command by leaving the Union
Correct Answer: A
Correct Answer Explanation: The law commandeers state legislative processes rather than regulating private actors directly or validly preempting state law.
Wrong Answer Explanations: B: Supremacy allows valid federal law to preempt state law; it does not allow Congress to order state legislatures to legislate. C: Congress might regulate private companies directly under a valid power; the defect is ordering states to legislate. D: States are not subject to commandeering merely because they are part of the federal system.
lb_rule_reference: Congress may not commandeer state legislatures by requiring them to enact or maintain federal regulatory programs.
