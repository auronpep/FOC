Question: Solomon owned Lot A and Lot B. Before selling Lot A to Leah, Solomon used a driveway across Lot B to reach a storage shed on Lot A. The driveway was visible. The deed conveying Lot A to Leah stated: “Grantee takes Lot A with no right to use any driveway located on Lot B.” Leah later claims an implied easement by prior use over the driveway on Lot B. What is the best result?
Answer A: Leah has the implied easement because visible prior use always overrides deed language.
Answer B: Leah has an easement by necessity because the driveway is useful for reaching the shed.
Answer C: Leah likely has no implied easement because the express deed language negates the claimed access right.
Answer D: Leah owns the driveway by prescription because Solomon used it before the sale.
Correct Answer: C
Correct Answer Explanation: Implied easements fill gaps in conveyances; they do not ordinarily contradict express terms. Although the driveway was visible and used before severance, the deed expressly stated that Leah took no right to use driveways on Lot B.
Wrong Answer Explanations: A: A is wrong because prior use does not automatically override express contrary language. B: B is wrong because usefulness is not strict necessity, and the deed negates the claimed access. C is correct for the reasons above. D: D is wrong because Solomon's pre-sale use of his own land was not prescriptive.
lb_rule_reference: Implied easement limited by express deed terms
lb_student_diagnostic: The repair signal is to read the deed before implying a gap-filling property right.
