Outline: Definition
Question: In a federal products-liability trial, Ezekiel claims that a grain mill made by Naomi Industries malfunctioned because a safety lever stuck. Ezekiel offers evidence that another customer complained to Naomi Industries about the same lever sticking two weeks before the accident. Naomi Industries objects that the earlier complaint does not prove Ezekiel's lever stuck. How should the court rule?
Answer A: Exclude the evidence because a prior complaint is relevant only if it conclusively proves the same defect.
Answer B: Exclude the evidence because other customer complaints are never relevant.
Answer C: Admit the evidence only if Ezekiel proves the other customer's accident was identical in every detail.
Answer D: Admit the evidence because the prior complaint tends to make notice of a possible lever problem more probable.
Correct Answer: D
Correct Answer Explanation: A prior complaint about the same safety lever tends to show notice of a possible defect. It need not prove that Ezekiel's lever actually stuck to be relevant for notice.
Wrong Answer Explanations: A: A overstates the proof required for relevance. B is categorically wrong; other complaints can be relevant for notice when tied to the same issue.
