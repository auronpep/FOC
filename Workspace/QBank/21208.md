Question: Samuel owned Lot 1, which benefited from a recorded driveway easement over Naomi's Lot 2. Samuel signed and delivered a written release stating, “I release and terminate the driveway easement over Lot 2.” The release was recorded. Two years later, Samuel sold Lot 1 to Hannah, whose deed did not mention the release. Hannah now claims the old easement still exists. Which result is most accurate?
Answer A: The easement was terminated by Samuel's written release, so Hannah did not acquire that easement with Lot 1.
Answer B: The easement survived because appurtenant easements can never be released.
Answer C: The easement survived because Hannah personally did not sign the release.
Answer D: The release only changed the easement into a license that Hannah may revoke at will.
Correct Answer: A
Correct Answer Explanation: An easement holder may terminate the easement by a legally effective release, ordinarily in a writing satisfying the statute of frauds. Samuel, then owner of the dominant estate, signed and delivered a release. Once extinguished, the easement did not pass to Hannah.
Wrong Answer Explanations: B: B is wrong because appurtenant easements can be released. C: C is wrong because Hannah cannot acquire an easement that Samuel had already extinguished. D: D is wrong because a release terminates the easement; it does not convert it into a license.
lb_rule_reference: Termination by written release
lb_student_diagnostic: The trap is assuming appurtenant rights always pass with land even after the dominant owner has formally extinguished them.
