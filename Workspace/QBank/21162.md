Outline: Refreshing recollection
Question: In a federal criminal trial, a prosecution witness, Nathan, refreshes his memory on the stand with an investigative note. The court orders the prosecutor to produce the note for the defense. The prosecutor refuses to produce it. The defense moves for relief. What must the court do?
Answer A: Take no action because the note was not offered into evidence.
Answer B: Order only a limiting instruction telling the jury that the note is not substantive evidence.
Answer C: Strike Nathan's testimony or, if justice so requires, declare a mistrial.
Answer D: Admit the note as substantive evidence so the jury can decide whether Nathan relied on it properly.
Correct Answer: C
Correct Answer Explanation: Rule 612(c) provides that if the prosecution does not comply in a criminal case with an order to produce or deliver a writing used to refresh memory, the court must strike the witness's testimony or, if justice so requires, declare a mistrial.
Wrong Answer Explanations: A: A is wrong because Rule 612 production rights do not depend on the proponent offering the writing into evidence. B: B is wrong because a limiting instruction is not the required remedy for prosecution noncompliance. D: D is wrong because the remedy is not automatic substantive admission of the writing.
lb_rule_reference: FRE 612(c) / prosecution noncompliance in criminal case
lb_student_diagnostic: Tests the special criminal-prosecution consequence for failure to produce a refreshing writing.
