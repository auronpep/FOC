


BARMATRIX Q#: 22736
Outline_code: 94030100
MBE Subjects (1 of 7): Civil Procedure
Subtopic: Jurisdiction and Venue
Outline: Removal to Federal Court
Question: A woman from State A kept a bank account in State B for 50 years. The woman became ill and moved to State C so her daughter could take care of her. She intended to stay in State C permanently. The woman died shortly thereafter in State C. The daughter, the executrix of the woman's estate, discovered evidence that someone at the bank had stolen funds from the woman's bank account. The daughter sued the bank in State C court. The bank claimed that it was not subject to suit in State C because its only branches were in State B, it sent all correspondence to the woman to her address in State A, and it did not know that the woman had moved to State C. Does the court have jurisdiction over the bank?
Answer A: A: Yes, because it held a bank account for a State C resident.
Answer B: B: Yes, because it held a bank account subject to probate in State C.
Answer C: C: No, because it did not intentionally do business in State C.
Answer D: D: No, because it is being sued in state court in State C.
Correct Answer: C
Correct Answer Explanation: A court does not have personal jurisdiction over a party if there are insufficient contacts between the jurisdiction and the party. Here, the bank has no branch in State C, and it does no business in State C. Additionally, it did not know the woman had moved and continued to send all correspondence to the woman's State A address. Thus, the bank has no contacts at all with State C and cannot be sued there. A is incorrect because the simple fact the bank held an account for a State C resident is not enough to create personal jurisdiction because the bank did not direct any business to State C and did not know that the woman had moved. B is incorrect because the potential probate issue does not change the analysis. D is incorrect because the fact this is State C state court does not change the analysis.
