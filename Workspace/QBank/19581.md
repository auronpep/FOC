Outline: Issue and Claim Preclusion
Question: Deborah sues Samuel for fraud. Samuel never appears, and default judgment is entered. Deborah later sues Samuel on a different transaction and argues that the default judgment conclusively establishes Samuel's fraudulent intent in the new case. Should issue preclusion apply to intent?
Answer A: Yes, because every judgment decides every pleaded allegation for all later cases
Answer B: Yes, because fraud was alleged in the first complaint
Answer C: No, because the issue was not actually litigated in the default proceeding
Answer D: No, because default judgments are never valid judgments for any purpose
Correct Answer: C
Correct Answer Explanation: Default judgments usually do not satisfy the actual-litigation requirement for issue preclusion.
Wrong Answer Explanations: A: Issue preclusion requires actual litigation, not merely allegations in a defaulted complaint. B: Allegation is not actual litigation. D: A default can have claim-preclusive effect even if it does not establish actually litigated issues.
lb_rule_reference: Issue preclusion requires the precise issue to have been actually litigated and determined.
