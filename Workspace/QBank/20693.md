MBE Subjects (1 of 7): Torts
Subtopic: Negligence
Outline: Cause in fact (actual cause)
Question: Two drivers, one from each direction, both ran red lights and struck a pedestrian at the same instant. Medical experts testify that either collision alone would have caused the same indivisible leg injury. One driver argues that the pedestrian cannot prove but-for causation because the other collision would have caused the injury anyway. Is that driver likely to defeat actual cause on this argument?
Answer A: Yes, because but-for causation always fails whenever another cause exists
Answer B: Yes, because each driver is liable only if the other driver was careful
Answer C: No, because each collision was a substantial factor in the indivisible injury
Answer D: No, because actual cause is irrelevant in negligence claims
Correct Answer: C
Correct Answer Explanation: Each negligent collision was independently sufficient to cause the same injury. The driver cannot use the other sufficient cause to defeat actual cause.
Wrong Answer Explanations: A: Substantial-factor analysis handles multiple sufficient causes so neither negligent actor escapes because the other was also sufficient. B: Multiple negligent actors can each cause one indivisible injury. D: Actual cause is required; the plaintiff satisfies it through substantial-factor analysis.
lb_rule_reference: When two negligent acts are each sufficient to cause one indivisible injury, each can be an actual cause under substantial-factor analysis.
