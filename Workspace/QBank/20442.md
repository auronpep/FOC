Question: The district court denies a discovery extension during an ongoing case. The losing party argues immediate appeal is proper because the appellate court would review scheduling decisions for abuse of discretion. What is wrong with the argument?
Answer A: It confuses the standard of review with whether the order is appealable now
Answer B: It is correct because every abuse-of-discretion issue is immediately appealable
Answer C: It is wrong because discovery orders are reviewed de novo
Answer D: It is correct only if the parties are diverse
Correct Answer: A
Correct Answer Explanation: Abuse-of-discretion review matters only after a valid appellate route exists.
Wrong Answer Explanations: B: Review standard does not create finality. C: The problem is appealability, not which standard would apply. D: Diversity does not make ordinary interlocutory orders appealable.
lb_rule_reference: Finality and appealability are jurisdictional routing questions; standards of review govern merits review after a valid appeal exists.
