MBE Subjects (1 of 7): Torts
Subtopic: Strict Liability and Products Liability
Outline: Abnormally Dangerous Activities
Question: In a rural farming county, aerial crop spraying is common and regulated. A farmer hires a licensed pilot to spray ordinary crop treatment over the farmer's fields. A neighbor claims that crop spraying is dangerous and sues the farmer only on an abnormally dangerous activity strict-liability theory after mild spray drift damages garden plants. What is the farmer's strongest response to strict liability?
Answer A: The activity is not automatically abnormally dangerous merely because it involves some risk
Answer B: The farmer is strictly liable because any chemical use is abnormally dangerous
Answer C: The farmer is strictly liable only if the pilot was an employee rather than an independent contractor
Answer D: The farmer wins only because the neighbor suffered plant damage rather than personal injury
Correct Answer: A
Correct Answer Explanation: Context matters. A common agricultural activity with risks manageable by ordinary precautions may not be classified as abnormally dangerous simply because it can cause harm.
Wrong Answer Explanations: B: The inquiry is contextual; not every chemical or crop-spraying use is automatically abnormally dangerous. C: The call asks whether the activity itself triggers strict liability. Employee status is not the primary abnormal-danger gate. D: Strict liability can cover property damage if the doctrine applies. The stronger issue is whether this activity is abnormally dangerous in context.
lb_rule_reference: Whether an activity is abnormally dangerous depends partly on context, including commonness of the activity in the community and whether the risk can be managed by reasonable care.
