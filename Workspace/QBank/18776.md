Question: Caleb granted Hannah, as owner of Cabin Lot, “a right to use the private road for access to the single-family residence on Cabin Lot.” Hannah later converted the residence into a public event hall. Hundreds of guests began using the private road each week, creating noise, congestion, and wear far beyond prior residential use. Caleb sues to limit the road use. Which is the best result?
Answer A: Hannah may use the road for the event hall because all access to Cabin Lot is within the easement.
Answer B: Hannah may use the road for any lawful business because zoning permits the event hall.
Answer C: Caleb may limit the use because the express easement was for access to a single-family residence, not materially greater public event traffic.
Answer D: Caleb may terminate the easement only if Hannah never again uses the road for residential access.
Correct Answer: C
Correct Answer Explanation: An express access easement is limited by its stated purpose and the burden reasonably contemplated at creation. A grant for access to a single-family residence does not automatically authorize heavy public event traffic that materially changes the burden on the servient road.
Wrong Answer Explanations: A: A is wrong because access to the same parcel can still exceed a purpose-limited grant. B: B is wrong because zoning permission does not expand private easement scope. C is correct because the traffic materially departs from the residential-access purpose. D: D is wrong because the remedy for overuse is not limited to termination after total nonuse.
lb_rule_reference: Purpose-limited access / commercial expansion
