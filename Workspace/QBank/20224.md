Subtopic: Relevancy and Excluding Relevant Evidence
Outline: Laying a Foundation
Question: Ruth is charged with unlawfully entering Daniel's storage room. The prosecutor offers a key found in Ruth's purse. A locksmith testifies that the key is cut in a pattern consistent with Daniel's storage-room lock, but that he did not test the key in the actual lock before trial. Ruth objects that the key is irrelevant unless the prosecutor proves it opens the lock. How should the court rule?
Answer A: Exclude the key because only actual testing in the lock can make it relevant.
Answer B: Admit the key if the locksmith's testimony and surrounding facts are sufficient to support a finding that the key fits the lock.
Answer C: Admit the key only if Ruth first fails to produce a different explanation for possessing it.
Answer D: Exclude the key because expert testimony about consistency is never enough to support relevance.
Correct Answer: B
Correct Answer Explanation: The key is relevant if a jury could reasonably find that it was connected to the lock. The court screens for sufficient evidence to support that finding. The lack of direct testing is a weight argument, not an automatic relevance bar.
Wrong Answer Explanations: A: A is wrong because the proponent need not use the strongest possible foundation method. C: C is wrong because the burden is not on Ruth to explain possession before the key may be admitted. D: D is wrong because consistency testimony can help establish a threshold connection.
lb_rule_reference: FRE 104(b) / FRE 401
lb_student_diagnostic: Over-demanding the foundation method and confusing best proof with sufficient proof.
