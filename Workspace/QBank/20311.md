Outline: Uniform Commercial Code (UCC)
Question: Joshua orally discussed buying 900 tools from Miriam for $1 each. No writing was signed. In court, Joshua testifies, “Miriam and I discussed price and delivery, but I never agreed to buy the tools.” Miriam argues that Joshua's testimony admits enough to satisfy UCC §2-201. Is Miriam correct?
Answer A: No, because an admission exception requires an admission that a contract for sale was made, not merely that negotiations occurred.
Answer B: Yes, because discussing price and delivery is enough to admit a contract.
Answer C: Yes, because UCC §2-201 treats any testimony about negotiations as a signed writing.
Answer D: No, because admissions under UCC §2-201 apply only to land contracts.
Correct Answer: A
Correct Answer Explanation: The UCC admission exception requires the party against whom enforcement is sought to admit that a contract for sale was made. An admission that negotiations occurred, coupled with denial of agreement, does not satisfy the exception.
Wrong Answer Explanations: B: B is wrong because negotiations are not the same as an admitted contract. C: C is wrong because testimony is not treated as a signed writing merely because it describes negotiations. D: D is wrong because UCC §2-201 applies to goods, not land.
lb_rule_reference: UCC §2-201 / negotiations not admission
