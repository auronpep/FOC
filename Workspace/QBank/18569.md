Question: A power tool lacked a warning that users should wear eye protection when cutting metal. The injured user admits that he already knew eye protection was recommended, owned goggles, and would not have worn them even if the tool had displayed a large warning. A metal fragment injured his eye. What is the manufacturer's strongest defense to the failure-to-warn claim?
Answer A: The missing warning did not cause the injury because the user would not have followed an adequate warning
Answer B: The manufacturer is liable because any missing warning creates strict liability
Answer C: The manufacturer is liable because eye injuries are severe
Answer D: The claim automatically becomes a design-defect claim
Correct Answer: A
Correct Answer Explanation: Warning defect requires that the absence or inadequacy of the warning cause the harm. The user's admission breaks warning causation.
Wrong Answer Explanations: B: A missing warning is not enough if a warning would not have changed the user's conduct. C: Severity does not prove warning causation. D: The facts test warning causation; no design alternative is supplied.
lb_rule_reference: Failure to warn requires causation; no liability if an adequate warning would not have changed the user's conduct.
