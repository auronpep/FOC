Subtopic: Verdicts and Judgments
Outline: Issue and Claim Preclusion
Question: A prior state judgment for a landlord rested on two independent grounds: the lease had expired and the tenant had materially breached. The state's preclusion law says alternative independent grounds are not treated as essential unless affirmed on appeal. The tenant did not appeal. In a later case, the landlord asserts issue preclusion on material breach. Under that state's rule, should material breach be automatically precluded?
Answer A: Yes, because every finding in a judgment is always essential
Answer B: Yes, because landlords receive broader preclusion rules
Answer C: No, because the state's governing rule does not treat the unappealed alternative ground as essential
Answer D: No, because issue preclusion can never apply to state judgments
Correct Answer: C
Correct Answer Explanation: Issue preclusion requires an essential determination as defined by the applicable preclusion law.
Wrong Answer Explanations: A: Essentiality depends on governing preclusion law, especially for alternative holdings. B: Party status does not create a special landlord rule. D: State judgments can have issue-preclusive effect, but the applicable elements must be met.
lb_rule_reference: Issue preclusion applies only to determinations treated as essential to the judgment under the governing preclusion law.
