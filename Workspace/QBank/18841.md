Subtopic: Rights in Land
Outline: Equitable Servitudes / Restrictive Covenants
Question: David owned Lot 1 and Lot 2 in a small lakeside development. When David sold Lot 1 to Samuel, the deed stated that Lot 1 could be used only for residential purposes. The restriction benefited David's retained Lot 2, but the deed was not recorded. Samuel later contracted to sell Lot 1 to Ruth. Before closing, David told Ruth about the residential-use restriction, and Ruth replied, “I know about it, but I plan to build a store anyway.” Ruth received a deed that did not mention the restriction. David seeks an injunction preventing Ruth from building the store. Which is the best result?
Answer A: Ruth is bound because she had actual notice of an equitable servitude touching the land.
Answer B: Ruth is not bound because the restriction was not recorded.
Answer C: Ruth is not bound because horizontal privity is required for equitable servitudes.
Answer D: Ruth is bound only if all lots in the development were subject to an identical common scheme.
Correct Answer: A
Correct Answer Explanation: An equitable servitude may bind a successor if there is a writing, intent, touch and concern, and notice. Actual notice is enough. The residential-use restriction was written in Samuel's deed, affected land use, benefited David's retained parcel, and Ruth had actual notice before taking title.
Wrong Answer Explanations: B: B is wrong because recording is not the only way to establish notice; actual notice can bind a purchaser. C: C is wrong because horizontal privity is a real covenant damages requirement, not an equitable servitude injunction requirement. D: D is wrong because a common scheme is one enforcement route, but it is not required where the servitude otherwise exists and the successor has actual notice.
lb_rule_reference: Equitable servitude / actual notice / injunction
