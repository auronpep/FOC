Question: Jacob and several neighbors regularly used a gravel road across Esau's land to reach their separate parcels. Jacob used the road openly, without permission, and under a claim of right for 11 years. The jurisdiction's prescriptive period is 10 years. Esau argues that Jacob cannot have a prescriptive easement because other neighbors also used the same road. What is Jacob's strongest response?
Answer A: Exclusivity is required because Jacob is claiming a use right rather than title.
Answer B: Shared use proves Jacob's use was permissive even without any permission facts.
Answer C: Exclusivity is not generally required for a prescriptive easement, so shared use does not by itself defeat Jacob's claim.
Answer D: Jacob automatically owns the road in fee because several people used it openly.
Correct Answer: C
Correct Answer Explanation: A prescriptive easement requires open, continuous, adverse use for the statutory period, but exclusivity is not generally required. Jacob's shared use with others does not by itself defeat a prescriptive easement claim.
Wrong Answer Explanations: A: A is wrong because it reverses the rule; exclusivity belongs to adverse possession, not ordinary easement prescription. B: B is wrong because shared use alone does not prove permission. C is correct for the reasons above. D: D is wrong because prescription creates a use right, not fee title.
lb_rule_reference: Exclusivity not required for prescriptive easement
lb_student_diagnostic: The trap is importing the adverse-possession exclusivity element into prescriptive easements.
