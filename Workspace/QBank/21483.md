Question: Peter bought a printing press from Elizabeth for $100,000. The press was warranted to run at a specified speed, but a latent defect made the accepted press worth only $84,000 at delivery. Peter timely notified Elizabeth of the defect. A reasonable repair costing $10,000 raised the press's value to $94,000, but it still did not meet the warranty. No consequential damages are claimed. What is Peter's accepted-goods damages recovery?
Answer A: $10,000.
Answer B: $16,000.
Answer C: $6,000.
Answer D: $100,000.
Correct Answer: B
Correct Answer Explanation: The remedy interest is expectation under UCC Article 2 for accepted nonconforming goods. The accepted-goods measure is the value as warranted minus the value as accepted, and the repair facts confirm the same loss: $10,000 repair cost + $6,000 residual value shortfall = $16,000. The limiting gate is formula discipline after acceptance; acceptance changes the remedy but does not eliminate damages. The result scope is limited accepted-goods damages, and the answer does not decide rescission, rejection, or consequential losses.
Wrong Answer Explanations: A: A is wrong because it awards only repair cost and omits the remaining value loss, a WAL-REM-031 repair-after-acceptance undercount. C: C is wrong because it awards only residual loss after repair and omits the repair cost. D: D is wrong because acceptance with damages is not a full price-refund remedy on these facts.
lb_rule_reference: UCC §2-714 — accepted-goods damages measured by value-as-warranted minus value-as-accepted or special repair/residual proof
