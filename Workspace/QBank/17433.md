Subtopic: Jurisdiction and Venue
Outline: Specific and General Jurisdiction
Question: ToolCo is incorporated and headquartered in State A. It sells lawn mowers through dealers in State B and runs State B advertisements for those mowers. Plaintiff, a State B citizen, is injured in State C by an industrial forklift that ToolCo designed, sold, and serviced only in State C. Plaintiff sues ToolCo in State B over the forklift injury. Does State B have specific personal jurisdiction over ToolCo for the forklift claim?
Answer A: Yes, because ToolCo has real commercial contacts with State B
Answer B: Yes, because Plaintiff is a State B citizen and feels the injury there
Answer C: No, because ToolCo's State B contacts are unrelated to the forklift injury
Answer D: No, but only because ToolCo is not incorporated in State B
Correct Answer: C
Correct Answer Explanation: The State B mower business does not supply relatedness for a State C forklift claim.
Wrong Answer Explanations: A: Specific jurisdiction requires a claim-linked contact. The forklift claim does not arise from or relate to the mower sales. B: Specific jurisdiction depends on defendant-created contacts tied to the claim, not plaintiff residence. D: The call asks specific jurisdiction. Lack of incorporation may defeat general jurisdiction, but the specific-jurisdiction problem is missing relatedness.
lb_rule_reference: Specific jurisdiction requires defendant-created forum contacts connected to the claim; unrelated forum business cannot substitute for relatedness.
