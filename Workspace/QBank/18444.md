Question: In federal court based on diversity jurisdiction, Isaac sues the estate of Jacob on a state-law contract claim. The forum state has a Dead Man's Statute that makes an interested party incompetent to testify about an oral transaction with a deceased person. Isaac seeks to testify that Jacob orally promised to repay him. Jacob's estate objects under the state statute. How should the court rule?
Answer A: Apply the state competency rule because this is a civil case and state law supplies the rule of decision for the contract claim.
Answer B: Ignore the state statute because the Federal Rules always make every person competent in federal court.
Answer C: Apply the state statute only if Isaac's testimony would be hearsay.
Answer D: Allow Isaac to testify because interested-party status affects only credibility, never competency.
Correct Answer: A
Correct Answer Explanation: Under the federal competency rule, every person is competent unless a rule provides otherwise, but in a civil case state law governs competency regarding a claim or defense for which state law supplies the rule of decision. Because the diversity contract claim is governed by state law, the state Dead Man's Statute may control competency.
Wrong Answer Explanations: B: B is wrong because the federal rule expressly incorporates state competency law for relevant civil state-law claims or defenses. C: C is wrong because the issue is competency, not hearsay. D: D is wrong because interested-party status is usually credibility, but a valid state competency rule can make it a competency issue in the covered civil setting.
