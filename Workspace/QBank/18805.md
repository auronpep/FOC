Outline: Requirements for valid deed
Question: Mary signed and delivered a deed stating, “I convey my lake lot to my children.” At the time of delivery, Mary had exactly two living children, James and John. No other person claimed to be Mary's child. The deed otherwise satisfied deed formalities. Who owns the lake lot?
Answer A: Mary, because a deed must name each grantee individually.
Answer B: Mary, until James and John sign the deed.
Answer C: James and John, because the class description identifies ascertainable grantees.
Answer D: James alone, because the oldest child takes when a class deed does not state shares.
Correct Answer: C
Correct Answer Explanation: The title source is a deed, and the decisive validity gate is grantee ascertainability. A deed need not always state each grantee's full individual name if the grantees can be identified with reasonable certainty. Mary's children were James and John at delivery, so the deed can convey the lake lot to them.
Wrong Answer Explanations: A: A is wrong because individual names are not always required when the class is ascertainable. B: B is wrong because grantees generally need not sign the deed to take title. D: D is wrong because nothing in the deed gives the oldest child the entire property.
