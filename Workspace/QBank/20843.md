Subtopic: Strict Liability and Products Liability
Outline: Strict Products Liability
Question: A driver negligently runs a red light and is struck by another car. The driver's seatback collapses because of a defective design, turning a survivable collision into a severe spinal injury. The car manufacturer argues that it cannot be liable because the defect did not cause the red-light collision. Is that argument likely sufficient?
Answer A: Yes, because a product defect must cause the initial accident or there is no products claim
Answer B: Yes, because negligent driving always supersedes vehicle design defects
Answer C: No, because the defect may have caused enhanced injury even if it did not cause the collision
Answer D: No, because the manufacturer is liable for the entire accident without proving defect causation
Correct Answer: C
Correct Answer Explanation: Crashworthiness focuses on whether the design defect increased the harm in a foreseeable accident.
Wrong Answer Explanations: A: A defect can be actionable if it enhances injuries in a foreseeable crash. B: Crashes are foreseeable uses for crashworthiness design. D: The plaintiff must still prove defect and enhanced-injury causation.
lb_rule_reference: A vehicle defect need not cause the initial accident if it foreseeably enhances the plaintiff's injuries in a crash.
