Question: Congress wants uniform standards for online ticket sales. Instead of regulating sellers directly, it orders each state legislature to amend its consumer-protection code within six months to include the federal standards. A state refuses. What is the state's best argument?
Answer A: Congress cannot command state legislatures to enact or amend state law
Answer B: The order is valid because Congress could have regulated ticket sellers directly
Answer C: The order is valid because consumer protection is important
Answer D: The order is invalid only if the state also proves individual consumers were harmed
Correct Answer: A
Correct Answer Explanation: The statute commandeers state lawmaking rather than regulating private parties directly or preempting contrary law.
Wrong Answer Explanations: B: Having a valid direct-regulation option does not allow commandeering a state legislature. C: Policy importance does not permit state legislative commandeering. D: The anti-commandeering problem is the command to the state legislature.
lb_rule_reference: Congress may regulate private parties directly or preempt conflicting state law, but it may not command state legislatures to enact or amend state law.
