Outline: Opinion or reputation
Question: In a federal civil trial, Daniel testifies for Sarah. On cross-examination, the opposing party properly impeaches Daniel with a recent perjury conviction. Sarah then calls Martha to testify that, in her opinion, Daniel is a truthful person. The opposing party objects that opinion support is improper bolstering. How should the court rule?
Answer A: Sustain the objection because a prior conviction can never open the door to truthful-character support.
Answer B: Sustain the objection because truthful-character support must be by specific acts, not opinion.
Answer C: Overrule the objection because the perjury conviction attacked Daniel's character for truthfulness and opinion support is permitted.
Answer D: Overrule the objection only if Martha was present when Daniel committed perjury.
Correct Answer: C
Correct Answer Explanation: A conviction for perjury attacks Daniel's character for truthfulness. Once that character has been attacked, Rule 608(a) allows support by reputation or opinion evidence. Martha's opinion testimony is therefore a proper rehabilitative form.
Wrong Answer Explanations: A: A is wrong because conviction impeachment can attack truthfulness and open rehabilitation. B: B is wrong because opinion and reputation, not specific truthful acts, are the Rule 608(a) support forms. D: D is wrong because Martha need not have witnessed the prior conviction event to give an opinion about Daniel's character for truthfulness.
lb_rule_reference: FRE 608(a) / conviction attack opens truthful-character support
lb_student_diagnostic: Tests the attack type that opens truthful-character support and the correct support form.
