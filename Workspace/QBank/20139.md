Outline: Refreshing recollection
Question: In a federal contract trial, Moses reviews his old job-site notes in the hallway before taking the stand. During testimony, he says he reviewed the notes earlier that morning to prepare for his testimony, but he does not look at them on the stand. Opposing counsel Ruth asks the court to order production of the notes. How should the court rule?
Answer A: Deny the request because Rule 612 applies only to writings used while the witness is physically on the stand.
Answer B: Grant the request automatically because every document reviewed before testimony must be produced to the adverse party.
Answer C: Decide whether justice requires production because the writing was used before testifying to refresh memory for testimony.
Answer D: Admit the notes as substantive evidence because Moses reviewed them before testifying.
Correct Answer: C
Correct Answer Explanation: Rule 612 automatically gives the adverse party options when a witness uses a writing while testifying. When the writing was used before testifying, the adverse party receives those options only if the court decides that justice requires it. Moses reviewed the notes before taking the stand for purposes of testimony, so the court must make that justice-required determination.
Wrong Answer Explanations: A: A is wrong because Rule 612 can apply to pretestimony use if justice requires. B: B is wrong because pretestimony use is not automatically producible under Rule 612. D: D is wrong because reviewing a writing to refresh memory does not make the writing substantive evidence.
lb_rule_reference: FRE 612(a)(2) / writing used before testifying
lb_student_diagnostic: Tests the timing lock: while testifying versus before testifying.
