Outline: Requirements for valid deed
Question: David signed and delivered a deed stating, “I convey to Jonathan my house at 18 Shiloh Road in Judah County.” David owned exactly one house at that address. The deed did not include a metes-and-bounds description, tax parcel number, or survey. Jonathan accepted the deed. Who owns the house?
Answer A: David, because a deed must include a metes-and-bounds description.
Answer B: David, because a street address is never a sufficient land description.
Answer C: Jonathan only after a survey is attached to the deed.
Answer D: Jonathan, because the property description identifies the land with reasonable certainty.
Correct Answer: D
Correct Answer Explanation: The title source is a deed, and the decisive validity gate is whether the property is described with reasonable certainty. A metes-and-bounds description is not required if the land can be identified from the deed and existing facts. The address identifies the house, so title passes to Jonathan.
Wrong Answer Explanations: A: A is wrong because metes and bounds are not mandatory. B: B is wrong because a street address can be sufficient when it identifies the land. C: C is wrong because a survey attachment is not required when the description already identifies the property.
