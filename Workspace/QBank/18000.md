Subtopic: Separation of Powers
Outline: Commerce power
Question: A state-owned timber mill sells logs to buyers at a discount. The contract requires every buyer, including out-of-state buyers, to process any finished furniture inside the state before reselling it. The state argues that because it owns the logs, the condition is immune from DCC review. What is the strongest DCC objection?
Answer A: The state can impose any resale condition because it once owned the logs
Answer B: The condition is suspect because it regulates downstream private processing and resale
Answer C: The condition is valid because all buyers are treated the same
Answer D: The condition is invalid only if it discriminates against citizens rather than corporations
Correct Answer: B
Correct Answer Explanation: The state moves beyond its own sale and tries to reserve later private processing for in-state activity.
Wrong Answer Explanations: A: The exception does not allow the state to control downstream private markets after its own sale. C: A local-processing requirement can be protectionist even if formally uniform. D: DCC protects interstate commerce and can be invoked by businesses; it is not limited to citizen plaintiffs.
lb_rule_reference: The market participant exception lets the state choose terms in its own market, but it does not let the state regulate downstream private markets.
