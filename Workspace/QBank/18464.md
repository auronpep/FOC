Question: Daniel granted Abigail “an emergency vehicle access easement over the rear lane for fire, ambulance, and rescue access to Abigail's building.” Abigail began using the rear lane every morning for bakery deliveries because it was shorter than the public alley. The delivery trucks were not emergency vehicles and sometimes blocked Daniel's loading area. Daniel seeks to stop the deliveries. Which is the best result?
Answer A: Abigail may use the lane for deliveries because delivery access is useful to her building.
Answer B: Daniel should prevail because the easement is limited to emergency vehicle access and does not cover routine bakery deliveries.
Answer C: Abigail may use the lane for deliveries because all vehicles are treated as emergency vehicles if the owner prefers the route.
Answer D: Daniel should prevail only if the deliveries continue for the statutory period required for prescription.
Correct Answer: B
Correct Answer Explanation: The grant's purpose controls. An emergency vehicle access easement for fire, ambulance, and rescue access does not authorize routine commercial deliveries, especially where those deliveries burden the servient owner's loading area.
Wrong Answer Explanations: A: A is wrong because usefulness to the dominant building does not expand a purpose-limited easement. B is correct because the stated purpose is emergency access. C: C is wrong because ordinary delivery vehicles are not emergency vehicles. D: D is wrong because Daniel is enforcing scope now, not waiting for a prescriptive-period issue.
lb_rule_reference: Emergency access / purpose limit
