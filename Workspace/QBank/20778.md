Question: A state denies otherwise eligible lawful permanent residents access to a general state disaster-relief grant available to citizens. The grant does not involve public employment or democratic self-governance. What scrutiny most likely applies?
Answer A: Strict scrutiny, because this is a state alienage classification outside the public-function exception
Answer B: Rational basis, because all alienage classifications receive federal immigration deference
Answer C: Intermediate scrutiny, because alienage is like gender
Answer D: No scrutiny applies because disaster relief is discretionary
Correct Answer: A
Correct Answer Explanation: States generally face strict scrutiny when discriminating against lawful resident aliens.
Wrong Answer Explanations: B: Federal alienage classifications get deference; state alienage classifications generally do not. C: State alienage classifications generally receive strict scrutiny. D: Government benefits cannot be distributed using suspect classifications without scrutiny.
lb_rule_reference: State classifications disadvantaging lawful resident aliens generally receive strict scrutiny unless a recognized exception, such as the political-function exception, applies.
