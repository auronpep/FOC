Question: Solomon conveyed Lot 3 to Esther by deed. The deed stated that Lot 3 was conveyed “together with the access easement shown as Easement A on recorded Plat 22.” Plat 22, recorded in the county land records, showed a ten-foot lane from Lot 3 across Solomon's retained parcel to the public road. Solomon later argued that no express easement was created because the deed itself did not spell out the lane's metes and bounds. Is Solomon correct?
Answer A: No. A deed may create an express easement by incorporating a recorded plat that reasonably identifies the easement route.
Answer B: Yes. An easement is invalid unless the deed itself contains a full metes-and-bounds description of the route.
Answer C: Yes. A plat can create only zoning rights, not private easements.
Answer D: No, but only because Esther owns fee title to the ten-foot lane.
Correct Answer: A
Correct Answer Explanation: A written grant may identify an easement by reference to another recorded instrument or plat if the incorporated document reasonably locates the right. The deed expressly incorporates recorded Plat 22, which shows the access lane.
Wrong Answer Explanations: B: B is wrong because a full metes-and-bounds description in the deed itself is not always required if the route is otherwise reasonably identified. C: C is wrong because recorded plats can be used to define private easement rights when incorporated. D: D is wrong because the grant creates a use right, not fee ownership of the lane.
