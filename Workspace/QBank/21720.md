Outline: Laying a Foundation
Question: In a federal property dispute, Joshua offers a handwritten boundary memorandum dated twenty-five years before trial. The memorandum is found in a locked family records box where boundary papers were kept, and it is in a condition that creates no suspicion about authenticity. The opponent objects that no living witness saw it written. How should the court rule on authentication?
Answer A: Exclude the memorandum because ancient documents require a living subscribing witness.
Answer B: Admit the memorandum if the court finds the age, condition, and location requirements for ancient-document authentication satisfied.
Answer C: Exclude the memorandum unless a handwriting expert identifies the writer.
Answer D: Admit the memorandum only if the opponent stipulates that it is genuine.
Correct Answer: B
Correct Answer Explanation: A document can be authenticated as an ancient document if it is in a condition creating no suspicion, was found in a place where authentic documents of that kind would likely be, and is at least twenty years old when offered.
Wrong Answer Explanations: A: A is wrong because a living witness to the writing is not required. C: C is wrong because expert handwriting testimony is not necessary if the ancient-document foundation is met. D: D is wrong because a stipulation is not required.
lb_rule_reference: FRE 901(b)(8) / ancient document authentication
lb_student_diagnostic: Tests ancient-document authentication and foundation method selection.
