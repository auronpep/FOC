Question: Congress enacts a valid statute setting federal safety standards for private drone manufacturers and providing that conflicting state standards are preempted. A state argues the law commandeers it because state regulators may no longer enforce a different state standard. What is the best answer?
Answer A: The federal statute is commandeering because any preemption affects state regulators
Answer B: The statute regulates private manufacturers and preempts contrary state law; that is not commandeering
Answer C: The statute is invalid because federal safety standards can never preempt state safety standards
Answer D: The statute is valid only if states vote to approve the federal standard
Correct Answer: B
Correct Answer Explanation: Congress is acting directly on private parties and displacing conflicting state standards.
Wrong Answer Explanations: A: Preemption of conflicting state law is different from ordering states to administer a federal program. C: Valid federal law can preempt state law even in traditional state regulatory areas. D: Valid federal law is supreme without state approval.
lb_rule_reference: Congress may regulate private parties directly and preempt conflicting state law; that is not commandeering merely because states must stop enforcing contrary rules.
