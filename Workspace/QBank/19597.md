Subtopic: General Principles
Outline: Mistake
Question: A warrant lists "214 Pine Street" but also describes the target as "the only blue two-story house on the northeast corner of Pine and Third, with a red front door." The correct address is 216 Pine Street, and that description identifies only one house. Officers search that blue house and find stolen laptops. Is the search invalid solely because the street number was wrong?
Answer A: No, because the warrant described the place with enough practical certainty despite the minor address error
Answer B: Yes, because any incorrect digit in a warrant automatically requires suppression
Answer C: No, because warrants never need to describe the place searched
Answer D: Yes, because officers found laptops rather than drugs
Correct Answer: A
Correct Answer Explanation: The particular description uniquely identified the premises. The technical address error did not create a realistic risk of searching the wrong place.
Wrong Answer Explanations: B: Particularity is practical. A minor error does not invalidate a warrant that otherwise identifies the place with reasonable certainty. C: Warrants do need particularity. This warrant satisfied that requirement through its detailed description. D: The call asks about the place description. Whether the laptops were within item scope would be a separate question not supplied by these facts.
lb_rule_reference: A warrant satisfies particularity when it enables officers to identify the correct place with reasonable certainty, despite a technical mistake.
