Question: A state-owned timber mill sells lumber at a discount to local furniture makers. The contract also requires every buyer to resell any furniture made with the lumber only within the state for five years. Out-of-state furniture retailers challenge the restriction. What is the best DCC analysis?
Answer A: The downstream resale restriction likely exceeds the market participant exception
Answer B: The restriction is valid because state ownership lets it control every later private resale
Answer C: The restriction is invalid only if the state sells to no local buyers
Answer D: The restriction is valid because furniture is not commerce
Correct Answer: A
Correct Answer Explanation: The state may participate in the lumber market, but it is trying to control a downstream furniture market.
Wrong Answer Explanations: B: Market participation does not create unlimited downstream regulatory power. C: The problem is downstream control, not whether local buyers exist. D: Furniture resale is commerce.
lb_rule_reference: The market participant exception permits local preference in the market in which the state participates, but it does not allow the state to regulate downstream private markets.
