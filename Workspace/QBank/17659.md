Question: Joseph did not own Redacre. Nevertheless, Joseph signed and delivered a quitclaim deed to Benjamin stating that Joseph quitclaimed “all right, title, and interest I have in Redacre.” Benjamin accepted. One year later, Joseph inherited Redacre. No statute changes the common-law effect of the deed, and the deed contained no warranty language. Who owns Redacre after Joseph inherits it?
Answer A: Benjamin, because any deed automatically carries after-acquired title.
Answer B: Benjamin, because Joseph's later inheritance relates back to the date of the quitclaim deed.
Answer C: Benjamin only if he paid fair value for the quitclaim deed.
Answer D: Joseph, because the quitclaim deed conveyed only Joseph's then-existing interest and did not generally pass after-acquired title.
Correct Answer: D
Correct Answer Explanation: The title source is a quitclaim deed, and the decisive deed-type lock is whether the instrument carries after-acquired title. Joseph had no interest when he delivered the quitclaim deed, and the deed contained no warranty language. Under the stated common-law default, the quitclaim conveyed only Joseph's then-existing interest, so Joseph keeps Redacre when he later inherits it.
Wrong Answer Explanations: A: A is wrong because after-acquired title is not automatic for every deed type. B: B is wrong because the quitclaim did not create a relation-back transfer of later-acquired title on these facts. C: C is wrong because Benjamin's value does not change the quitclaim's deed-type effect.
lb_rule_reference: Quitclaim deed generally does not carry after-acquired title
