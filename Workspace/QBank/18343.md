Subtopic: Relevancy and Excluding Relevant Evidence
Outline: Discretionary exclusion (undue prejudice, confusion, waste of time)
Question: In a federal products-liability trial, Rebekah calls three qualified engineers who each testify that the same bolt failed because of the same design flaw. Rebekah then seeks to call four more engineers to give the same opinion using the same tests. The defendant objects under Rule 403. How should the court rule?
Answer A: Overrule the objection because expert testimony can never be cumulative.
Answer B: Sustain the objection if the additional experts would needlessly repeat the same point and waste time.
Answer C: Sustain the objection only if the first three experts were unqualified.
Answer D: Overrule the objection because the proponent is entitled to call as many experts as she can afford.
Correct Answer: B
Correct Answer Explanation: Rule 403 permits the court to exclude needlessly cumulative evidence and prevent waste of time. Repetitive expert testimony on the same point may add little probative value after multiple experts have already testified.
Wrong Answer Explanations: A: A is wrong because expert testimony can be cumulative. C: C is wrong because the first experts' qualification does not control whether additional identical testimony is needlessly cumulative. D: D is wrong because a party does not have an unlimited right to present repetitive evidence.
lb_rule_reference: FRE 403
lb_student_diagnostic: Student treats expert status as defeating cumulative-proof control.
