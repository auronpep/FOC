Outline: Parol Evidence Rule
Question: Samuel agreed in a signed land-sale contract to sell Lydia “Lot 4, consisting of 20 acres.” The writing contained a merger clause and a metes-and-bounds description of Lot 4. Lydia offers evidence that, before signing, Samuel orally promised to include a separate two-acre orchard next to Lot 4 for the same price. How should the court treat the evidence? How should the court treat the evidence?
Answer A: Admit it because land contracts are not subject to the parol evidence rule.
Answer B: Admit it because the orchard promise is helpful to show Lydia's expectations.
Answer C: Exclude it only if Samuel proves that the orchard is worth more than the rest of Lot 4.
Answer D: Exclude it because it adds a separate parcel inconsistent with the complete written land description.
Correct Answer: D
Correct Answer Explanation: A complete land-sale writing with a specific legal description cannot be varied by a prior oral promise to include a separate parcel. The offered oral term adds land not described in the integrated writing.
Wrong Answer Explanations: A: A is wrong because land contracts can be subject to the parol evidence rule. B: B is wrong because a party's expectation does not overcome an integrated legal description. C: C is wrong because value is not the test for whether a prior oral parcel term contradicts the writing.
lb_rule_reference: Complete integration / land description contradiction
