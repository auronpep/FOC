Subtopic: Relations Between Federal and State Governments
Outline: Tenth Amendment
Question: Congress wants uniform rules for private data brokers. Instead of regulating the brokers directly or preempting conflicting state laws, Congress orders each state attorney general to write and enforce state regulations matching a federal template. Which answer best states the constitutional problem?
Answer A: Congress may not commandeer state officials to administer a federal regulatory program, even if Congress could regulate private data brokers directly
Answer B: The order is valid because Congress could have preempted state law, so it may command state enforcement instead
Answer C: The order is invalid because Congress can never regulate private data brokers
Answer D: The order is valid if Congress reimburses the states for enforcement costs
Correct Answer: A
Correct Answer Explanation: The existence of a valid federal regulatory target does not permit Congress to conscript state governments as administrators.
Wrong Answer Explanations: B: Preemption and direct private regulation are valid alternatives; commandeering state officials is different. C: The question assumes Congress might regulate private brokers directly; the defect is state commandeering. D: Paying costs does not convert a direct command to administer a federal program into valid spending inducement.
lb_rule_reference: Congress may regulate private parties directly or preempt conflicting state law, but it may not avoid federal administration costs by ordering states to enact or administer the federal program.
