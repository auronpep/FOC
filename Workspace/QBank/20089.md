Question: Without a warrant, officers crawl under a suspect's car parked in a public lot and attach a GPS tracker. They monitor the car's movements for three weeks and use the data to connect the suspect to several robberies. Was attaching and using the GPS tracker a Fourth Amendment search?
Answer A: No, because the car traveled only on public roads where anyone could watch it
Answer B: Yes, because officers physically trespassed on the vehicle to install a device for information gathering
Answer C: No, because GPS data is never private
Answer D: Yes, but only because the monitoring lasted more than one day
Correct Answer: B
Correct Answer Explanation: Installing the GPS device was a physical intrusion on property for the purpose of obtaining information, which is a search.
Wrong Answer Explanations: A: Physical attachment of a device to obtain information is a search even if the vehicle later travels publicly. C: The physical installation itself triggers Fourth Amendment search analysis. D: The physical trespass to install the tracker is enough to classify the conduct as a search.
lb_rule_reference: Physically attaching a GPS device to a vehicle to obtain information is a Fourth Amendment search.
