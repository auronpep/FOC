Question: The clerk entered default after defendant missed the answer deadline. No default judgment has been entered. Ten days later, defendant appears, explains a calendaring error, shows a potentially meritorious defense, and moves to set aside the entry of default. Which standard applies?
Answer A: Good cause under Rule 55(c), because only entry of default has occurred
Answer B: Rule 60(b) automatically applies because any default is a final judgment
Answer C: Rule 50 applies because the defendant has a defense
Answer D: No standard applies because defaults can never be set aside
Correct Answer: A
Correct Answer Explanation: The case is at the entry-of-default stage, not final default judgment.
Wrong Answer Explanations: B: Entry of default is not the same as default judgment. C: Rule 50 concerns JMOL at trial. D: Rule 55(c) permits setting aside entry of default for good cause.
lb_rule_reference: The court may set aside an entry of default for good cause; setting aside a final default judgment requires Rule 60(b) standards.
