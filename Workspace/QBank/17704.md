Question: A state court in State A enters judgment in a contract dispute. Later, the defendant is sued in federal court in State B and argues that the State A judgment is preclusive. The parties dispute which preclusion law governs the State A judgment's effect. Which law should the federal court generally consult?
Answer A: State A preclusion law, because State A rendered the judgment
Answer B: Federal preclusion law always, because the second court is federal
Answer C: State B law always, because the second case is pending there
Answer D: No preclusion law applies unless both cases are in the same court
Correct Answer: A
Correct Answer Explanation: Federal courts generally give state judgments the same effect the rendering state would give.
Wrong Answer Explanations: B: The source of the prior judgment matters. C: The rendering state controls the state judgment's effect. D: Preclusion often operates across courts.
lb_rule_reference: Full faith and credit principles require federal courts to look to the rendering state's preclusion law for state judgments.
