Question: In a federal negligence trial, Hannah testifies about the layout of a market aisle. Her lawyer displays a simple diagram that Hannah says fairly illustrates the relative positions of the shelves, although it is not drawn to scale. The lawyer offers the diagram only to help the jury understand Hannah's testimony. The defendant objects that the diagram is not itself an exact depiction of the scene. How should the court rule?
Answer A: Exclude the diagram because demonstrative aids must be exact scale models.
Answer B: Admit the diagram as conclusive proof of the aisle dimensions.
Answer C: Allow the diagram as a demonstrative aid if it fairly helps illustrate Hannah's testimony, with any needed limiting instruction.
Answer D: Allow the diagram only if it is self-authenticating.
Correct Answer: C
Correct Answer Explanation: A demonstrative aid may be used to help explain testimony if it fairly illustrates the witness's testimony and is not misleading. It need not be an exact, substantive depiction of the scene if it is used only illustratively.
Wrong Answer Explanations: A: A is wrong because demonstratives need not always be exact scale models. B: B is wrong because the diagram's illustrative use does not make it conclusive substantive proof of dimensions. D: D is wrong because self-authentication is not the route for a demonstrative aid illustrating testimony.
lb_rule_reference: FRE 611 / demonstrative aid versus substantive exhibit
lb_student_diagnostic: Tests proof-vehicle identity: demonstrative aid versus real/documentary evidence.
