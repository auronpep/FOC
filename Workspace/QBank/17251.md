Outline: Prior inconsistent statement
Question: In a federal battery trial, Mark testifies that he saw Joshua strike Abel. On cross-examination, Mark also says he has never owned a red fishing boat. The defense asks to call Luke to testify that Mark once told him, “I own a red fishing boat.” The defense offers Luke only to contradict Mark on that point. The prosecutor objects. How should the court rule?
Answer A: Admit Luke's testimony because every prior inconsistent statement may be proved by extrinsic evidence.
Answer B: Admit Luke's testimony because Mark's ownership of a red fishing boat proves he is untruthful.
Answer C: Exclude Luke's testimony because the boat issue is collateral and the proposed extrinsic proof would only distract from the battery issue.
Answer D: Exclude Luke's testimony only if Mark was not first shown a photograph of the boat.
Correct Answer: C
Correct Answer Explanation: Rule 613(b) supplies timing requirements for extrinsic proof of prior inconsistent statements, but it does not require admission of extrinsic proof on collateral matters. Mark's boat ownership has no independent significance to the battery case and is offered only to contradict him on a side point, so the court should exclude it as collateral or under ordinary control and balancing principles.
Wrong Answer Explanations: A: A is wrong because Rule 613 does not make all extrinsic inconsistencies admissible. B: B is wrong because ownership of a red fishing boat is not a truthfulness-specific act. D: D is wrong because showing a photograph is not the decisive requirement.
lb_rule_reference: FRE 613(b) plus collateral matter limit / extrinsic PIS discretion
lb_student_diagnostic: Tests the interaction between prior-inconsistent-statement impeachment and collateral-matter control.
