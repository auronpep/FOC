Subtopic: Jurisdiction and Venue
Outline: Venue
Question: A defendant first files a Rule 12(b)(6) motion to dismiss for failure to state a claim. At the time, the defendant also knows all facts supporting an improper venue objection. After the court denies the Rule 12(b)(6) motion, the defendant files a second pre-answer motion under Rule 12(b)(3) for improper venue. How should the court rule on the venue motion?
Answer A: Hear it because Rule 12(b)(6) motions never trigger consolidation
Answer B: Deny it as waived because improper venue was available but omitted from the first Rule 12 motion
Answer C: Hear it because venue can be raised any time before trial
Answer D: Deny it only if the plaintiff proves the venue was actually proper
Correct Answer: B
Correct Answer Explanation: Improper venue is a Rule 12(b)(3) defense subject to Rule 12(h)(1) waiver. Because the defendant knew the venue facts and omitted the defense from the first Rule 12 motion, it is waived.
Wrong Answer Explanations: A: Once a party makes a Rule 12 motion, available Rule 12(b)(2)-(5) defenses must be consolidated. Venue was available and omitted. C: Venue is waivable. It must be raised in the first Rule 12 response opportunity. D: The problem is waiver, not whether venue was correct. A waived venue defense is unavailable even if venue was defective.
lb_rule_reference: Rule 12(g) and Rule 12(h)(1) bar a party from making a second pre-answer motion raising an available Rule 12(b)(2)-(5) defense omitted from the first Rule 12 motion.
