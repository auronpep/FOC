Subtopic: Relevancy and Excluding Relevant Evidence
Outline: Laying a Foundation
Question: Abraham offers a handwritten note allegedly signed by Sarah. To authenticate it, Abraham calls Elijah, who testifies that he first studied Sarah's handwriting last week after Abraham's lawyer showed him several documents for this lawsuit. Elijah had never seen Sarah's handwriting before that. Sarah objects. How should the court rule on Elijah's handwriting opinion?
Answer A: Admit it because any person who has compared handwriting samples may give a nonexpert opinion.
Answer B: Admit it because the jury is free to accept or reject Elijah's opinion.
Answer C: Exclude it because a nonexpert handwriting opinion must be based on familiarity not acquired for the current litigation.
Answer D: Exclude it only if Sarah proves that the note is forged.
Correct Answer: C
Correct Answer Explanation: A nonexpert handwriting opinion is allowed only when familiarity with the handwriting was not acquired for the current litigation. Elijah's familiarity was created for the lawsuit, so this proof channel fails.
Wrong Answer Explanations: A: A is wrong because litigation-created familiarity is specifically insufficient for this nonexpert route. B: B is wrong because the jury's ability to weigh evidence does not cure a missing foundation requirement. D: D is wrong because Sarah need not prove forgery before objecting to a defective authentication method.
lb_rule_reference: FRE 901(b)(2)
lb_student_diagnostic: Ignoring the source of handwriting familiarity.
