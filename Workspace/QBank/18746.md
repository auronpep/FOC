Outline: Uniform Commercial Code (UCC)
Question: John orally agreed to buy 500 robes from Deborah, each embroidered with John's new store name in a unique pattern. Before John repudiated, Deborah ordered the special fabric, cut 300 robes, and began the embroidery. The robes would not be suitable for sale to others in Deborah's ordinary business. Can Deborah enforce the oral contract despite the lack of a signed writing?
Answer A: Yes, because the goods were specially manufactured, unsuitable for ordinary resale, and Deborah made a substantial beginning before repudiation.
Answer B: No, because UCC §2-201 has no exceptions once the price exceeds $500.
Answer C: No, because specially manufactured goods must be fully completed before the exception applies.
Answer D: Yes, but only for the number of robes already fully embroidered.
Correct Answer: A
Correct Answer Explanation: UCC §2-201 allows enforcement without a signed writing when goods are specially manufactured for the buyer, unsuitable for sale to others in the seller's ordinary course, and the seller has made a substantial beginning or commitments before receiving notice of repudiation. Deborah's facts satisfy that route.
Wrong Answer Explanations: B: B is wrong because UCC §2-201 contains exceptions. C: C is wrong because substantial beginning or procurement commitments may be enough; full completion is not required. D: D is wrong because the exception is not limited to fully finished goods.
lb_rule_reference: UCC §2-201 / specially manufactured goods
