Outline: Parol Evidence Rule
Question: A written goods contract required Joshua to sell Abigail “all grain required by this agreement.” The writing did not say whether Abigail had promised to buy all of her farm's grain needs from Joshua or only the grain needed for one festival. Before signing, Abigail had sent Joshua a written request for bids stating that she sought a supplier for “all grain needed for the spring festival.” Joshua offers the request for bids to explain the phrase. How should the court rule? How should the court rule?
Answer A: Exclude the request because it was written before the final contract.
Answer B: Exclude the request because the contract contains the word all.
Answer C: Admit the request if the phrase is reasonably ambiguous and the evidence helps explain its meaning.
Answer D: Admit the request only if Abigail breached the contract first.
Correct Answer: C
Correct Answer Explanation: A prior document can be parol evidence, but it may be admissible to explain an ambiguous contractual phrase. The request for bids clarifies whether “all grain required by this agreement” means all farm needs or the festival order.
Wrong Answer Explanations: A: A is wrong because prior timing does not bar evidence offered to explain ambiguity. B: B is wrong because the word “all” does not eliminate the ambiguity about the scope of the requirement. D: D is wrong because the admissibility question is separate from breach.
