Question: Isaac owned Lot 1, which benefited from an easement across Rebekah's Lot 2. Isaac later built a permanent new driveway from Lot 1 directly to a public road. He wrote to Rebekah, “I am giving up the old easement forever,” removed the old gate on Lot 1, and built a masonry wall across the only entrance from Lot 1 to the easement route. Fifteen years later, Isaac tried to use the old route again. Which result is most likely?
Answer A: The easement necessarily survived because nonuse alone can never matter.
Answer B: The easement survived because abandonment always requires a formal written release.
Answer C: The easement was likely abandoned because Isaac's statement and permanent obstruction showed intent and conduct inconsistent with keeping it.
Answer D: The easement converted into fee title in Lot 2 because Isaac once held a right to cross.
Correct Answer: C
Correct Answer Explanation: Abandonment generally requires intent to relinquish the easement plus conduct inconsistent with continued ownership. Isaac's express statement, construction of a permanent substitute, removal of the old gate, and wall across the entrance strongly show abandonment.
Wrong Answer Explanations: A: A is wrong because this case includes far more than nonuse. B: B is wrong because abandonment can arise from intent and conduct even without a formal release. C is correct for the reasons above. D: D is wrong because an easement is a use right, not fee title.
lb_rule_reference: Abandonment / intent plus inconsistent conduct
lb_student_diagnostic: The trap is repeating the nonuse-alone rule when the facts include objective abandonment conduct.
