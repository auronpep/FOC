Question: Joseph owned Lot 1 and Lot 2 next to each other. He signed and delivered a deed to Benjamin stating, “I convey Lot 1 of the Bethel subdivision to Benjamin.” The deed accurately described Lot 1 and did not mention Lot 2. When Joseph handed over the deed, he orally said, “I also mean for you to have Lot 2.” Benjamin accepted. Joseph signed no writing describing Lot 2. What is the best result?
Answer A: Benjamin owns both lots because Joseph orally stated that intent during delivery.
Answer B: Benjamin owns Lot 1 only, because the deed's written property description does not convey Lot 2.
Answer C: Benjamin owns Lot 2 only, because the oral statement was later in time than the written description.
Answer D: Benjamin owns neither lot because the oral statement contradicted the deed.
Correct Answer: B
Correct Answer Explanation: The title source is a deed, and the decisive validity gate is the written property description. The deed identifies and conveys Lot 1. Joseph's oral statement cannot add Lot 2 to the written conveyance because Lot 2 was not described in the deed or another signed writing. The correct consequence is partial title: Benjamin receives Lot 1 only.
Wrong Answer Explanations: A: A is wrong because oral intent cannot expand a land description to an additional parcel not described in the deed. C: C is wrong because a later oral statement does not displace the written deed description. D: D is wrong because the oral statement does not defeat the valid written conveyance of Lot 1.
