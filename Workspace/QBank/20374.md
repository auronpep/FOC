Outline: Laying a Foundation
Question: In a federal civil trial, Paul offers a handwritten note allegedly written by Lydia. Mark testifies that he exchanged handwritten letters with Lydia for ten years before the lawsuit and recognizes the note as Lydia's handwriting. Lydia objects that Mark is not a handwriting expert. How should the court rule?
Answer A: Exclude the note because handwriting can be authenticated only by an expert.
Answer B: Exclude the note because Mark must have seen Lydia write this particular note.
Answer C: Admit the note because Mark's pre-litigation familiarity with Lydia's handwriting is sufficient foundation.
Answer D: Admit the note only if Lydia first denies writing it.
Correct Answer: C
Correct Answer Explanation: A nonexpert may give an opinion that handwriting is genuine if the opinion is based on familiarity not acquired for the current litigation. Mark's ten years of letters with Lydia supply that foundation.
Wrong Answer Explanations: A: A is wrong because expert testimony is not required. B: B is wrong because the witness need not have seen the particular writing created. D: D is wrong because a denial by the alleged writer is not a foundation prerequisite.
lb_rule_reference: FRE 901(b)(2) / nonexpert handwriting familiarity before litigation
lb_student_diagnostic: Tests nonexpert handwriting authentication and rejects the expert-only trap.
