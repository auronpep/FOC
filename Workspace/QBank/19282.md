Outline: Opinion or reputation
Question: In a federal contract trial, Mary calls John as her first witness. Before John is cross-examined, Mary calls Elizabeth and asks, “What is John's reputation for truthfulness?” The opposing party objects. How should the court rule?
Answer A: Overrule the objection because every witness's truthfulness is automatically in issue.
Answer B: Overrule the objection because reputation evidence is a permitted form of character proof.
Answer C: Sustain the objection only if Elizabeth intends to mention specific acts.
Answer D: Sustain the objection because truthful-character support is admissible only after the witness's character for truthfulness has been attacked.
Correct Answer: D
Correct Answer Explanation: Rule 608(a) allows support for a witness's truthful character only after the witness's character for truthfulness has been attacked. John has not been attacked yet, so the reputation testimony is premature.
Wrong Answer Explanations: A: A is wrong because general credibility relevance does not permit preemptive bolstering. B: B is wrong because reputation is a proper form only when support is otherwise allowed. C: C is wrong because the defect is timing, not merely specific-act content.
lb_rule_reference: FRE 608(a) / premature truthful-character bolstering
lb_student_diagnostic: Tests premature bolstering and the difference between permitted form and permitted timing.
