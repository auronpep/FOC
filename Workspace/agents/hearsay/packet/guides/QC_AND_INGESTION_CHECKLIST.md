# Quick QA and Ingestion Checklist

Before importing a generated artifact:

1. YAML parses.
2. Top-level sections are present and ordered.
3. `artifact_type` is `hearsay_finished_question_draft`.
4. `review_status` is `draft_internal_only`.
5. Exact statement is identified.
6. Declarant is identified.
7. Offered purpose is identified.
8. Every layer is routed.
9. Correct answer is one-best-answer.
10. Every wrong answer has WAL + REP + failure axis.
11. Christian surface is explicit and legally sterile.
12. No source text or source answer choices were copied.
13. No fabricated outline code.
14. No fabricated authority.
15. Human-review flags remain true.
